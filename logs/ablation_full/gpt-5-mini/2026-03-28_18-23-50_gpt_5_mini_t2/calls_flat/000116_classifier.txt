## Root Cause
In code_snippets_v2/temporal_drift_c/pipeline.py the call compute_raw_stats(normalized) uses the variable 'normalized' instead of the original input variable 'data'. This causes compute_raw_stats to receive transformed data rather than the original untransformed data. The specific function/variable pair at fault is compute_raw_stats(normalized) in pipeline.pipeline.

## Failure Mechanism
Because pipeline.pipeline computes normalized = normalize(data) and then calls compute_raw_stats(normalized), raw_stats values become statistics of the normalized values (numbers in [0,1]) rather than the original values. For example, given data = [10, 20, 30], normalize(data) yields [0.0, 0.5, 1.0]. compute_raw_stats(normalized) will produce {'raw_max': 1.0, 'raw_min': 0.0, 'raw_sum': 1.5, 'raw_count': 3} and compute_derived will give raw_mean 0.5. The expected raw stats for the original data are {'raw_max': 30, 'raw_min': 10, 'raw_sum': 60, 'raw_count': 3} and raw_mean 20. Downstream consumers relying on raw_* keys (for example drift checks comparing raw_mean between batches) will therefore operate on incorrect values and produce incorrect conclusions.

## Broken Invariant
The pipeline contract 'raw_stats MUST reflect the original data before any transforms' is violated. Concretely, for any non-empty input list data, after pipeline(data) the invariant raw_stats['raw_max'] == max(data) must hold (and similarly for raw_min, raw_sum, raw_count). With the current code raw_stats reflect max(normalize(data)) instead.

## Fix Strategy
Call compute_raw_stats on the original input 'data' before applying transforms. I moved the raw-stat computation to Stage 1 and use compute_raw_stats(data) so raw_stats are computed from the untransformed input. This ensures raw_max/raw_min/raw_sum/raw_count match the original data and derived metrics computed from them are correct, while later stages still operate on normalized/clipped values for display.

"""Multi-stage metrics pipeline.

Stage 1: compute raw stats on original data
Stage 2: normalize
Stage 3: clip to range
Stage 4: summarize for display
"""

from transforms import normalize, clip, summarize_for_display
from metrics import compute_raw_stats, compute_derived


def pipeline(data):
    """4-stage pipeline.

    raw_stats MUST reflect the original data before any transforms.
    """
    # Stage 1: raw stats (must use original data)
    raw_stats = compute_raw_stats(data)
    derived = compute_derived(raw_stats)
    # Stage 2: normalize
    normalized = normalize(data)
    # Stage 3: clip
    clipped = clip(normalized, 0.05, 0.95)
    # Stage 4: display summary
    display = summarize_for_display(clipped)

    return {
        "raw_stats": raw_stats,
        "derived": derived,
        "cleaned": clipped,
        "display": display,
    }
