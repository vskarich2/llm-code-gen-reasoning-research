# Developer's Reasoning

## Root Cause
The bug is in catalog.update_product: after updating the database entry in _db (via _db[product_id].update(fields)), the function does not call invalidate(product_id) to remove the cached copy stored by cache.put. Because the cache key (product_id) remains present in the cache module's _store, subsequent reads can return the stale cached value instead of the updated _db entry.

## Failure Mechanism
Concrete scenario: add_product(1, 'Socks', 10) stores {'name':'Socks','price':10} in _db. get_product(1) calls get(1), sees no cache, reads product = _db.get(1) and then calls put(1, dict(product)) to cache {'name':'Socks','price':10}. Now update_product(1, price=12) executes _db[1].update({'price':12}) but does not call invalidate(1), so the cache still holds the old dict with price 10. A later get_product(1) will call get(1), receive the cached {'name':'Socks','price':10}, and return it, so callers observe price 10 instead of the updated 12. The root cause is the missing invalidate(product_id) call in update_product, allowing the cache to serve stale data.

## Broken Invariant
After calling update_product(product_id, **fields) with an existing product_id, a subsequent get_product(product_id) must return a product whose fields reflect the updated values in _db. Formally: if update_product(pid, price=P) returns True, then get_product(pid)['price'] == P.

## Fix Strategy
I added a call to invalidate(product_id) immediately after updating the in-memory DB in update_product. This ensures the cache no longer contains the old copy, so the next get_product will see a cache miss, read the updated object from _db, repopulate the cache with the fresh values via put(product_id, dict(product)), and then return a product reflecting the update. The change is localized to update_product and uses the existing invalidate import.

"""Product catalog using external cache module."""

from cache import get, put, invalidate

_db = {}


def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Ensure cache no longer serves stale data after an update
    invalidate(product_id)
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()
