# Developer's Reasoning

## Root Cause
The function update_product updates the in-memory database _db but does not modify or invalidate the cached entry in _cache. Specifically, update_product calls _db[product_id].update(fields) and then returns True without touching _cache, so _cache can continue to hold an outdated dict for product_id.

## Failure Mechanism
Concrete scenario: call add_product('p1', 'Widget', 10.0) then call get_product('p1') — get_product stores a copy of _db['p1'] in _cache['p1']. Later call update_product('p1', price=12.0). update_product updates _db['p1'] to {'name': 'Widget', 'price': 12.0'} but leaves _cache['p1'] as the old {'name': 'Widget', 'price': 10.0'}. A subsequent get_product('p1') sees product_id in _cache and returns the stale cached dict (old price), so callers observe the old price despite the database having the new value.

## Broken Invariant
After a successful update_product(product_id, ... ) (i.e., update_product returns True), get_product(product_id) must return data equal to the current database entry _db[product_id]. Testable statement: for any existing product_id, if update_product(product_id, **fields) returns True, then get_product(product_id) == _db[product_id].

## Fix Strategy
Ensure the cache reflects the updated database state and prevent callers from mutating internal cached objects. Concretely: (1) after writing to _db in update_product, refresh _cache[product_id] with a shallow copy of the updated _db entry so get_product cannot return stale data; (2) make add_product also refresh the cache for consistency when a product is added or replaced; (3) make get_product return a fresh copy (dict(...)) to callers so external mutations don't corrupt cached data. These changes address the exact failure mechanism by keeping _cache synchronized with _db and isolating callers from internal mutable state.

_db = {}
_cache = {}


def add_product(product_id, name, price):
    """Add or replace a product in the database and refresh the cache."""
    _db[product_id] = {"name": name, "price": price}
    # Keep cache consistent with the database so get_product always returns current data.
    _cache[product_id] = dict(_db[product_id])


def get_product(product_id):
    """Get product by ID, returning a fresh copy.

    Uses an internal cache for fast repeated lookups. Callers receive a copy
    to avoid mutating internal state.
    """
    cached = _cache.get(product_id)
    if cached is not None:
        return dict(cached)
    product = _db.get(product_id)
    if product is None:
        return None
    # Cache a copy and return a fresh copy to callers.
    _cache[product_id] = dict(product)
    return dict(product)


def update_product(product_id, **fields):
    """Update product fields in the database and refresh the cache.

    Returns True if the product existed and was updated, False otherwise.

    Invariant: get_product(product_id) must reflect the latest _db state after a successful update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Refresh cache to prevent stale data being served.
    _cache[product_id] = dict(_db[product_id])
    return True


def reset():
    """Clear all data."""
    _db.clear()
    _cache.clear()
