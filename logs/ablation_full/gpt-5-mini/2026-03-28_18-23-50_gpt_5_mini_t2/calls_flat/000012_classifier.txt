## Root Cause
Two related operations: config.create_config() does 'config = DEFAULTS' (returns a module-level dict reference) and middleware.ConfigMiddleware.apply_config() does 'cfg = self._base' followed by 'cfg.update(request_overrides)' (mutating the cached reference). Together these cause shared-state mutation across requests.

## Failure Mechanism
A request with an override (e.g. handle_debug_request calls handle_request({"debug": True})) → middleware.ConfigMiddleware.apply_config sets cfg = self._base (which references DEFAULTS because create_config returned DEFAULTS) → cfg.update({'debug': True}) mutates the shared dict stored in self._base / DEFAULTS → subsequent requests call handle_request() without overrides and receive the mutated value (debug True) instead of the original default (debug False).

## Broken Invariant
create_config() must return a fresh, independent dict and per-request config must not mutate the cached base: after any call with overrides, DEFAULTS['debug'] (and other defaults) must remain equal to the initial factory values (e.g. False for 'debug'). This is testable by calling handle_debug_request() then handle_request() and asserting debug is False in the latter.

## Fix Strategy
Two changes: (1) Make create_config return a shallow copy of DEFAULTS (config = dict(DEFAULTS)) so callers get an independent dict. (2) Ensure ConfigMiddleware.apply_config never mutates the cached base: create a fresh dict from self._base each request (cfg = dict(self._base)) and update that with request_overrides. This breaks the causal chain by preventing any per-request update from mutating shared objects (DEFAULTS or middleware._base).

def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides."""

    if overrides:

def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools.
    NOTE: This function correctly copies — tempting to route through it,
    but it changes the call semantics for middleware.
    """
    result = dict(base)
    result.update(overrides)
    return result


def get_default(key):
    """Read a single default value."""
    return DEFAULTS.get(key)


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


from config import create_config


class ConfigMiddleware:
    """Middleware that loads config once and applies per-request overrides.

    The cached _base is a protected, immutable-by-convention snapshot of defaults.
    apply_config returns a fresh dict per request and never mutates the cached base.
    """

    def __init__(self):
        # create_config now returns a fresh copy, but we still treat _base as immutable.
        self._base = create_config()  # cached at init time

    def apply_config(self, request_overrides=None):
        """Return config for this request, applying any overrides."""
        # Build a fresh dict every request to avoid mutating the cached base.
        cfg = dict(self._base)
        if request_overrides:
            cfg.update(request_overrides)
        return cfg

    def get_timeout(self):
        return self._base.get("timeout", 30)
