# Developer's Reasoning

## Root Cause
In add_entry(), the code inserts the new label into the _labels list at the given position but uses _values.append(value) instead of inserting the corresponding value at the same position in _values. The causal relationship is that add_entry manipulates _labels and _values asymmetrically: _labels.insert(position, label) vs _values.append(value), so the new value is placed at the end of _values rather than aligned with the new label index.

## Failure Mechanism
Given an initial state _labels = ['A','B'], _values = [1,2], calling add_entry('C', 3, position=1) will execute _labels.insert(1,'C') producing ['A','C','B'] but then execute _values.append(3) producing [1,2,3]. As a result, get_entry(1) returns ('C', 2) instead of the expected ('C', 3) and get_all() yields [('A',1),('C',2),('B',3)], showing that labels and values are paired incorrectly because the value for the inserted label ended up at the list end.

## Broken Invariant
For every valid index i, the invariant _labels[i] corresponds to _values[i] must hold. Concretely, after add_entry(label, value, position), get_entry(position) must return (label, value). The current implementation can violate this invariant for inserts with a position argument.

## Fix Strategy
Change the mutation of _values in the positional-insert branch to mirror the mutation of _labels: use _values.insert(position, value) instead of _values.append(value). This ensures that when a label is inserted at index position, its matching value is inserted at the identical index, restoring the element-wise correspondence between _labels and _values.

_values = []


def add_entry(label, value, position=None):
    """Add an entry to the report.

    If position is given, insert at that index.
    Otherwise, append to the end.
    """
    if position is not None:
        _labels.insert(position, label)
        _values.insert(position, value)
    else:
        _labels.append(label)
        _values.append(value)


def get_entry(index):
    """Return (label, value) at the given index."""

    """Return list of (label, value) tuples."""
