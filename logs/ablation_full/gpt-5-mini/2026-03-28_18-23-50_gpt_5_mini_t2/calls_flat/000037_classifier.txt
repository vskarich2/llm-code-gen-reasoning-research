## Root Cause
The bug is in get_host() using the module-level variable _default_host which was set once at import time from _settings (line: _default_host = _settings["host"]). Because _default_host is captured eagerly, subsequent calls to configure(...) that change _settings do not affect _default_host and get_host() continues to return the original import-time value.

## Failure Mechanism
Example scenario: module imported (so _default_host == 'localhost'). Later code calls configure(host='example.com') which updates _settings['host'] but does not change _default_host. A call to get_host() still returns 'localhost' even though get_settings() would show {'host': 'example.com', ...}. The cause-effect chain is: import sets _default_host -> configure mutates _settings but not _default_host -> get_host() returns stale _default_host.

## Broken Invariant
After calling configure(host=<new_host>), get_host() must return <new_host>. This invariant is violated because get_host() returned the original import-time host (e.g., 'localhost') instead of the configured value.

## Fix Strategy
Removed the eagerly-captured _default_host and introduced an explicit _DEFAULT_SETTINGS constant. get_host() now reads the current host from the mutable _settings dict so changes made by configure(...) are immediately visible. reset_settings() was changed to mutate the existing _settings dict (clear() + update(DEFAULTS)) instead of rebinding the global name, preserving any external references to the settings dict. These changes ensure get_host() reflects configure(...) and that reset_settings() reliably restores defaults.

"""Service with lazily-read settings.

This module keeps a single mutable _settings dict. get_host() reads the
current value from that dict so configure(...) and reset_settings()
immediately affect what get_host() returns. reset_settings() mutates the
existing dict rather than rebinding the name so external references to the
settings dict remain valid.
"""

_DEFAULT_SETTINGS = {"host": "localhost", "port": 8080, "debug": False}

# single mutable settings object
_settings = dict(_DEFAULT_SETTINGS)


def get_host():
    """Return the current host setting."""
    return _settings["host"]


def get_settings():
    """Return a copy of the current settings dict."""
    return dict(_settings)


def reset_settings():
    """Reset settings to default values (mutate the existing dict).

    Mutating preserves any external references to the settings dict.
    """
    _settings.clear()
    _settings.update(_DEFAULT_SETTINGS)


def configure(host=None, port=None, debug=None):
    """Update settings.

    Only non-None arguments update the corresponding setting.
    """
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
        _settings["debug"] = debug
