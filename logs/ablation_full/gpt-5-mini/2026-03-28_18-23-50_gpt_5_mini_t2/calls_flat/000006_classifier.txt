# Developer's Reasoning

## Root Cause
config.create_config returns the module DEFAULTS object itself (config = DEFAULTS) rather than a fresh dict, and app.get_settings previously cached that returned object in the _cached_settings global. Because create_config returned a reference to DEFAULTS, the cached value was the exact same dict object; when defaults were changed (e.g. reset_defaults rebinds DEFAULTS to a new dict) or callers mutated the returned dict, the app's cached settings did not reflect the intended current defaults.

## Failure Mechanism
Concrete scenario: 1) At startup get_settings() calls create_config(), which sets _cached_settings to the DEFAULTS dict object. 2) An admin calls reset_defaults(), which reassigns the module-level DEFAULTS variable to a new dict. 3) Subsequent get_settings() returns the previously cached dict (the old DEFAULTS object) because _cached_settings points to the old dict, so callers observe stale values instead of the newly reset defaults. Similarly, apply_overrides() updated the cached dict in-place (settings.update(...)), mutating the same object referenced by DEFAULTS and causing surprising global state changes.

## Broken Invariant
After calling reset_defaults() (or otherwise updating module-level defaults), a subsequent call to get_settings() MUST return settings that reflect the current DEFAULTS. This is testable: call reset_defaults(); then assert get_settings() == create_config() and that values match the newly reset DEFAULTS.

## Fix Strategy
Removed the cache in app.get_settings so settings are constructed fresh on each call, and modified config.create_config to return a shallow copy of DEFAULTS (config = dict(DEFAULTS)). Returning a copy prevents callers from mutating the module DEFAULTS via the returned object, and creating settings each time guarantees get_settings() reflects the current DEFAULTS. clear_cache() is kept as a no-op for compatibility.

    """Return a config dict based on defaults, with optional overrides.

    Always return a shallow copy of DEFAULTS so callers cannot mutate the
    module-level DEFAULTS by accident.
    """
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}
