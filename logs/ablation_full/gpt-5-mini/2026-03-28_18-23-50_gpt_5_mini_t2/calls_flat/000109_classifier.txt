## Root Cause

The causal relationship: compute_raw_stats takes its input to compute raw_min/raw_max/raw_sum, so providing the normalized list instead of the original 'data' causes raw_stats to reflect transformed values rather than the original data.

## Failure Mechanism

The existing pipeline computes raw_stats = compute_raw_stats(cleaned), resulting in {'raw_max': 1.0, 'raw_min': 0.0, 'raw_sum': 1.5}. This is incorrect: the intended raw_stats for the original data should be {'raw_max': 3, 'raw_min': 1, 'raw_sum': 6}. The incorrect call site (compute_raw_stats(cleaned)) is the direct cause of this wrong output.

## Fix Strategy

'''Metrics pipeline: compute raw stats before transforming data.'''

from typing import List, Dict, Sequence


def compute_raw_stats(data: Sequence[float]) -> Dict[str, float]:
    """Compute statistics on raw (untransformed) numeric data.

    Returns a dictionary with keys 'raw_max', 'raw_min', and 'raw_sum'.
    For empty input, returns zeros to match previous behavior.
    """
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {
        "raw_max": max(data),
        "raw_min": min(data),
        "raw_sum": sum(data),
    }


def normalize(data: Sequence[float]) -> List[float]:
    """Normalize numeric data to the 0-1 range.

    If data is empty, returns an empty list. If all values are equal,
    returns a list of 0.5 values (midpoint) to avoid division-by-zero.
    """
    if not data:
        return []
    lo, hi = min(data), max(data)
    if hi == lo:
        return [0.5] * len(data)
    return [(x - lo) / (hi - lo) for x in data]


def pipeline(data: Sequence[float]) -> Dict[str, object]:
    """Run pipeline: compute raw stats on original data, then normalize.

    Important: raw_stats MUST reflect the original (untransformed) data.
    """
    # Compute raw statistics from the ORIGINAL input data.
    raw_stats = compute_raw_stats(data)
    # Then compute the cleaned/normalized representation.
    cleaned = normalize(data)
    return {"raw_stats": raw_stats, "cleaned": cleaned}


def format_report(result: Dict[str, object]) -> str:
    """Format pipeline result for display (keeps original simple behavior)."""
    return f"max={result['raw_stats']['raw_max']}"
