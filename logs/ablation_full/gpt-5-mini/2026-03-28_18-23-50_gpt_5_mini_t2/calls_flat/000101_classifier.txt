## Root Cause
In order_service.place_order the except ValueError: branch re-raises the exception without calling release(product_id, qty). As a result reserve(product_id, qty) in the same function increments inventory._reserved (tracked in inventory._reserved) but release is never called when payment (_process_payment) fails, leaving inventory._reserved permanently increased for that product.

## Failure Mechanism
Concrete scenario: set_gateway_fail(True) causes _process_payment to raise ValueError('payment declined'). place_order(product_id, qty, price) calls reserve(product_id, qty) which increases inventory._reserved[product_id]. When _process_payment raises, the except ValueError block executes and immediately re-raises without releasing the reservation. The reservation remains in inventory._reserved, so inventory.available(product_id) remains decreased even though the order did not complete.

## Broken Invariant
If place_order(product_id, qty, price) raises an exception, then inventory.get_reserved(product_id) must be unchanged from its value before the call. Currently, after a payment failure the reserved count increases by qty and is not rolled back.

## Fix Strategy
Call release(product_id, qty) when payment processing fails, ensuring the reservation is rolled back. Also fix reset() to call inventory.reset() instead of attempting to clear non-existent _stock/_reserved variables in this module. The change in place_order ensures reserve() is undone on any payment exception; the change in reset ensures test resets actually clear the inventory module state.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release
import inventory

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail
    _notifications = []
    _gateway_fail = False
    # Ensure the inventory module state is reset as well
    inventory.reset()


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except Exception:
        # Roll back the inventory reservation on any payment failure
        try:
            release(product_id, qty)
        except Exception:
            # If release itself fails, do not mask the original payment error
            pass
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
