# Developer's Reasoning

## Root Cause
In payment.process_payment the early return when txn_id is found in the module-level _cache causes the function to return the cached result without calling ledger.record. The causal relationship: the if txn_id in _cache branch returns before record(...) is invoked, so duplicate calls never append entries to the ledger's _entries list.

## Failure Mechanism
Concrete scenario: call process_payment('tx1', 100) once — it records {'txn_id': 'tx1', 'amount': 100, 'status': 'charged'} and caches the result. Call process_payment('tx1', 100) a second time — the function hits the if txn_id in _cache branch and returns the cached result immediately, skipping record(...). As a result, the ledger._entries length is 1 but total process_payment calls is 2; verify(2) returns False even though two process_payment calls occurred.

## Broken Invariant
For every invocation of payment.process_payment, regardless of whether txn_id is a duplicate, the ledger must have one corresponding entry. Formally: after N calls to process_payment (across any txn_ids and duplicates), len(_entries) == N must hold.

## Fix Strategy
Ensure record(...) is invoked on every process_payment call. I modified payment.process_payment so that when a duplicate is detected it still calls record(txn_id, 0, 'duplicate') before returning the cached result. Recording amount 0 for duplicate attempts preserves the invariant that ledger entry count equals number of calls while avoiding inflating the charged total. This change eliminates the early-return path that previously skipped ledger.record.

```python
"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # Always record the attempt. For duplicates, record as a zero-amount attempt
    # so the ledger's count reflects number of calls while not inflating charged totals.
    if txn_id in _cache:
        record(txn_id, 0, "duplicate")
        return _cache[txn_id]

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()

```
