# Developer's Reasoning

## Root Cause
In catalog.update_product the local cache is not invalidated: the function calls invalidate_shared(product_id) but omits invalidate_local(product_id). Because api.get_product reads from the local layer first (it calls get_local which returns from cache._local), leaving the local entry intact causes subsequent reads to return stale data.

## Failure Mechanism
Concrete scenario: 1) A request calls api.get_product(id). api.get_product calls get_local(id) which returns a cached dict from cache._local, so the product is served from the local cache. 2) catalog.update_product(id, price=new_price) updates _db[id] and calls invalidate_shared(id) only, removing the entry from cache._shared but not from cache._local. 3) A later request calls api.get_product(id) again: get_local(id) still returns the old dict stored in cache._local (because invalidate_local was never called), so api.get_product returns the stale pre-update product even though the DB and shared cache were updated/invalidated.

## Broken Invariant
The code's documented invariant in catalog.update_product states: "after update, all cache layers must be invalidated." The broken, testable invariant is: after calling catalog.update_product(product_id, ...), both cache._local.get(product_id) and cache._shared.get(product_id) must return None. Currently cache._local.get(product_id) may still return the pre-update value.

## Fix Strategy
Call invalidate_local(product_id) inside catalog.update_product immediately after invalidate_shared(product_id). This change ensures the per-request local layer (cache._local) is cleared when the DB is updated, so subsequent api.get_product calls won't read stale data from the local cache and will instead miss the cache and fetch the updated value (from shared cache or DB). The change is minimal and directly addresses the missing invalidation in update_product.

"""Product catalog with two-layer cache integration."""

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()
