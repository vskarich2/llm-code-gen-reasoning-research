## Root Cause
The bug is in the ROLE_PERMISSIONS mapping and how get_permissions uses it: ROLE_PERMISSIONS is missing an entry for the 'moderator' role, and get_permissions(role) uses ROLE_PERMISSIONS.get(role, set()) so a lookup for 'moderator' falls through to the default empty set. Concretely, the variable ROLE_PERMISSIONS lacks the key 'moderator' and the function get_permissions returns an empty set for that missing key.

## Failure Mechanism
When code checks permissions for a moderator, e.g. has_permission('moderator', 'delete'), execution flows: has_permission -> get_permissions('moderator') -> ROLE_PERMISSIONS.get('moderator', set()) which returns the default empty set because 'moderator' is not present in ROLE_PERMISSIONS; then 'delete' in set() evaluates to False. As a result, legitimate moderator actions are incorrectly denied.

## Broken Invariant
For every defined role R that the system must support, get_permissions(R) must return the configured set of permissions for R (i.e. R must be a key in ROLE_PERMISSIONS). Specifically, 'moderator' must be present in ROLE_PERMISSIONS so that get_permissions('moderator') returns a non-empty set of moderator permissions instead of the default empty set.

## Fix Strategy
Add an explicit 'moderator' entry to ROLE_PERMISSIONS with the intended permissions and make get_permissions return a copy of the stored set (to avoid accidental external mutation). This prevents lookups for 'moderator' from falling through to the empty default and preserves the defined permission set when callers modify the returned value.

```python
"""Access control: map roles to permission sets.

This module defines the permissions granted to each role and provides
helpers to query those permissions.
"""

# Define permission strings used by the application.
PERM_READ = "read"
PERM_WRITE = "write"
PERM_DELETE = "delete"
PERM_MANAGE_USERS = "manage_users"

# Map roles to their permission sets. The mapping must include all
# roles the application expects to handle.
ROLE_PERMISSIONS = {
    "admin": {PERM_READ, PERM_WRITE, PERM_DELETE, PERM_MANAGE_USERS},
    "user": {PERM_READ, PERM_WRITE},
    "moderator": {PERM_READ, PERM_DELETE},  # explicit moderator entry
}


def get_permissions(role):
    """Return a fresh set of permissions for the given role.

    If the role is unknown, return an empty set. A copy is returned so
    callers cannot mutate the canonical ROLE_PERMISSIONS mapping.
    """
    perms = ROLE_PERMISSIONS.get(role)
    return set(perms) if perms is not None else set()


def has_permission(role, action):
    """Check whether a role has a specific permission.

    This delegates to get_permissions so unknown roles yield False for
    any action.
    """
    return action in get_permissions(role)

```
