The missing assignment to user['full_name'] in the first_name branch causes full_name to diverge from the component name fields.

## Failure Mechanism
Example: starting user = {'first_name': 'Alice', 'last_name': 'Smith', 'full_name': 'Alice Smith', 'email': 'a@example.com'}. Calling update_profile(user, {'first_name': 'Alicia'}) runs the first_name branch, calls sanitize_string and validate_name, sets user['first_name'] = 'Alicia' but leaves user['full_name'] unchanged. The returned user becomes {'first_name': 'Alicia', 'last_name': 'Smith', 'full_name': 'Alice Smith', ...}, so full_name no longer equals first_name + ' ' + last_name.

## Broken Invariant
After update_profile(user, changes) returns, the invariant full_name == first_name + ' ' + last_name may be broken. Specifically, there exist inputs (e.g., changes containing a valid 'first_name' but not 'last_name') that cause user['full_name'] != user['first_name'] + ' ' + user['last_name'].

## Fix Strategy
Recompute user['full_name'] immediately after any successful change to either first_name or last_name. I added assignments that set user['full_name'] = user['first_name'] + ' ' + user['last_name'] in both the first_name and last_name branches. This ensures the invariant is restored regardless of which name field was changed (and works correctly if both are changed sequentially in the same updates dict).

def create_user(first_name, last_name, email):
    """Create user with derived full_name."""
    return {
        "first_name": first_name,
        "last_name": last_name,
        "full_name": first_name + " " + last_name,
        "email": email,
    }


def update_profile(user, changes):
    """Update profile fields. full_name must stay in sync.

    Invariant: full_name == first_name + ' ' + last_name
    """
    for key, value in changes.items():
        value = sanitize_string(value)
        if key == "first_name" and validate_name(value):
            user["first_name"] = value
            # Recompute full_name after first_name change
            user["full_name"] = user["first_name"] + " " + user["last_name"]
        elif key == "last_name" and validate_name(value):
            user["last_name"] = value
            # Recompute full_name after last_name change
            user["full_name"] = user["first_name"] + " " + user["last_name"]
        elif key == "email":
            user["email"] = value
    return user
