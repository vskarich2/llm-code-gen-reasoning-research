# Developer's Reasoning

## Root Cause
The bug is in worker.process_batch: the parameter seen is defined with a mutable default value seen=set(). Because default argument expressions are evaluated once at function definition time, the single set object is shared across all calls to process_batch, causing entries added during one call to remain in seen for subsequent calls.

## Failure Mechanism
Concrete scenario: first call process_batch([create_task('a')]) uses the default seen set, adds 'a' to that shared set and returns [{'name': 'a', 'result': 'processed'}]. A later call process_batch([create_task('a')]) (caller omitted the seen argument again) checks if 'a' is in the same shared seen set, finds it, and skips processing, returning an empty list. The causal chain is: default seen=set() -> same set reused -> previously added task IDs remain -> valid tasks in new batches are skipped as duplicates.

## Broken Invariant
If the caller does not supply the seen argument, each independent call process_batch(tasks) must process every task in tasks. Formally: for any tasks list, calling process_batch(tasks) with seen omitted must return a results list whose length equals len(tasks).

## Fix Strategy
Change the default value of seen from a mutable set to None and create a fresh set inside the function when seen is None. This ensures a new, empty seen set is used for each call that doesn't explicitly provide one, preventing cross-call state leakage. Concretely, replaced the function signature seen=set() with seen=None and added: if seen is None: seen = set().

"""Worker that processes task batches."""

from queue import create_task


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results

    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
