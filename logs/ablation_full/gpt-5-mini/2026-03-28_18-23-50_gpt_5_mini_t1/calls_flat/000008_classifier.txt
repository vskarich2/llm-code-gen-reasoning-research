# Developer's Reasoning

## Root Cause
config.create_config uses assignment `config = DEFAULTS` which binds the local variable `config` to the module-level dict `DEFAULTS`; subsequent `config.update(...)` (or any caller mutating the returned dict) therefore mutates DEFAULTS and the cached settings in app._cached_settings.

## Failure Mechanism
create_config returns a direct reference to DEFAULTS → caller or app.apply_overrides mutates the returned dict (via dict.update) → DEFAULTS is mutated in-place and the cached settings object in app._cached_settings now reflects those mutations → future calls to create_config or get_settings that expect original defaults observe mutated/stale data (e.g., timeout changed), causing incorrect behavior.

## Broken Invariant
create_config() must return a new independent dict equal to DEFAULTS but not the same object: create_config() is expected to satisfy `create_config() is not DEFAULTS` and `create_config() != create_config()` may be False but `create_config() is not create_config()` should be True (i.e., two calls produce distinct dict objects). This invariant is violated because currently `create_config() is DEFAULTS`.

## Fix Strategy
Change create_config to return a fresh deep copy of DEFAULTS (use copy.deepcopy) so returned config is independent of the module-level DEFAULTS. This breaks the causal chain because updates to the returned dict will mutate only the copy, not DEFAULTS, and cached settings will no longer unintentionally alter DEFAULTS for future create_config calls.

DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides.

    Returns a deep copy of DEFAULTS so callers can mutate the returned dict
    without affecting the module-level DEFAULTS or other callers.
    """
    # Make a deep copy to avoid returning a reference to DEFAULTS
    config = copy.deepcopy(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result
