## Root Cause
service.update_record calling cache_invalidate(key) immediately before cache_set(key, value) (operation sequence: cache_invalidate -> cache_set). The redundant cache_invalidate call creates an unnecessary mutation of the cache state that can widen a race window where another actor may write a newer cache value which can then be overwritten by the following cache_set.

## Failure Mechanism
update_record: cache_invalidate(key) → cache entry removed (mutation) → time window exists before cache_set executes → concurrent writer B performs db_write('records', key, new_value) and cache_set(key, new_value) (propagation) → original update_record's subsequent cache_set(key, old_value) runs and overwrites B's newer cache value → read_record returns stale/older value (observable failure).

## Broken Invariant
After update_record(key, value) returns, read_record(key) should return value (testable: call update_record(k,v); then read_record(k) must equal v). This property can be violated when cache_invalidate + cache_set create a race window allowing other writers to set a newer value which is then overwritten.

## Fix Strategy
Change update_record to write to the database and then set the cache directly (db_write(...); cache_set(key, value)), removing any invalidation before the set. This breaks the causal chain of 'invalidate → window → overwrite of newer cache' by eliminating the explicit removal step that created a small but exploitable gap between removing a cache entry and restoring it. The change reduces unnecessary operations and the invalidation step that served no purpose when a set follows immediately.

from cache import cache_set, cache_get, cache_invalidate, cache_get_version, cache_conditional_set


def update_record(key, value):

    # Set the cache directly to the new value.
    # Removing an explicit cache_invalidate before cache_set avoids an unnecessary

    if cached is not None:
        return cached
    val = db_read("records", key)
    if val is not None:
        cache_set(key, val)
    return val
