# Developer's Reasoning

## Root Cause
In add_entry(), when a position is provided the code inserts the label into the _labels list but appends the value to the _values list. Concretely the function calls _labels.insert(position, label) but then calls _values.append(value) instead of _values.insert(position, value), so the two parallel lists diverge.

## Failure Mechanism
Example sequence: add_entry('a', 1) -> labels ['a'], values [1]; add_entry('b', 2) -> labels ['a','b'], values [1,2]; add_entry('c', 3, position=1) runs _labels.insert(1,'c') producing ['a','c','b'] but uses _values.append(3) producing [1,2,3]. As a result get_all() returns list(zip(labels, values)) => [('a',1), ('c',2), ('b',3)] instead of the expected [('a',1), ('c',3), ('b',2)]. The misalignment is introduced exactly because values were appended instead of inserted at the provided position.

## Broken Invariant
The module promises that labels and values are stored in parallel such that for every valid index i, _labels[i] corresponds to the associated value _values[i]. Equivalently, len(_labels) == len(_values) and get_entry(i) returns the (label, value) pair that was inserted at index i. The current implementation can violate this invariant after an add_entry call with a non-None position.

## Fix Strategy
Change add_entry so that when a position is provided it performs the same insert operation on both _labels and _values. I replaced the incorrect _values.append(value) with _values.insert(position, value) and added a small type check for position to ensure callers pass an int or None. This prevents the divergent modification sequence that caused the two lists to go out of sync, restoring the parallel-list invariant.

```python
"""Report builder with parallel label/value arrays.

This module stores labels and values in parallel lists. add_entry inserts
both lists consistently so that get_entry and get_all return aligned
(label, value) pairs.
"""

from typing import List, Optional, Tuple

_labels: List[str] = []
_values: List[object] = []


def add_entry(label: str, value: object, position: Optional[int] = None) -> None:
    """Add an entry to the report.

    If position is given (an int), insert the (label, value) pair at that
    index in both internal lists. If position is None, append to the end.

    Raises TypeError if position is not an int or None.
    """
    if position is None:
        _labels.append(label)
        _values.append(value)
    else:
        if not isinstance(position, int):
            raise TypeError("position must be an int or None")
        # Ensure both lists are modified the same way to keep them aligned.
        _labels.insert(position, label)
        _values.insert(position, value)


def get_entry(index: int) -> Tuple[str, object]:
    """Return (label, value) at the given index."""
    return (_labels[index], _values[index])


def get_all() -> List[Tuple[str, object]]:
    """Return list of (label, value) tuples."""
    return list(zip(_labels, _values))


def count() -> int:
    """Return the number of entries."""
    return len(_labels)


def reset() -> None:
    """Clear all entries."""
    _labels.clear()
    _values.clear()

```
