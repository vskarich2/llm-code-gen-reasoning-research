## Root Cause
The bug is in retry_send(msg, max_retries): the conditional handling of the send() result is inverted. The code uses 'if not result: continue', which means that when send() returns True (success) the loop does not break and the function keeps calling send() again, causing duplicate sends. Additionally, clear_log() is a no-op (pass) so the sent log can't be cleared via that function.

## Failure Mechanism
Example: reset() sets _sent = []. Calling retry_send('hello', max_retries=3) will run the loop three times because send('hello') returns True each time and the loop does not exit on success. Each send() appends 'hello' to the module-level list _sent, so after the call get_sent() returns ['hello', 'hello', 'hello'] instead of the expected ['hello']. Also calling clear_log() does nothing because it is pass.

## Broken Invariant

## Fix Strategy
Change retry_send to stop retrying when send() returns True and only retry on failure. Concretely, iterate attempts 1..max_retries and return True immediately on a successful send; return False only if all attempts failed. Implement clear_log() to clear the _sent list (delegate to reset()). These changes prevent duplicate sends by breaking out on success and allow clearing the log via clear_log().

"""Message sender with retry logic."""

_sent = []


def reset():
    global _sent
    _sent = []


def send(msg):
    """Send a message. Always succeeds. Appends to _sent."""
    _sent.append(msg)
    return True


def retry_send(msg, max_retries=2):
    """Attempt to send up to max_retries times.

    Stop and return True on the first successful send. If all attempts fail,
    return False. max_retries must be >= 1.
    """
    if max_retries < 1:
        raise ValueError("max_retries must be >= 1")

    for attempt in range(1, max_retries + 1):
        result = send(msg)
        if result:
            # success: stop retrying
            return True
        # failure: will retry until attempts exhausted
    return False


def get_sent():
    return list(_sent)


def clear_log():
    """Utility to clear the log for display purposes."""
    reset()
