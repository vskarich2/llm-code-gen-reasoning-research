# Developer's Reasoning

## Root Cause
In auth.py the dispatch dictionary _ROLE_DISPATCH omits the "guest" key, so the variable _ROLE_DISPATCH does not map the role name "guest" to the function guest_access. Because get_access looks up handlers with _ROLE_DISPATCH.get(role, _default_access), the missing key causes the lookup to return _default_access instead of guest_access.

## Failure Mechanism
When code calls get_access("guest") or can_read("guest"), get_access performs handler = _ROLE_DISPATCH.get(role, _default_access). Because "guest" is not present in _ROLE_DISPATCH, handler becomes _default_access. get_access() then returns _default_access() which is {"read": False, "write": False, "delete": False}. As a concrete effect, can_read("guest") returns False even though roles.guest_access() would return {"read": True, "write": False, "delete": False}. The missing dispatch entry therefore causes guest users to receive no access instead of read-only access.

## Broken Invariant
For every role function defined in roles.py (admin_access, user_access, moderator_access, guest_access), get_access(role_name) must return that function's access dict. Specifically, get_access("guest") should return {"read": True, "write": False, "delete": False}. This invariant is violated because _ROLE_DISPATCH lacks the "guest" entry.

## Fix Strategy
Add the missing mapping "guest": guest_access to _ROLE_DISPATCH in auth.py. This ensures that _ROLE_DISPATCH.get(role, _default_access) returns guest_access for role == "guest", so get_access("guest") returns guest_access() and can_read("guest") becomes True. The change is minimal, localized to the dispatch table and directly addresses the lookup failure described above.

# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {

    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access,
}

    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)
