## Root Cause
In place_order, the except ValueError block re-raises the wallet.charge error without calling inventory.release(qty). The problematic code is the bare except ValueError: raise inside place_order, which prevents the inventory reservation from being released when wallet.charge fails.

## Failure Mechanism
If a caller calls place_order(inventory, wallet, qty, price) and wallet.balance < qty * price, wallet.charge raises ValueError. The except ValueError handler immediately re-raises that ValueError without calling inventory.release(qty). As a result inventory.reserved remains incremented by qty even though the order did not complete. Subsequent calls see reduced inventory.available() and may incorrectly raise 'insufficient stock' even though the item was never sold.

## Broken Invariant
After place_order returns with an exception, inventory.reserved must be the same as before the call (i.e., place_order must not leave a lasting reservation when it fails). The current code can leave inventory.reserved increased by qty when wallet.charge raises ValueError.

## Fix Strategy
Ensure that any failure during payment releases the previously made inventory reservation. I refactored place_order to reserve first, then attempt wallet.charge inside a try/except. On any exception raised while charging, the code now calls inventory.release(qty) before re-raising the exception. On success it returns the confirmed order. Using except Exception ensures release occurs for any unexpected errors from wallet.charge, preserving the invariant that failed orders do not leave reservations.

# Code Produced
```python
"""Order fulfillment with inventory and wallet."""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release on failure.

    Guarantees that if charging the wallet fails (for any exception),
    the prior inventory reservation is released so that inventory state
    is not left inconsistent.
    """
    inventory.reserve(qty)
    try:
        wallet.charge(qty * price)
    except Exception:
        # Ensure we don't leave a reservation on any failure during charging.
        inventory.release(qty)
        raise
    else:
        return {"status": "confirmed", "qty": qty, "total": qty * price}

```
