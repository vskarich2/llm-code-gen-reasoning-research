## Root Cause
In code_snippets_v2/lazy_init_a/service.py the module-level variable _default_host is set once at import time from _settings by the line _default_host = _settings["host"]. The function get_host() returns that captured _default_host value, so it never reflects subsequent updates to the mutable _settings mapping.

## Failure Mechanism
When client code calls configure(host='example.com'), configure updates _settings['host'] but does not change _default_host. Because get_host() returns the stale _default_host captured at import time, calls to get_host() continue to return 'localhost' (the original value) instead of the newly configured 'example.com'. Example sequence: import service (sets _default_host == 'localhost'); service.configure(host='example.com') (updates _settings['host'] to 'example.com'); service.get_host() still returns 'localhost' because it reads _default_host, not _settings.

## Broken Invariant
After calling configure(host=NEW_HOST), get_host() should return NEW_HOST. Concretely: service.configure(host='example.com'); assert service.get_host() == 'example.com'. This invariant is violated because get_host() returns the stale _default_host captured at import time.

## Fix Strategy
Removed the eagerly captured _default_host and introduced a DEFAULT_SETTINGS constant. Initialize _settings from DEFAULT_SETTINGS.copy() and reset_settings reassigns _settings = DEFAULT_SETTINGS.copy(). get_host() now returns the current value from _settings['host']. Using a DEFAULT_SETTINGS copy prevents accidental aliasing. These changes ensure get_host() reads live state so updates made by configure() and reset_settings() are visible.

# Mutable runtime settings initialised from the defaults

    """Return the current host setting."""

    """Return the current settings dict."""
    return dict(_settings)


def reset_settings():
    """Reset settings to the default values (e.g., for testing)."""
    global _settings
    _settings = DEFAULT_SETTINGS.copy()


def configure(host=None, port=None, debug=None):
    """Update settings."""
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
