# Developer's Reasoning

## Root Cause
In create_config, the line config = DEFAULTS assigns the DEFAULTS dictionary by reference to the local variable config. Because config is the same object as DEFAULTS, subsequent config.update(overrides) mutates the module-level DEFAULTS instead of producing an independent configuration dictionary.

## Failure Mechanism
If a caller calls create_config({'debug': True}), the function sets config = DEFAULTS (an alias), then calls config.update({'debug': True}). That update writes debug=True into the module-level DEFAULTS object. Future calls to create_config() (without overrides) will return dictionaries that already have debug=True, so overrides leak into global defaults. Example: DEFAULTS['debug'] is False initially; after create_config({'debug': True}) it becomes True unexpectedly.

## Broken Invariant
Calling create_config(overrides) must not mutate the module-level DEFAULTS. Formally: after any call create_config(overrides), the expression DEFAULTS == {'timeout': 30, 'retries': 3, 'debug': False} must hold unless reset_defaults() was explicitly called to change DEFAULTS.

## Fix Strategy
create_config now returns a shallow copy of the defaults (config = DEFAULTS.copy()) so updates apply only to the returned dict. Additionally, DEFAULTS is initialized from an internal _BASE_DEFAULTS template and reset_defaults() reassigns DEFAULTS to a fresh copy of that template. These changes prevent aliasing between returned configs and the module-level defaults and make reset explicit.

# Code Produced
```python
 _BASE_DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}

# PUBLIC default configuration exported by the module. It is a separate
# copy of the base template so callers can read it, and reset_defaults
# can restore it from the canonical template.
DEFAULTS = _BASE_DEFAULTS.copy()


def create_config(overrides=None):
    """Return a new config dict based on DEFAULTS, with optional overrides.

    The returned dict is a shallow copy and can be modified by the
    caller without affecting the module-level DEFAULTS.
    """
    config = DEFAULTS.copy()
    if overrides:
        config.update(overrides)
    return config


def reset_defaults():
    """Restore DEFAULTS to the canonical base values.

    This reassigns the module-level DEFAULTS to a fresh copy of
    _BASE_DEFAULTS so subsequent create_config calls start from
    the original factory values.
    """
    global DEFAULTS
    DEFAULTS = _BASE_DEFAULTS.copy()

```
