# Developer's Reasoning

## Root Cause
In process_batch(items) the call to snapshot() is placed after the for-loop, so snapshot() (which appends the current _counter to _snapshots) is executed only once per batch instead of once per item. The causal relationship is: process_batch increments _counter for each item, but because snapshot() is called once at the end, _snapshots grows by 1 regardless of how many items were processed.

## Failure Mechanism
For example, calling process_batch([1, 2, 3]) runs the loop and increases _counter by 1, then 2, then 3 (ending with _counter += 6), and then snapshot() appends a single value (6) to _snapshots. As a result, len(_snapshots) becomes 1 even though three items were processed. This breaks any logic expecting one snapshot per item and makes verify_consistency() (which previously returned len(_snapshots)) unable to assert the per-item snapshot invariant.

## Broken Invariant
After processing N items across all calls to process_batch, the number of recorded snapshots (len(_snapshots)) must equal the number of processed items (_processed_count). Concretely: for any history of calls, len(_snapshots) == _processed_count must hold.

## Fix Strategy
Call snapshot() once for each processed item by moving the snapshot() invocation inside the per-item loop in process_batch and track the total number of processed items with a new _processed_count variable. Also make verify_consistency() explicitly compare _processed_count to len(_snapshots). These changes ensure a snapshot is recorded for each item processed and make the invariant check explicit.

 """Batch processor with per-item snapshots.

This module maintains a running counter and a list of snapshots of that
counter. Each processed item should produce one snapshot recorded after
its contribution to the counter.
"""

_counter = 0
_snapshots = []
_processed_count = 0


def reset():
    """Reset the module state: counter, snapshots, and processed count."""
    global _counter, _snapshots, _processed_count
    _counter = 0
    _snapshots = []
    _processed_count = 0


def snapshot():
    """Record the current counter value as a snapshot."""
    _snapshots.append(_counter)


def get_snapshots():
    """Return a shallow copy of the snapshots list."""
    return list(_snapshots)


def process_batch(items):
    """Process each item: increment counter and record a snapshot per item.

    For every item in the iterable items, add the item to the running
    _counter, then record a snapshot of the updated counter. Returns the
    updated counter value.
    """
    global _counter, _processed_count
    for item in items:
        _counter += item
        # Record a snapshot AFTER processing each individual item.
        snapshot()
        _processed_count += 1
    return _counter


def verify_consistency():
    """Verify that there is exactly one snapshot per processed item.

    Returns True when the number of snapshots equals the number of
    processed items, otherwise False.
    """
    return _processed_count == len(_snapshots)
