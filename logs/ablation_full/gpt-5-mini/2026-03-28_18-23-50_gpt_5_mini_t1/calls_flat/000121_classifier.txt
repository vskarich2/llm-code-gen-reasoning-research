# Developer's Reasoning

## Root Cause
The ROLE_PERMISSIONS dictionary in permissions.py does not contain a key for the "moderator" role. The functions get_permissions(role) and has_permission(role, action) rely on ROLE_PERMISSIONS.get(role, set()), so when role == 'moderator' the lookup falls back to the empty set. In other words, the missing key in the ROLE_PERMISSIONS mapping causes get_permissions to return an empty set for 'moderator'.

## Failure Mechanism
Concrete scenario: code calls has_permission('moderator', 'delete'). has_permission delegates to get_permissions('moderator'), which executes ROLE_PERMISSIONS.get('moderator', set()). Because 'moderator' is not present in ROLE_PERMISSIONS, get() returns the fallback empty set. has_permission then evaluates 'delete' in set(), which is False, so the caller incorrectly concludes the moderator lacks the 'delete' permission. The chain is: has_permission -> get_permissions -> ROLE_PERMISSIONS.get(..., set()) -> empty set -> membership test fails.

## Broken Invariant
The codebase expects configured roles to be present in ROLE_PERMISSIONS and for get_permissions(role) to return the intended permission set for known roles. Specifically, for the 'moderator' role the invariant is: 'moderator' in ROLE_PERMISSIONS and get_permissions('moderator') must return a set containing 'delete' (i.e., 'delete' in get_permissions('moderator') is True). This is a concrete, testable statement that currently fails.

## Fix Strategy
I added an explicit 'moderator' entry to ROLE_PERMISSIONS with the intended permissions (including 'delete'), so ROLE_PERMISSIONS.get('moderator', set()) now returns the correct permission set instead of the empty fallback. I also made get_permissions return an immutable frozenset to prevent accidental external mutation and added KNOWN_ROLES and is_known_role() helpers so callers can check configuration completeness. These changes directly address the missing mapping that caused the fallback empty set and make the role-permission mapping clearer and safer.

    """Check whether a role has a specific permission."""
