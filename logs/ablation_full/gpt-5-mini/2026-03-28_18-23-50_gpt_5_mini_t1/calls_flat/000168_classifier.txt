## Root Cause
The bug is in the function is_enabled which uses FLAGS.get(flag_name, False). Callers pass camelCase names like 'darkMode' but FLAGS contains snake_case keys like 'dark_mode', so FLAGS.get receives a mismatched key and returns the provided default False. In short: is_enabled + FLAGS.get(flag_name, False) causes a silent false negative when flag_name is camelCase.

## Failure Mechanism
Example: FLAGS contains 'dark_mode': True. A caller calls is_enabled('darkMode'). is_enabled passes 'darkMode' directly to FLAGS.get('darkMode', False). Because 'darkMode' is not a key in FLAGS, .get returns the default False, so the caller receives False even though the intended flag 'dark_mode' is True.

## Broken Invariant
If FLAGS contains a truthy value for a flag (e.g. FLAGS['dark_mode'] is True), then calling is_enabled with an equivalent camelCase or snake_case name (e.g. is_enabled('darkMode') or is_enabled('dark_mode')) should return True. The original code violated this: is_enabled('darkMode') returned False despite FLAGS['dark_mode'] being True.

## Fix Strategy
I normalized incoming flag names to snake_case with a new helper _to_snake_case and stopped using dict.get with a silent default. is_enabled now (1) validates the input, (2) converts camelCase to snake_case, (3) checks membership explicitly in FLAGS, and (4) raises a KeyError for unknown flags. This prevents silent false negatives (removing the FLAGS.get(..., False) default) and ensures camelCase callers correctly map to the existing snake_case keys.

```python
import re

"""Feature flag system with snake_case keys.

This module accepts either snake_case or camelCase flag names when checking
flags. Unknown flags now raise KeyError instead of silently returning False,
so callers get explicit feedback on misspelled or missing flags.
"""

FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def _to_snake_case(name):
    """Convert a flag name to snake_case.

    Accepts names already in snake_case or in camelCase / PascalCase. Also
    normalizes dashes to underscores and strips surrounding whitespace.

    Raises ValueError for empty strings and TypeError for non-strings.
    """
    if not isinstance(name, str):
        raise TypeError("flag_name must be a string")

    s = name.strip()
    if not s:
        raise ValueError("flag_name must not be empty")

    # If it already contains underscores, treat it as snake_case and normalize
    if "_" in s:
        return s.lower()

    # Convert CamelCase or camelCase to snake_case using regex:
    # -> insert underscore between lowercase/number and uppercase boundaries
    s1 = re.sub(r'(.)([A-Z][a-z]+)', r'\1_\2', s)
    snake = re.sub(r'([a-z0-9])([A-Z])', r'\1_\2', s1)
    snake = snake.replace('-', '_').lower()
    return snake


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Args:
        flag_name: the flag key to look up (snake_case or camelCase)

    Returns:
        True if the flag is enabled, False if it exists and is falsy.

    Raises:
        TypeError: if flag_name is not a string.
        ValueError: if flag_name is an empty string.
        KeyError: if the normalized flag name does not exist in FLAGS.
    """
    # Validate and normalize the incoming name to the canonical snake_case
    snake = _to_snake_case(flag_name)

    if snake not in FLAGS:
        available = ", ".join(sorted(FLAGS.keys()))
        raise KeyError(
            f"Unknown feature flag '{flag_name}' (normalized: '{snake}'). "
            f"Available flags: {available}"
        )

    return bool(FLAGS[snake])


def list_flags():
    """Return all flag names as a new list (preserve insertion order).

    Callers should treat this list as read-only.
    """
    return list(FLAGS.keys())

```
