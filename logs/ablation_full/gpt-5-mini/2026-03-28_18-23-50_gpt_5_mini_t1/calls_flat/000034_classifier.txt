# Developer's Reasoning

## Root Cause
In catalog.update_product, after mutating the database _db the function calls invalidate_shared(product_id) but does not call invalidate_local(product_id). The API layer's get_product first calls cache.get_local(product_id) (which reads from the module-level _local dict). Because invalidate_local is never invoked, the stale entry remains in _local and get_product returns the old value.

## Failure Mechanism
Concrete scenario: 1) A client calls api.get_product('p1'); get_product checks get_local('p1') -> miss, then get_shared('p1') -> miss, then db_get('p1') -> returns DB row and api.put_local('p1') stores it in the _local dict. 2) Someone calls catalog.update_product('p1', price=NEW). update_product updates _db['p1'] and calls invalidate_shared('p1') but does not call invalidate_local('p1'), so the _local entry remains unchanged. 3) A subsequent client call to api.get_product('p1') finds get_local('p1') returns the stale dictionary from _local and returns it immediately, never touching shared or DB. The result is that the API returns the old price despite the DB having been updated.

## Broken Invariant
After a successful update_product(product_id, ...), both cache layers must be cleared for that product id. Formally: for any product_id present in _db, if update_product(product_id, ...) returns True, then cache.get_local(product_id) is None and cache.get_shared(product_id) is None (equivalently, api.get_product(product_id) must return the updated DB values, not pre-update values).

## Fix Strategy
Call invalidate_local(product_id) in update_product immediately after updating the DB (in addition to the existing invalidate_shared call). This ensures the per-request local cache (_local) no longer contains the stale object; subsequent api.get_product(product_id) will miss local, miss shared (already invalidated), and read fresh data from db_get, then repopulate caches with the updated value.

"""Product catalog with two-layer cache integration."""

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()
