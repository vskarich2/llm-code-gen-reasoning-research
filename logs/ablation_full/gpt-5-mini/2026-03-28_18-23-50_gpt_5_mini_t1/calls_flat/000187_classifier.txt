# Developer's Reasoning

## Root Cause
The bug is in api.py: the checkout function declares the parameter use_new_pricing but never uses it. Because checkout doesn't set the feature flag, pricing.compute_price (in pricing.py) continues to read the global flag via flags.is_enabled("new_pricing") and therefore ignores the caller's intent.

## Failure Mechanism
If a caller calls checkout(customer, items, use_new_pricing=True), checkout currently just calls create_invoice(customer, items) without toggling the feature flag. compute_price(base, qty) in pricing.py checks is_enabled("new_pricing") and will still see the global flag value (default False in flags._flags), so invoices are produced with v1 pricing even though the caller requested new pricing. This manifests as invoices with pricing_version "v1" and no discounts applied for bulk when use_new_pricing=True.

## Broken Invariant
Calling checkout(..., use_new_pricing=True) must result in invoices whose pricing_version is "v2" (and whose computed prices reflect v2 rules). Currently checkout(..., use_new_pricing=True) does not guarantee that the returned invoice's pricing_version is "v2".

## Fix Strategy
Make checkout actually toggle the global feature flag around the call to create_invoice so compute_price (which calls flags.is_enabled("new_pricing")) observes the requested value. The code saves the previous flag state, sets new_pricing according to use_new_pricing, calls create_invoice, and then restores the previous flag to avoid side effects. This ensures compute_price sees the requested flag value during invoice creation while preserving global flag state afterwards.


# Task Description

# Code Produced
```python
from billing import create_invoice, get_invoices
from flags import enable, disable, is_enabled


def checkout(customer, items, use_new_pricing=False):
    # Save previous flag state so we can restore it after creating the invoice
    previous = is_enabled("new_pricing")

    # Apply requested pricing flag for this checkout
    if use_new_pricing:
        enable("new_pricing")
    else:
        disable("new_pricing")

    try:
        invoice = create_invoice(customer, items)
    finally:
        # Restore previous value to avoid global side effects
        if previous:
            enable("new_pricing")
        else:
            disable("new_pricing")

    return invoice

    return get_invoices()
```
