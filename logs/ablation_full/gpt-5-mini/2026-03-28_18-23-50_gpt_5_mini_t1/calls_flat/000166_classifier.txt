## Root Cause
Report.insert_column: missing update to self.column_widths after inserting a header and inserting values into each row (no .insert or equivalent on self.column_widths), causing the three parallel arrays to become unsynchronized.

## Failure Mechanism
Caller invokes Report.insert_column(position, header, default_value) → headers list has header inserted and every row gets a new element (row.insert(position, default_value)) → column_widths remains at its previous length because there is no insertion into self.column_widths → invariant len(headers) == len(column_widths) is violated → validate_table detects header/width count mismatch (len(headers) != len(widths)) or format_table indexing into widths for header parts raises IndexError / misalignment → rendering/validation breaks.

## Broken Invariant
For a Report instance, len(self.headers) == len(self.column_widths) must hold at all times; after insert_column this property is violated (testable by calling report.validate() which will return (False, 'header/width count mismatch') or by accessing widths[ i ] in format_table for i in range(len(headers))).

## Fix Strategy
Modify Report.insert_column to update self.column_widths in sync with the headers and rows. After inserting the header and inserting the default_value into each existing row, compute an appropriate width for the new column and insert that width into self.column_widths at the same position. The width is chosen as max(len(header), max(len(str(row[position])) for each row)) so it accounts for the header text and the actual inserted cell values. This breaks the causal chain by ensuring the three parallel arrays (headers, rows, column_widths) remain the same length and column widths reflect the newly inserted column's content, preventing validate_table/format_table failures.

"""Report with headers, rows, and column widths."""

from data import make_row, validate_table
from formatter import format_table, recalculate_widths


class Report:
    """A table with synchronized headers, rows, and column widths."""

    def __init__(self, headers, default_width=10):
        self.headers = list(headers)
        self.rows = []
        self.column_widths = [default_width] * len(headers)

    def add_row(self, *values):
        """Add a row, padding to match current column count."""
        row = make_row(values, len(self.headers))
        self.rows.append(row)

    def insert_column(self, position, header, default_value=""):
        """Insert a new column at the given position.

        Must update headers, every row, AND column_widths
        to keep all three arrays in sync.
        """
        self.headers.insert(position, header)
        for row in self.rows:
            row.insert(position, default_value)
        # Update column_widths so it stays in sync with headers and rows.
        # Compute a width that fits the header and any existing values in the
        # newly inserted column. If there are no rows, use the header length.
        if self.rows:
            # Use max length among header and all row values at position
            new_width = max(len(header), max(len(str(r[position])) for r in self.rows))
        else:
            new_width = len(header)
        self.column_widths.insert(position, new_width)

    def render(self):
        """Render the table using the formatter."""
        return format_table(self.headers, self.rows, self.column_widths)

    def validate(self):
        """Validate internal consistency."""
        return validate_table(self.headers, self.rows, self.column_widths)

    def column_count(self):
        """Return number of columns."""
        return len(self.headers)
