# Developer's Reasoning

## Root Cause
In payment.process_payment the early return on duplicates (the if txn_id in _cache: return _cache[txn_id] branch) prevents calling ledger.record(). The variable _cache is used to detect duplicates, but returning immediately when a transaction is cached skips the ledger.record(txn_id, amount, status) call that increments _entries.

## Failure Mechanism
If process_payment('tx1', 100) is called once, record() appends one entry. On a second call process_payment('tx1', 100) the function hits the early-return branch because txn_id is in _cache and returns the cached result without calling record() again. As a result, only one ledger entry exists though process_payment was called twice, so verify(2) will be False and summary count will be 1 while two calls occurred.

## Broken Invariant
For every call to process_payment, including duplicate txn_id calls, the ledger must have one corresponding entry: after N calls to process_payment(…), verify(N) must return True.

## Fix Strategy
Ensure every call to process_payment records an entry before returning, even for duplicates. I removed the early-return and instead, when txn_id is cached, retrieve the cached result and call record(txn_id, amount, status) with the cached result's amount and status before returning. This guarantees _entries is appended on every invocation and preserves cached results.

```python
"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # On duplicate, still record the call in the ledger and return cached result
    if txn_id in _cache:
        result = _cache[txn_id]
        # record the duplicate call using the same amount and status as the cached result
        record(result["txn_id"], result["amount"], result["status"])
        return result

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()

```
