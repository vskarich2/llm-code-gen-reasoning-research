# Developer's Reasoning

## Root Cause
In Report.delete_column the code deletes an entry from self.headers (del self.headers[index]) but does not remove the corresponding element from each row in self.rows. The function operates only on the headers list and never mutates the lists stored in self.rows, so header and row positions become inconsistent.

## Failure Mechanism
Example: headers = ['a','b','c'] and rows = [[1,2,3]]. Calling delete_column(1) removes header 'b' leaving headers = ['a','c'] while rows remain [[1,2,3]]. Later render() builds dict(zip(self.headers, row)) which produces {'a':1, 'c':2} — the value 2 (originally for 'b') is now mapped to header 'c', causing silent misalignment of columns.

## Broken Invariant
After Report.delete_column(index) returns, for every row in report.rows the invariant len(row) == len(report.headers) must hold. Currently this is violated because headers are shortened but rows are not updated.

## Fix Strategy
Modify Report.delete_column to remove the element at the given index from each row in self.rows after deleting the header. The updated implementation iterates over self.rows and deletes row[index] for each row. If any row is too short (doesn't contain that index), raise a ValueError with a clear message so callers can detect inconsistent data instead of producing silently misaligned output.

```python
"""Tabular report with headers and rows."""

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Remove header first (this will raise IndexError for invalid index)
        del self.headers[index]

        # Remove the corresponding element from every row to preserve alignment.
        # If a row is shorter than expected, raise a clear error instead of
        # producing silently misaligned data.
        for i, row in enumerate(self.rows):
            try:
                del row[index]
            except IndexError:
                raise ValueError(
                    f"Row at index {i} (value={row}) does not contain column {index}"
                )

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)

```
