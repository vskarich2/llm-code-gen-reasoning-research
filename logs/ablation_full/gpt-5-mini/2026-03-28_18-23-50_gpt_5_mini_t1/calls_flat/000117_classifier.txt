# Developer's Reasoning

## Root Cause
In pipeline.pipeline the raw statistics are computed from the variable normalized instead of from the original input data. Specifically, the line raw_stats = compute_raw_stats(normalized) (in pipeline.py) calls compute_raw_stats on the already-transformed normalized list rather than on the original argument data. Because compute_raw_stats expects untransformed data (see metrics.compute_raw_stats docstring), using the variable normalized causes raw_* keys to reflect normalized values, not the original values.

## Failure Mechanism
Given an input like data = [10, 20, 30], normalize(data) returns [0.0, 0.5, 1.0]. With the current code pipeline computes raw_stats = compute_raw_stats(normalized), producing raw_max=1.0, raw_sum=1.5, raw_count=3 and derived raw_mean=0.5. The intended raw metrics (computed from the original data) are raw_max=30, raw_sum=60, raw_count=3 and raw_mean=20. Thus reports and any consumers of raw_stats/derived get values scaled to 0-1 instead of the original magnitudes, creating incorrect monitoring and alerts.

## Broken Invariant
The pipeline contract says: "raw_stats MUST reflect the original data before any transforms." Concretely, for any non-empty input list data, pipeline(data)['raw_stats']['raw_max'] must equal max(data) and pipeline(data)['raw_stats']['raw_count'] must equal len(data). That invariant is violated because raw_stats were computed from normalized instead of data.

## Fix Strategy
Compute raw stats before performing any transforms and pass the original data to compute_raw_stats. I moved the compute_raw_stats(data) and compute_derived(raw_stats) calls to the start of pipeline() so the raw metrics are derived from the untransformed input. The rest of the pipeline still normalizes, clips, and summarizes for display in the same order, so display/cleaned values remain unchanged while raw_stats/derived now correctly reflect the original data.

"""Multi-stage metrics pipeline.

Stage 1: compute raw stats on original data
Stage 2: normalize
Stage 3: clip to range
Stage 4: summarize for display
"""

from transforms import normalize, clip, summarize_for_display
from metrics import compute_raw_stats, compute_derived


def pipeline(data):
    """4-stage pipeline.

    raw_stats MUST reflect the original data before any transforms.
    """
    # Stage 1: raw stats (compute from original untransformed data)
    raw_stats = compute_raw_stats(data)
    derived = compute_derived(raw_stats)
    # Stage 2: normalize
    normalized = normalize(data)
    # Stage 3: clip
    clipped = clip(normalized, 0.05, 0.95)
    # Stage 4: display summary
    display = summarize_for_display(clipped)

    return {
        "raw_stats": raw_stats,
        "derived": derived,
        "cleaned": clipped,
        "display": display,
    }


def quick_report(data):
    """Quick report that only uses display stats. Unrelated path."""
    normalized = normalize(data)
    return summarize_for_display(normalized)
