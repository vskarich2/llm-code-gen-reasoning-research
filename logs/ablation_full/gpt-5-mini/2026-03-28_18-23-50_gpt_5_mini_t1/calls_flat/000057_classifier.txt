# Developer's Reasoning

## Root Cause
In scheduler.with_history the parameter history uses the module-level list _shared_log as its default (history=_shared_log). Because default parameter objects are shared, both @with_history decorations (on schedule_one and schedule_batch) close over the same list object, so the history list is shared between the two wrappers.

## Failure Mechanism
When the module is imported, with_history is invoked twice as a decorator (once for schedule_one and once for schedule_batch). Both invocations receive the same default list object _shared_log, so wrapper functions for schedule_one and schedule_batch append to the same list. Concretely, if schedule_one() is called once and then schedule_batch() is called once, schedule_one.get_history() will contain two entries (one for each call) instead of one, and get_all_stats() will report identical counts for one_calls and batch_calls even though the functions were called separately.

## Broken Invariant
Invariant violated: 'each decorated function must have its OWN independent history list.' Specifically, schedule_one.get_history() must return a list containing only calls to schedule_one, and schedule_batch.get_history() must return a list containing only calls to schedule_batch; with the bug both wrappers returned the same combined history list.

## Fix Strategy
Change the decorator to avoid using the shared mutable default. I replaced the default history=_shared_log with history=None and, inside with_history, create a new list when history is None (history = []). This ensures each invocation of the decorator (each decorated function) gets a fresh list enclosed by its wrapper. wrapper.get_history still returns a copy and wrapper.clear_history still clears the correct enclosed list, restoring the required per-function independent histories.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process

_shared_log = []


def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Fix: do not use a shared mutable default. Create a fresh list
    # for the history when none is provided so each decorated
    # function gets its own independent history list.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }
