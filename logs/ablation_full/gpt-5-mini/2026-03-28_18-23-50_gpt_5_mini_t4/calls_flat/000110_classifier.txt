# Developer's Reasoning

## Root Cause
In pipeline(), the code calls compute_raw_stats(cleaned) where 'cleaned' is the output of normalize(data). The function compute_raw_stats should be applied to the original input 'data', so passing 'cleaned' causes raw_stats to reflect the normalized values rather than the original values. The problematic line is: raw_stats = compute_raw_stats(cleaned).

## Failure Mechanism
For example, given data = [2, 4, 6], normalize(data) returns [0.0, 0.5, 1.0]. Because pipeline computes raw_stats over the normalized list, compute_raw_stats sees max(cleaned) == 1.0 and returns {'raw_max': 1.0, ...} instead of the correct {'raw_max': 6, ...}. As a result format_report(result) will produce 'max=1.0' where 'max=6' is expected.

## Broken Invariant
The pipeline must guarantee that result['raw_stats'] summarizes the original input 'data'. Concretely: for any non-empty numeric input list L, pipeline(L)['raw_stats']['raw_max'] == max(L) (and similarly for raw_min and raw_sum). Currently this invariant is violated when normalize changes value range.

## Fix Strategy
I changed pipeline() to compute raw_stats from the original data before performing normalization and clarified variable names. Specifically, I call raw_stats = compute_raw_stats(data) and then normalized = normalize(data). The returned structure still exposes the normalized values under the 'cleaned' key for compatibility. This ensures raw_stats reflects the untransformed input and fixes the incorrect aggregation observed when compute_raw_stats was applied to the normalized list.

```python
"""Metrics pipeline: compute raw stats before transforming data.

This module computes simple summary statistics on the original input
and also provides a normalization step. The pipeline ensures the
reported raw statistics always reflect the untransformed input.
"""
from typing import Iterable, List, Dict


def compute_raw_stats(data: Iterable[float]) -> Dict[str, float]:
    """Compute statistics on raw (untransformed) data.

    Returns a dict with keys 'raw_max', 'raw_min', and 'raw_sum'. For an
    empty input the function returns zeros for each field.
    """
    data_list = list(data)
    if not data_list:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {
        "raw_max": max(data_list),
        "raw_min": min(data_list),
        "raw_sum": sum(data_list),
    }


def normalize(data: Iterable[float]) -> List[float]:
    """Normalize data to the 0-1 range.

    If the input is empty, return an empty list. If all values are equal,
    return a list of 0.5 values of the same length (midpoint normalization).
    """
    data_list = list(data)
    if not data_list:
        return []
    lo, hi = min(data_list), max(data_list)
    if hi == lo:
        return [0.5] * len(data_list)
    return [(x - lo) / (hi - lo) for x in data_list]


def pipeline(data: Iterable[float]) -> Dict[str, object]:
    """Run pipeline: compute raw stats on original data, then normalize.

    raw_stats MUST reflect the original data, not the normalized version.
    """
    # Compute raw statistics from the original input first
    raw_stats = compute_raw_stats(data)
    # Then perform normalization; keep returned key 'cleaned' for
    # compatibility with existing callers.
    normalized = normalize(data)
    return {"raw_stats": raw_stats, "cleaned": normalized}


def format_report(result: Dict[str, object]) -> str:
    """Format pipeline result for display: show the raw maximum.

    This function expects result to contain 'raw_stats' with a numeric
    'raw_max' value.
    """
    return f"max={result['raw_stats']['raw_max']}"

```
