# Developer's Reasoning

## Root Cause
The function checkout in api.py accepts the parameter use_new_pricing but never uses it. Because checkout simply calls create_invoice without changing the 'new_pricing' feature flag, the pricing module's is_enabled('new_pricing') check always sees whatever global flag state existed beforehand rather than the checkout parameter.

## Failure Mechanism
If a caller invokes checkout(customer, items, use_new_pricing=True), they expect the new pricing to be applied. Instead, create_invoice calls pricing.compute_price which calls is_enabled('new_pricing') (in pricing.py). Since checkout never sets the 'new_pricing' flag, compute_price continues to use the global _flags value (default False) and returns v1 prices. The effect is that checkout's use_new_pricing argument has no impact on invoice['pricing_version'] or amounts.

## Broken Invariant
Calling checkout(..., use_new_pricing=True) must produce an invoice whose 'pricing_version' equals 'v2' and whose line amounts reflect the _v2_price calculation (including bulk discount for qty >= 10). Currently this is not guaranteed because checkout does not propagate the flag to the flags module.

## Fix Strategy
Make checkout actually set the 'new_pricing' feature flag to the requested value for the duration of create_invoice, then restore the original global flag state. This uses flags.enable/disable based on the use_new_pricing parameter and preserves the previous flag value in a try/finally so the global flags are restored even if create_invoice raises. This ensures pricing.compute_price sees the intended flag value while building the invoice.


# Task Description
The checkout function takes a use_new_pricing flag but pricing doesn't seem to respect it. Fix the flag propagation. Return the updated code.

from billing import create_invoice, get_invoices
from flags import enable, disable, is_enabled


def checkout(customer, items, use_new_pricing=False):
    # Save current global state so we can restore it after creating the invoice
    original = is_enabled("new_pricing")

    # Set the flag according to the caller's request
    if use_new_pricing:
        enable("new_pricing")
    else:
        disable("new_pricing")

    try:
        invoice = create_invoice(customer, items)
    finally:
        # Restore the original global state no matter what
        if original:
            enable("new_pricing")
        else:
            disable("new_pricing")

    return invoice
