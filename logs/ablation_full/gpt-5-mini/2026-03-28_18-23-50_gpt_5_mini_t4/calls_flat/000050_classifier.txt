# Developer's Reasoning

## Root Cause
The bug is in function enqueue: its parameter queue has a mutable default value [] (the variable queue). Because default argument objects are created once at function definition time, the same list object is reused across calls and gets modified by queue.append(task), causing state to be shared between independent calls.

## Failure Mechanism
Example scenario: first call enqueue(make_task('a')) uses the default queue list and appends {'name':'a'} so it returns [{'name':'a'}]. A subsequent call enqueue(make_task('b')) (again without passing a queue) appends to the same default list, yielding [{'name':'a'}, {'name':'b'}]. The shared default list causes results from earlier calls to appear in later calls.

## Broken Invariant
Invariant violated: For any call of enqueue(task) made without supplying the queue parameter, the returned value must be a list containing only that task (i.e., returned_list == [task]).

## Fix Strategy
Change enqueue to use None as the default for the queue parameter and create a fresh list inside the function when queue is None. This ensures a new list is allocated for calls that don't pass an explicit queue, so append modifies a per-call list rather than a shared object.

```python
"""Task queue utilities without a mutable default argument.

This module provides small helpers for building and processing task queues.

enqueue(task, queue=None): Add a task to a queue. If no queue is provided,
    a new list is created per call so calls without an explicit queue do not
    share state.
make_task(name, priority=1): Create a task dictionary.
process(queue): Process all tasks in the given queue and return results.
"""

from typing import Dict, List, Optional


def enqueue(task: Dict, queue: Optional[List[Dict]] = None) -> List[Dict]:
    """Add a task to the given queue and return the queue.

    If queue is None, a new list is created so calls that omit the queue
    argument do not share a single mutable default list.
    """
    if queue is None:
        queue = []
    queue.append(task)
    return queue


def make_task(name: str, priority: int = 1) -> Dict:
    """Create a task dict."""
    return {"name": name, "priority": priority}


def process(queue: List[Dict]) -> List[str]:
    """Process all tasks in the queue and return results."""
    results: List[str] = []
    for task in queue:
        results.append(f"done:{task['name']}")
    return results

```
