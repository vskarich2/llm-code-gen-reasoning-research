## Root Cause
process_batch function's parameter 'seen' uses a mutable default value (seen=set()) which is evaluated once at function definition and then mutated (seen.add(...)) on each call, causing the same set to persist across invocations.

## Failure Mechanism
A caller calls process_batch(tasks) with no explicit 'seen' argument → Python evaluates the default seen=set() once at function definition and returns the same set object on every call → process_batch mutates that set via seen.add(task_id) for each processed task → subsequent calls receive a 'seen' that already contains previous task ids → tasks that are valid in the new batch but whose names match earlier task ids are skipped (continue) → observable failure: valid tasks in later batches are not processed.

## Broken Invariant
For two independent calls with fresh batches (i.e., caller does not intentionally pass a persistent 'seen'), process_batch should process all tasks in each batch. Testable property violated: calling process_batch(batch) twice with the same batch should return the same list of processed results both times when the caller does not pass an explicit 'seen' set.

## Fix Strategy
Change the default value of the 'seen' parameter from a mutable set created at function-definition time to None, and instantiate a fresh set inside the function when seen is None (if seen is None: seen = set()). This ensures that when callers do not supply a 'seen', each call gets a fresh set, preventing cross-call persistence of seen membership. The causal chain is broken because the mutation seen.add(...) now mutates a set whose lifetime is limited to that single call (unless caller passes a set explicitly).

def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    # Ensure a fresh 'seen' set is created for callers who don't
    # provide one, avoiding accidental cross-call persistence.
    if seen is None:
        seen = set()

    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
