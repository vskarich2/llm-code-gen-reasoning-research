This reduces a transient cache miss window caused by invalidate and relies on cache_set to atomically overwrite the previous value in the in-memory cache implementation.

def update_record(key, value):

    # Directly set the cache to the new value. Removing any invalidate-before-set
    # avoids a transient cache miss window where a concurrent reader would miss
    # the cache between invalidate and set.

    val = db_read("records", key)
