# Developer's Reasoning

## Root Cause
In sender.send_with_retry the success path does not stop the retry loop: after a successful call to send(msg, ...), the code neither returns nor breaks, so send() may be invoked again. The specific function and variable are send_with_retry (in sender.py) and the call to send(msg, ...).

## Failure Mechanism
For example, calling send_with_retry('hello', max_retries=2, fail_first=False) enters the for loop (range(2)). On the first iteration send('hello', ...) succeeds and stores the message via append(msg) and notify(msg). Because there is no break or return after that success, the loop proceeds to the second iteration and calls send('hello', ...) again, causing a second append and duplicate notification. The duplicate arises directly from the repeated invocations of send inside the retry loop.

## Broken Invariant
A single call to send_with_retry(msg, ...) must result in at most one store.append(msg) and one notify(msg) when a send succeeds; currently a successful send can lead to multiple append/notify calls within the same send_with_retry invocation.

## Fix Strategy
Stop retrying once send succeeds by returning immediately on success. If all attempts fail, raise the last ConnectionError so callers can observe the failure. The change is implemented by returning True right after a successful send() call and re-raising the last error if no attempt succeeds.

"""Message sender with retry and store integration."""

from store import append, notify, get_messages, get_notifications

_attempt_count = 0


def reset():
    global _attempt_count, _messages, _notifications
    _attempt_count = 0
    _messages = []
    _notifications = []


def send(msg, fail_first=False):
    """Send a message: store it and notify.

    If fail_first is True, raises on first call to simulate transient error.
    """
    global _attempt_count
    _attempt_count += 1
    if fail_first and _attempt_count == 1:
        raise ConnectionError("transient failure")
    append(msg)
    notify(msg)
    return True


def send_with_retry(msg, max_retries=2, fail_first=False):
    """Retry send on transient errors."""
    last_error = None
    for attempt in range(max_retries):
        try:
            send(msg, fail_first=fail_first)
            # On success, stop retrying and return immediately to avoid duplicate sends
            return True
        except ConnectionError as e:
            last_error = e
            continue
    # If we exhausted retries and saw an error, raise it so callers know the send failed
    if last_error:
        raise last_error
    return False


def get_attempt_count():
    return _attempt_count
