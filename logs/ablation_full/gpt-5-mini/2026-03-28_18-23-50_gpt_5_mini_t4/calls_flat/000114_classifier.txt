## Root Cause
In code_snippets_v2/temporal_drift_b/pipeline.py, function pipeline computes cleaned = normalize(data) and then calls compute_raw_stats(cleaned). The variable 'cleaned' is the normalized data, so compute_raw_stats is given transformed values instead of the original input 'data'. This incorrect argument causes raw_stats to reflect normalized values.

## Failure Mechanism

Because pipeline calls compute_raw_stats(cleaned), compute_raw_stats returns {'raw_max': 1.0, 'raw_min': 0.0, 'raw_sum': 1.5} instead of {'raw_max': 30, 'raw_min': 10, 'raw_sum': 60}. The raw_stats output is therefore inconsistent with the original data and will mislead any consumer that expects statistics over the untransformed values.

This property is violated because pipeline passed normalized data to compute_raw_stats.

## Fix Strategy
Call compute_raw_stats with the original 'data' instead of 'cleaned'. Changing the call from compute_raw_stats(cleaned) to compute_raw_stats(data) ensures compute_raw_stats runs on the untransformed input before normalize is applied, restoring the intended contract without modifying transforms.py.

def compute_raw_stats(data):
    """Compute statistics on raw (untransformed) data.

    Must be called on original data before any transforms.
    Returns keys: raw_max, raw_min, raw_sum.
    """
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {
        "raw_max": max(data),
        "raw_min": min(data),
        "raw_sum": sum(data),

def normalize(data):
    """Normalize data to 0-1 range."""
    if not data:
        return []
    lo, hi = min(data), max(data)
    if hi == lo:
        return [0.5] * len(data)
    return [(x - lo) / (hi - lo) for x in data]


def summarize_for_display(cleaned):
    """Summarize cleaned data for reporting. Uses different keys.

    Distractor: similar to compute_raw_stats but returns display_max,
    display_min, display_mean — not the same contract.

        "display_min": min(cleaned),
        "display_mean": sum(cleaned) / len(cleaned),
