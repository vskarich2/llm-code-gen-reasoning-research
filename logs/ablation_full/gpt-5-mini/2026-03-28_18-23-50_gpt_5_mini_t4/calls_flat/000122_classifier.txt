# Developer's Reasoning

## Root Cause
The ROLE_PERMISSIONS mapping in permissions.py is missing an entry for the 'moderator' role. The get_permissions(role) function uses ROLE_PERMISSIONS.get(role, set()), so when 'moderator' is looked up it falls through to the default empty set. Thus the missing key in the ROLE_PERMISSIONS dict (variable) causes get_permissions (function) to return an empty permission set for 'moderator'.

## Failure Mechanism
Concretely, code that checks moderator rights calls has_permission('moderator', 'delete'). has_permission delegates to get_permissions('moderator'), which returns the default empty set because 'moderator' is absent from ROLE_PERMISSIONS. As a result the membership test 'delete' in set is False and the moderator is (incorrectly) denied the 'delete' action.

## Broken Invariant
get_permissions('moderator') must include the moderation permissions (specifically 'read' and 'delete'). This is testable: after the fix, get_permissions('moderator') should contain both 'read' and 'delete'.

## Fix Strategy
I added an explicit 'moderator' entry to ROLE_PERMISSIONS with the intended permissions and made the mapping and defaults clearer: introduced DEFAULT_PERMISSIONS as an immutable frozenset, used frozenset for stored role permissions, and made get_permissions return a fresh mutable set copy. This fixes the failure mechanism because looking up 'moderator' now finds its permissions in ROLE_PERMISSIONS instead of falling back to the empty default; the clearer constants and comments make the intent explicit.

```python
"""Access control: map roles to permission sets.

This module defines a clear, explicit mapping of known roles to their
permission sets and small helpers to query permissions.
"""

from typing import Set

# Use immutable containers for stored permissions to signal they are
# canonical and then return a mutable copy to callers to avoid accidental
# mutation of the canonical mapping.
DEFAULT_PERMISSIONS = frozenset()

ROLE_PERMISSIONS = {
    "admin": frozenset({"read", "write", "delete", "manage_users"}),
    "moderator": frozenset({"read", "delete"}),
    "user": frozenset({"read", "write"}),
}


def get_permissions(role: str) -> Set[str]:
    """Return a set of permissions for the given role.

    If the role is unknown, an empty set is returned (the caller gets a
    fresh mutable set). Known roles are defined in ROLE_PERMISSIONS.
    """
    perms = ROLE_PERMISSIONS.get(role, DEFAULT_PERMISSIONS)
    # Return a mutable copy so callers can safely operate on the result
    # without changing the canonical PERMISSIONS mapping.
    return set(perms)


def has_permission(role: str, action: str) -> bool:
    """Check whether a role has a specific permission."""
    return action in get_permissions(role)

```
