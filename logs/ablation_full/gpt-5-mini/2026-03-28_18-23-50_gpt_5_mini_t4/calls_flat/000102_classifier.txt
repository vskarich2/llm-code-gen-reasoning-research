# Developer's Reasoning

## Root Cause
In order_service.place_order the except block for payment failure re-raises the ValueError without calling inventory.release. The function reserves inventory by calling inventory.reserve(product_id, qty) but on payment failure it does 'except ValueError: raise' which leaves _reserved in inventory unchanged.

## Failure Mechanism
Concrete scenario: add_product('sku1', 5) then call place_order('sku1', 2, 10) with set_gateway_fail(True). place_order calls reserve('sku1', 2) which increments inventory._reserved['sku1'] by 2. The payment simulation _process_payment raises ValueError; the except ValueError block immediately re-raises the exception without calling release('sku1', 2). Result: inventory.get_reserved('sku1') remains 2 even though the order failed and no payment succeeded.

## Broken Invariant
After place_order returns (either success or by raising due to payment failure), inventory.get_reserved(product_id) must equal the number of seats actually held for completed orders. Specifically, if place_order raises ValueError for a payment failure, the invariant is that inventory.get_reserved(product_id) decreases by qty that was reserved for that failed order (i.e., release must be called). Currently this invariant is violated because reserved count is not rolled back on payment failure.

## Fix Strategy
Call release(product_id, qty) when payment processing fails before re-raising the exception. This ensures the reservation performed by reserve(product_id, qty) is rolled back on payment failure. The change modifies order_service.place_order to release the reserved quantity inside the except ValueError handler and then re-raise the original exception; notifications are still only appended after successful payment.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Roll back the inventory reservation when payment fails
        release(product_id, qty)
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
