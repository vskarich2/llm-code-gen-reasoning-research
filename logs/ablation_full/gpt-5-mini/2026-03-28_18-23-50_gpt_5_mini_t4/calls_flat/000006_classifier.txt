# Developer's Reasoning

## Root Cause
In config.create_config(), the line `config = DEFAULTS` returns a direct reference to the module-level DEFAULTS dict rather than a new dict. As a result, callers that receive the config (including the cached value in app._cached_settings) share the same object as DEFAULTS.

## Failure Mechanism
Sequence showing cause and effect: 1) get_settings() calls create_config() and stores the returned dict in _cached_settings. Because create_config returned DEFAULTS by reference, _cached_settings is the same object as DEFAULTS. 2) reset_defaults() assigns a new dict to DEFAULTS, so the module-level DEFAULTS is replaced, but _cached_settings still points at the old dict and therefore returns stale values. Alternatively, calling create_config(overrides={'debug': True}) currently does `config.update(overrides)` on the shared object and thus mutates DEFAULTS globally, causing unexpected persistent changes for subsequent callers.

## Broken Invariant
create_config() must return a new, independent dict instance (i.e., the result is not the same object as DEFAULTS) and applying overrides to the returned dict must not mutate the module-level DEFAULTS. Currently, `create_config()` violates `create_config() is not DEFAULTS` (identity test) and `after calling create_config(overrides=...), DEFAULTS remains unchanged`.

## Fix Strategy
Modify create_config() to make a shallow copy of DEFAULTS (using dict(DEFAULTS)) and then apply overrides to that copy. This breaks the alias between returned configs and DEFAULTS, so the cached settings in app._cached_settings can be safely mutated or replaced without inadvertently mutating or becoming stale relative to the module-level DEFAULTS. The change is localized to create_config() and preserves existing behavior of merge_overrides() and reset_defaults().

def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides."""
    # Return a copy of DEFAULTS so callers don't get a reference to the module-level dict.
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}
