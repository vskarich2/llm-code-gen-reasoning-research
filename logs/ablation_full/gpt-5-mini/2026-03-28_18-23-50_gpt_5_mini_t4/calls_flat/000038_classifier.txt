# Developer's Reasoning

## Root Cause
The module-level variable _default_host is initialized once at import time from _settings (line: _default_host = _settings["host"]). The function get_host() returns this captured _default_host instead of reading the current _settings, so it never reflects later changes made by configure().

## Failure Mechanism
If a caller updates the host via configure(host='127.0.0.1'), _settings['host'] is updated but _default_host remains the original 'localhost'. A subsequent call to get_host() returns 'localhost' (the stale _default_host) instead of '127.0.0.1', producing incorrect behavior when the settings are changed at runtime.

## Broken Invariant
After configure(host=<new_host>) is called, get_host() must return <new_host>. Concretely, calling configure(host='127.0.0.1') followed by get_host() should return '127.0.0.1'. This invariant is violated by the original code because get_host() returns the value captured in _default_host at import time.

## Fix Strategy
Removed the stale module-level _default_host and made get_host() read the current _settings['host'] dynamically. Introduced DEFAULTS as the canonical defaults and used dict(DEFAULTS) when initializing or resetting _settings to avoid accidental shared mutation. These changes ensure configure() updates are visible to get_host() immediately.

```python
"""Service with eagerly loaded settings (refactored for clarity).

This module keeps a mutable _settings dict and exposes simple helpers to
read and update it. get_host() now reads the current settings dynamically
instead of returning a value captured at import time.
"""

# Canonical defaults for the service settings
DEFAULTS = {"host": "localhost", "port": 8080, "debug": False}

# Current settings (starts as a copy of DEFAULTS)
_settings = dict(DEFAULTS)


def get_host():
    """Return the current host setting.

    This reads from _settings each time so callers see updates made by
    configure() or reset_settings().
    """
    return _settings["host"]


def get_settings():
    """Return a shallow copy of the current settings dict."""
    return dict(_settings)


def reset_settings():
    """Reset settings to the canonical defaults."""
    global _settings
    _settings = dict(DEFAULTS)


def configure(host=None, port=None, debug=None):
    """Update settings in-place for any provided parameters."""
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
        _settings["debug"] = debug

```
