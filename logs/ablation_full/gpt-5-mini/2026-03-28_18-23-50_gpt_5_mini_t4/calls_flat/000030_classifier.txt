# Developer's Reasoning

## Root Cause
In catalog.update_product the function updates the in-memory database (_db[product_id].update(fields)) but does not call invalidate(product_id). Because cache.invalidate is never called, the stale value previously stored by get_product via put(product_id, dict(product)) remains in the cache and is returned on subsequent get_product calls.

## Failure Mechanism
Concrete sequence: add_product(1, 'Widget', 10) stores _db[1] = {'name': 'Widget', 'price': 10}. A call to get_product(1) sees no cache entry and executes put(1, dict(product)), so the cache now contains the old price (10). Later update_product(1, price=8) executes _db[1].update({'price': 8}) but does not remove the cached entry. A subsequent get_product(1) returns the cached dict with price 10 (cache.get returns the cached value), so callers observe the old price instead of the updated price.

## Broken Invariant
After update_product(product_id, **fields) returns True, get_product(product_id) must return a product whose fields reflect the update. Example testable statement: add_product(1,'X',10); get_product(1)['price'] == 10; update_product(1, price=20) -> get_product(1)['price'] == 20. This invariant is violated because the cached value is not invalidated.

## Fix Strategy
Call invalidate(product_id) at the end of update_product once the DB row has been updated. Removing the cached entry forces the next get_product call to read from _db and re-put a fresh copy into the cache, ensuring the cache no longer serves stale data. The actual change is a single line added to update_product: invalidate(product_id).

```python
"""Product catalog using external cache module."""

from cache import get, put, invalidate

_db = {}


def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Ensure cache no longer holds stale data for this product.
    invalidate(product_id)
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()

```
