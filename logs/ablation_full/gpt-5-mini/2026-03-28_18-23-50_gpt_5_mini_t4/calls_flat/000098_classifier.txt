## Failure Mechanism

The change was applied inside place_order: after inventory.reserve(qty) we try wallet.charge(...); on any exception we call inventory.release(qty) and then re-raise. This guarantees the Inventory.reserved counter is restored on failure and preserves the intended invariant.

```python
 """Order fulfillment with inventory and wallet.

This module ensures inventory reservations are always released if charging fails.
"""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release on failure.

    The reservation is always released if charging fails to avoid leaking
    reserved stock.
    """
    inventory.reserve(qty)
    try:
        wallet.charge(qty * price)
    except Exception:
        # Release the earlier reservation before propagating the error.
        inventory.release(qty)
        raise
    return {"status": "confirmed", "qty": qty, "total": qty * price}

```
