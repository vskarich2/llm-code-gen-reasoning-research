# Developer's Reasoning

## Root Cause
The bug is in pipeline.ingest: the for-loop does not break after a successful call to send_with_retry, so send_with_retry(msg, ...) is invoked repeatedly. Each successful invocation calls sender.send which appends the message to store._messages (via store.append) and increments sender._attempt_count. Because pipeline.ingest lacks a break, a single logical ingest can call sender.send multiple times, producing duplicate stored messages.

## Failure Mechanism
Example: ingest(msg, max_pipeline_retries=2, fail_first=True). On the first pipeline iteration, send_with_retry calls sender.send: sender._attempt_count == 0 so the first send raises ConnectionError, send_with_retry retries and the second send succeeds and append(msg) is executed once. Because pipeline.ingest doesn't break, it proceeds to the second pipeline iteration and calls send_with_retry again; sender._attempt_count is already >0 so sender.send succeeds immediately and append(msg) runs again. The store ends up with the same msg appended twice. With nested retries (pipeline-level and sender-level), this can produce 2x (or more, depending on configured retries) duplicates.

## Broken Invariant
Ingesting a single message via pipeline.ingest(msg) must result in at most one append to the message store (i.e., store.message_count() increases by exactly 1 for a successful ingest). The current pipeline.ingest implementation can append the same msg multiple times for one ingest call, violating this invariant.

## Fix Strategy
Stop the pipeline-level retry loop after a successful send_with_retry to prevent repeated successful sends. Additionally, use the existing module reset helpers to properly reset shared state. The change adds a break after the successful send_with_retry call in pipeline.ingest, preventing subsequent iterations from re-invoking the sender and causing duplicate appends. The reset function now calls store.reset() and sender.reset_sender() (instead of trying to mutate other modules' internals), ensuring consistent clearing of state.
