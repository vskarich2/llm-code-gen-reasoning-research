# Developer's Reasoning

## Root Cause
In scheduler.py the decorator factory with_history is defined as def with_history(func, history=_shared_log): while the module-level variable _shared_log = [] is used as the default for history. Because mutable default values are evaluated at function definition time, every decorated function captures and appends into the same list _shared_log.

## Failure Mechanism
schedule_one and schedule_batch are both decorated with @with_history. When schedule_one(...) runs it appends an entry into the shared list (_shared_log). Later, when schedule_batch(...) runs it appends another entry into the same shared list. As a result schedule_one.get_history() and schedule_batch.get_history() both return the combined entries (both 'schedule_one' and 'schedule_batch' records). For example, calling schedule_one(task1) then schedule_batch([t1, t2]) yields schedule_one.get_history() length 2 and includes a record with 'func': 'schedule_batch', violating the expectation of per-function separation. This also makes get_all_stats() report incorrect per-function call counts.

## Broken Invariant
Each decorated function must have its OWN independent history list such that wrapper.get_history() returns only records produced by calls to that specific wrapped function. Concretely, after calling schedule_one(x) once and schedule_batch([a,b]) once, len(schedule_one.get_history()) must be 1 and schedule_one.get_history() must contain only entries whose 'func' == 'schedule_one'.

## Fix Strategy
Change the decorator to avoid using a module-level mutable default. I replaced the default history argument with None and allocate a fresh list for history at decoration time when history is None. This ensures each invocation of the decorator (i.e., each decorated function) closes over its own independent list. The wrapper still exposes get_history and clear_history, but they now operate on a per-decorator list instead of a shared module list.

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper
