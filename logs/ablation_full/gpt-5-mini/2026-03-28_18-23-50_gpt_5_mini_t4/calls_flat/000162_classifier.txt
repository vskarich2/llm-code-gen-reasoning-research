# Developer's Reasoning

## Root Cause
In Report.delete_column the code deletes an entry from self.headers (del self.headers[index]) but does not remove the corresponding element from each row in self.rows. The function modifies self.headers but leaves the lists stored in self.rows untouched, so headers and row values go out of sync.

## Failure Mechanism
Given headers = ['A','B','C'] and a row [1,2,3], calling Report.delete_column(1) executes del self.headers[1] making headers ['A','C'] while each stored row remains [1,2,3]. Later render() builds dictionaries via dict(zip(self.headers, row)): zip pairs 'A'->1 and 'C'->2, so column 'C' is assigned the former 'B' value (2) and the table is misaligned. get_column(1) would also return the wrong column values because it reads row[1] from unmodified rows.

## Broken Invariant
After any call that modifies the table structure, for every row in report.rows len(row) == len(report.headers) must hold. Currently delete_column can produce rows whose length is greater than len(headers), violating this invariant.

## Fix Strategy
When deleting a column at index we now remove the header AND delete the element at the same index from every row: after del self.headers[index] the code iterates over self.rows and executes del row[index]. This restores the one-to-one correspondence between headers and row elements so render() and get_column() produce correct results.

```python
"""Tabular report with headers and rows."""

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Remove header
        del self.headers[index]
        # Also remove the corresponding element from each row to keep alignment
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)

```
