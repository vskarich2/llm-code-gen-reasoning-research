## Root Cause
In process_payment, the early return on the condition `if amount == 0: return {'status': 'skipped', 'amount': 0}` prevents the function from appending an entry to the module-level list `_ledger`. The causal relationship is that the early return exits the function before `_ledger.append(entry)` can run, so zero-amount payments are not recorded in `_ledger`.

## Failure Mechanism
When a caller invokes process_payment(0), the function evaluates `if amount == 0` and executes the early return. The function returns {'status': 'skipped', 'amount': 0} but never executes the code that creates `entry` and calls `_ledger.append(entry)`. As a concrete consequence, calling verify_ledger(expected_count) after a zero-amount payment does not reflect that payment: the ledger length does not increase and any test expecting an added 'skipped' entry fails.

## Broken Invariant
The module-level invariant is: 'All calls to process_payment(amount, ...) must create a ledger entry in `_ledger`.' Concretely testable: after calling process_payment(0, 'desc'), len(_ledger) increases by 1 and the newly appended entry equals {'amount': 0, 'description': 'desc', 'status': 'skipped'}.

## Fix Strategy
Remove the early return and ensure process_payment always constructs a ledger entry and appends it to `_ledger`. The revised function determines the correct status ('skipped' for amount == 0, otherwise 'charged'), creates `entry`, appends it to `_ledger`, and then returns the response. This guarantees that zero-amount payments are recorded while preserving the original return value semantics.

"""Simple payment processor with reasoning_evaluator_audit ledger."""

_ledger = []


def process_payment(amount, description="payment"):
    """Process a payment and record it in the ledger.

    All payments — including zero-amount — must be recorded in the
    ledger for reasoning_evaluator_audit compliance. Zero-amount payments are recorded
    with status 'skipped' but still appear in the ledger.
    """
    # Determine status for the payment instead of returning early,
    # so every processed payment is recorded in the ledger.
    status = "skipped" if amount == 0 else "charged"

    entry = {"amount": amount, "description": description, "status": status}
    _ledger.append(entry)

    return {"status": status, "amount": amount}


def get_ledger():
    """Return a copy of the current ledger."""
    return list(_ledger)


def verify_ledger(expected_count):
    """Verify that ledger has exactly expected_count entries."""
    return len(_ledger) == expected_count
