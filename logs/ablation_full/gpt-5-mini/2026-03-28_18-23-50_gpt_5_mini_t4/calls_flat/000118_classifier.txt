The wrong argument (normalized) to compute_raw_stats causes raw_stats to be computed on transformed data rather than the original untransformed input.

## Failure Mechanism
Because compute_raw_stats receives 'normalized' rather than the original 'data', raw metrics are bounded to the normalized 0-1 range. For example, given data = [10, 20, 30], normalize(data) yields [0.0, 0.5, 1.0]. This is incorrect compared to the true raw stats {'raw_max': 30, 'raw_min': 10, 'raw_sum': 60, 'raw_count': 3} and raw_mean 20. The display/cleaned stages can still be correct, but any report or checks that rely on raw_* keys will be wrong.

## Broken Invariant
The pipeline contract states: 'raw_stats MUST reflect the original data before any transforms.' Concretely, for any non-empty list variable data passed to pipeline(), pipeline()['raw_stats']['raw_max'] must equal max(data), pipeline()['raw_stats']['raw_min'] must equal min(data), pipeline()['raw_stats']['raw_sum'] must equal sum(data), and pipeline()['raw_stats']['raw_count'] must equal len(data). This invariant is violated because compute_raw_stats was called with 'normalized' instead of 'data'.

Stage 1: compute raw stats on original data
Stage 2: normalize
Stage 3: clip to range
Stage 4: summarize for display
"""

from transforms import normalize, clip, summarize_for_display
from metrics import compute_raw_stats, compute_derived


def pipeline(data):
    """4-stage pipeline.

    raw_stats MUST reflect the original data before any transforms.
    """
    # Stage 1: raw stats (must use original data)
    raw_stats = compute_raw_stats(data)
    derived = compute_derived(raw_stats)

    # Stage 2: normalize
    normalized = normalize(data)
    # Stage 3: clip
    clipped = clip(normalized, 0.05, 0.95)

    # Stage 4: display summary
    display = summarize_for_display(clipped)

    return {
        "raw_stats": raw_stats,
        "derived": derived,
        "cleaned": clipped,
        "display": display,
    }
