# Developer's Reasoning

## Root Cause
In worker.py, the function process_batch declares a mutable default argument seen=set(). Because default argument expressions are evaluated once at function definition time, the same set object is reused across multiple calls to process_batch. As a result, task IDs added to that set during one call remain in that same set on later calls.

## Failure Mechanism
Concrete scenario: call process_batch([{"name": "A"}]). The function adds 'A' to the default seen set and returns a processed result for task A. Later, call process_batch([{"name": "A"}, {"name": "B"}]). Because the same seen set still contains 'A', the function skips task A and only processes B (or may skip both if previously added). This manifests as valid tasks in a fresh batch being incorrectly skipped because their IDs are present in the persisted seen set.

## Broken Invariant
The function process_batch violates its documented invariant: 'each call to process_batch with a fresh batch must process ALL tasks in that batch, regardless of prior calls.' Specifically, for any two independent calls with input lists tasks1 and tasks2, every task in tasks2 must be returned as processed if not duplicated inside that call; the current implementation can return fewer processed tasks for tasks2 because seen is shared across calls.

## Fix Strategy
Replace the mutable default seen=set() with a sentinel default seen=None and allocate a new set inside the function when seen is None. This ensures each call gets a fresh set (so per-call duplicate tracking remains local) and prevents cross-call state from causing valid tasks in later batches to be skipped. The code change is: def process_batch(tasks, seen=None): followed by if seen is None: seen = set().

"""Worker that processes task batches."""


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
