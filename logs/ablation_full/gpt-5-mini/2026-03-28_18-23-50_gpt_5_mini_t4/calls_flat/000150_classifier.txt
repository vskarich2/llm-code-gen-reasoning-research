# Developer's Reasoning

## Root Cause
In payment.process_payment the early return on duplicates (the conditional `if txn_id in _cache: return _cache[txn_id]`) skips calling ledger.record. The variable `_cache` is used to detect duplicates, but because the code returns immediately when a txn_id is already present, no ledger entry is appended for that call.

## Failure Mechanism
If a client calls process_payment('tx123', 100) twice, the first call records an entry via record(...) and caches the result. The second call hits `if txn_id in _cache` and returns the cached result without calling record. As a result, the ledger's internal `_entries` list grows by 1 even though process_payment was invoked twice; calling verify(2) (which checks `len(_entries) == expected_count`) will return False. The missing ledger entry is caused solely by the early return path that omits `record(...)`.

## Broken Invariant
For any sequence of calls to process_payment, the number of ledger entries must equal the number of calls. Concretely: after N calls to process_payment (including duplicate txn_ids), ledger.verify(N) must return True. This invariant is violated when process_payment returns early for duplicate txn_ids without calling record.

## Fix Strategy
Ensure every invocation of process_payment appends a ledger entry. Instead of returning immediately on a cache hit, retrieve the cached result, call record(...) to log the current call (using the cached status), and then return the cached result. This preserves duplicate-detection behavior while guaranteeing the ledger is updated on every call.

"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # On duplicate, still record the call before returning the cached result
    if txn_id in _cache:
        cached = _cache[txn_id]
        # Record this invocation (use the cached status so ledger reflects what happened)
        record(txn_id, amount, cached.get("status"))
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()
