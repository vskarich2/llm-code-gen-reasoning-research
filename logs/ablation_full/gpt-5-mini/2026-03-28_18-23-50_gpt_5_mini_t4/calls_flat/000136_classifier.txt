    Args:

        limit: maximum allowed requests (integer, >= 0)

    Returns:
        True if the caller should be blocked, False if allowed.

    Notes:
        The function treats count >= limit as blocked. This matches the
        protocol used by check_and_increment which checks before incrementing.
    '''

        raise ValueError('count and limit must be non-negative')

    # FIX: use >= so that count == limit is considered rate-limited
