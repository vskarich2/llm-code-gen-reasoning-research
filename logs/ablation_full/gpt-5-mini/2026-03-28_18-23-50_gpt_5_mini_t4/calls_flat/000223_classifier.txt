# Developer's Reasoning

## Root Cause
The bug is in process(): it checks the module-level flag _initialized and, when False, appends an error to _log and returns False. The module-level list _buffer is declared but never used, so items passed to process() before init() are not retained. Specifically, process() uses _initialized to decide whether to log an error (line that does _log.append(f"error:not_init:{item}")) instead of enqueuing the item in _buffer, and init() never flushes any pending items because _buffer is unused.

## Failure Mechanism
When run_steps executes (process, ("a",)) before (init, ()), process() sees _initialized == False and executes the branch that does _log.append(f"error:not_init:{item}") and returns False. Because the item 'a' is neither stored ( _buffer is unused ) nor re-processed later, the subsequent init() call only appends "init" to _log and the later process("b") appends "processed:b". The resulting log becomes ["error:not_init:a", "init", "processed:b", "shutdown"] and the item 'a' is lost from the processed output.

## Broken Invariant
For any sequence of calls starting from reset(), if process(item) is called before init(), the system must still record that item as processed after init() completes. Concretely, after reset(), run_steps([(process, ("a",)), (init, ()), (process, ("b",)), (shutdown, ())]) must produce the same log as the correctly ordered sequence: ["init", "processed:a", "processed:b", "shutdown"].

## Fix Strategy
Instead of treating calls to process() before initialization as errors, process() now enqueues items into the module-level _buffer. init() sets _initialized True and then flushes _buffer by marking each buffered item as processed (appending "processed:<item>" to _log). This ensures that items submitted before init() are retained and processed once initialization occurs. The change uses the existing _buffer variable (previously unused) and modifies process() to append to _buffer when not initialized, and modifies init() to drain _buffer after setting _initialized.
