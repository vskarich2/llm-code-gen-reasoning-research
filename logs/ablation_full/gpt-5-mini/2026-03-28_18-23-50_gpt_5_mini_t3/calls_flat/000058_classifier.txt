# Developer's Reasoning

## Root Cause
In scheduler.py the decorator function with_history uses the module-level list _shared_log as the default value for its history parameter (history=_shared_log). Because default parameter objects are evaluated once at function definition time, every time with_history is applied (e.g., to schedule_one and schedule_batch) they close over the same _shared_log list instead of getting independent lists.

## Failure Mechanism
When schedule_one or schedule_batch is called their wrapper appends an entry to the shared history list. For example, after calling schedule_one(task1) and then schedule_batch([task2, task3]), schedule_one.get_history() will return entries from both calls (both schedule_one and schedule_batch) because they both appended to the same _shared_log. This mixes histories across decorated functions and prevents distinguishing calls per-function.

## Broken Invariant
Invariant violated: "each decorated function must have its OWN independent history list." Specifically, schedule_one.get_history() must return only entries produced by calls to schedule_one, but currently it may include entries produced by schedule_batch because both wrappers share the same history list.

## Fix Strategy
Change with_history to use history=None as the default and allocate a fresh list when history is None. This ensures each application of the decorator gets its own history list closure. Concretely, replaced the default history=_shared_log with history=None and added 'if history is None: history = []'. No other behavior of the wrapper (append, get_history, clear_history) is changed, so each decorated function now maintains an independent history list.

_shared_log = []


def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # FIX: Do not use the module-level _shared_log as a mutable default.
    # Allocate a fresh list for each decorated function unless an explicit
    # history list is provided.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history

    """Schedule and process a single task."""
    return process(task)
