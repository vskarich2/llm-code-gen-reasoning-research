## Root Cause
process() function + _initialized check: process() performs an early return (logging error and returning False) when _initialized is False, causing the input item to be dropped instead of being retained for later processing.

## Failure Mechanism
Call sequence: process('a') called while _initialized == False → process() executes `if not _initialized: _log.append(f"error:not_init:{item}"); return False` → the function returns without recording the item for future processing (no buffering) → later init() runs but there is no record of 'a' to process → observable failure: 'a' is never logged as processed (lost item) and an 'error:not_init:a' entry appears instead.

## Broken Invariant
If init() is called eventually after one or more process(item) calls, then for every earlier process(item) call there MUST be a corresponding 'processed:<item>' entry in _log after init() completes. This invariant is violated: reset(); process('a'); init(); get_log() currently yields no 'processed:a'.

## Fix Strategy
Change process() so that when called before init it buffers the item (appends to module-level _buffer) instead of logging an error and returning False. Modify init() to, after setting _initialized True and logging 'init', flush the buffer in FIFO order by recording 'processed:<item>' entries for each buffered item and clearing the buffer. Additionally, make shutdown() initialize/flush buffered items if shutdown is called while not initialized but buffer is non-empty (so items aren't silently lost if init() was never called but there are pending items). This breaks the causal chain because items are no longer lost at the point of the early return in process(); instead they are retained until init() (or shutdown-triggered init) occurs and are then processed.

_log = []
_initialized = False
_buffer = []


def reset():
    global _initialized
    _log.clear()
    _buffer.clear()
    _initialized = False


def init():
    """Mark initialized and flush any buffered items in FIFO order."""
    global _initialized
    _initialized = True
    _log.append("init")
    # flush buffered items in arrival order
    while _buffer:
        item = _buffer.pop(0)
        _log.append(f"processed:{item}")


def process(item):
    """Accept item; if not initialized, buffer it for later processing.

    Previously this function logged an error and returned False when not
    initialized, causing the item to be lost. Now it retains the item by
    buffering so that a subsequent init() (or shutdown-triggered init)
    will process it.
    """
    if not _initialized:
        # buffer for later processing instead of dropping
        _buffer.append(item)
        return True
    _log.append(f"processed:{item}")
    return True


def shutdown():
    # If there are buffered items but init() was never called, ensure they
    # are processed so items aren't lost on shutdown.
    if not _initialized and _buffer:
        init()
    _log.append("shutdown")
    return list(_log)


def get_log():
    return list(_log)


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def correct_order():
    """init -> process(a) -> process(b) -> shutdown. Correct."""
    reset()
    run_steps([
        (init, ()),
        (process, ("a",)),
        (process, ("b",)),
        (shutdown, ()),
    ])
    return get_log()
