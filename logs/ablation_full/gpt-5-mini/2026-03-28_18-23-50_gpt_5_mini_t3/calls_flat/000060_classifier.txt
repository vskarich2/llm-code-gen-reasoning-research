## Root Cause
with_history (scheduler.py) uses the module-level variable _shared_log as the default value for the parameter 'history' (operation: default parameter binding), causing every decorated function to capture and append into the same list.

## Failure Mechanism
decorator default → during function definition the default parameter 'history' is bound to the module-level list _shared_log → both schedule_one and schedule_batch are decorated with with_history and therefore close over the same list object → when schedule_one is called it appends entries into that shared list → schedule_batch.get_history() (and schedule_one.get_history()) return the combined entries from both functions → observable failure: histories are combined and per-function history invariant is violated (get_all_stats reports counts that include calls from other decorated functions).

## Broken Invariant
Each decorated function must have an independent history list: for any two decorated functions f and g, f.get_history() must contain only entries for f and not entries produced by g. Currently schedule_one.get_history() and schedule_batch.get_history() can contain entries from both functions.

## Fix Strategy
Change with_history to avoid using _shared_log as a mutable default. Accept only the function argument on decoration (keep signature compatible when used as @with_history) and create a fresh list inside the decorator when no explicit history is supplied. Concretely: replace the default parameter history=_shared_log with history=None, then inside with_history set history = [] if history is None. This ensures each decorated function closes over its own list instance, breaking the causal chain: previously shared list → now per-decorator list, so appends affect only that function's history.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Create a fresh history list for each decorated function when
    # no explicit history is provided. This avoids sharing a module-
    # level mutable default across multiple wrappers.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    def get_history():
        return list(history)

    def clear_history():
        history.clear()

    wrapper.get_history = get_history
    wrapper.clear_history = clear_history
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }
