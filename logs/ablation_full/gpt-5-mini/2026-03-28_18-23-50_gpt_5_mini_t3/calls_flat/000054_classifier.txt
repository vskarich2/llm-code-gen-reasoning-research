# Developer's Reasoning

## Root Cause
In worker.py the function process_batch defines a mutable default argument seen=set(). The default set object is created once at function definition time and reused across calls, so the local variable 'seen' retains values added by previous invocations.

## Failure Mechanism
Because the same 'seen' set is reused, names of tasks processed during the first call remain in that set. For example, given tasks = [create_task('t1'), create_task('t2')], the first call process_batch(tasks) will add 't1' and 't2' to the persistent seen set and return two processed results. A subsequent call process_batch(tasks) (with no explicit seen passed) will find both 't1' and 't2' already in seen and skip them, returning an empty list instead of processing both tasks again.

## Broken Invariant
The function violates its documented invariant: 'each call to process_batch with a fresh batch must process ALL tasks in that batch, regardless of prior calls.' Concretely, for any list tasks of length n passed with the default seen, process_batch(tasks) must return a list of length n with each element having 'result': 'processed'. Under the bug, a repeated call can return fewer than n results.

## Fix Strategy
Removed the mutable default by changing the signature to use seen=None and creating a new local set when seen is None (seen = set()). This ensures each call that doesn't pass an explicit seen receives a fresh set and no state is carried over between calls, so previously processed task names do not cause valid tasks in a later call to be skipped.

"""Worker that processes task batches."""

from queue import create_task


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    # Ensure a fresh set when the caller doesn't provide one
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
