# Developer's Reasoning

## Root Cause
In Report.delete_column (report.py) the code deletes the header entry with del self.headers[index] but does not remove the corresponding element from each row in self.rows. Removing only self.headers breaks the alignment between headers and row elements because self.rows is left unchanged.

## Failure Mechanism
Example: r = Report(['A','B','C']); r.add_row(1,2,3); r.delete_column(1) results in r.headers == ['A','C'] but the single row remains [1,2,3]. render() will produce dict(zip(['A','C'], [1,2,3])) -> {'A': 1, 'C': 2} instead of the expected {'A': 1, 'C': 3}. get_column(1) will return 2 (the leftover middle element) rather than the value that belonged to header 'C'.

## Broken Invariant
For every row in self.rows, len(row) == len(self.headers). This must hold before and after any column operations. The original delete_column violates this by removing a header without removing the corresponding element from each row.

## Fix Strategy
Enforce the rows/headers length invariant and remove the column element from every row when deleting a header. I imported validate_row and added a length check in add_row to prevent adding mis-sized rows. In delete_column I check the index bounds, delete the header, and then delete the element at that index from every row (del row[index]). Because add_row now enforces len(row) == len(headers), the deletion on each row is safe and restores alignment.

```python
"""Tabular report with headers and rows."""

from data import make_row, validate_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        row = make_row(*values)
        # Ensure rows always match the number of headers
        if not validate_row(row, self.column_count()):
            raise ValueError(
                f"Row has {len(row)} columns but expected {self.column_count()}"
            )
        self.rows.append(row)

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Validate index first
        if index < 0 or index >= len(self.headers):
            raise IndexError("Column index out of range")
        # Remove header
        del self.headers[index]
        # Remove the corresponding element from each row to preserve alignment
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)

```
