# Developer's Reasoning

## Root Cause
The cache-write behavior was split across two functions in cache_writer.py: refresh_user_snapshot(user) uses cache_put_if_absent and sync_user_to_cache(user) uses cache_put. In user_service.py the rename_user flow calls refresh_user_snapshot, which uses cache_put_if_absent and will not overwrite an existing entry in the in-memory _store. Because refresh_user_snapshot was used for rename_user, the cache (_store) can remain stale after a database rename even though sync_user_to_cache (the overwriting variant) exists separately.

## Failure Mechanism
Concrete scenario: a user with id 42 is cached in cache_writer._store as 'user:42' -> 'Alice'. Calling rename_user(42, 'Alicia') updates the DB via db.update_name but then calls refresh_user_snapshot(updated). refresh_user_snapshot calls cache_put_if_absent(f'user:42', 'Alicia'), which sees that 'user:42' already exists in _store and leaves the stored value as 'Alice'. Subsequent calls to cache_reader.get_display_name(42) still return 'Alice' even though user_repo.db now holds 'Alicia', causing the application to serve a stale display name.

## Broken Invariant
After rename_user(user_id, new_name) completes, cache_writer._store must contain key f'user:{user_id}' whose value equals lookup_user(user_id)['name']. (Previously violated because rename_user used cache_put_if_absent.)

## Fix Strategy
I removed the duplicated small helpers and consolidated them into a single explicit API sync_user_cache(user, replace=False) in cache_writer.py which chooses between cache_put (replace=True) and cache_put_if_absent (replace=False). I then updated all callers in user_service.py: save_user and bulk_warm_cache call sync_user_cache(user) to preserve the original 'put if absent' seeding behavior, while rename_user now calls sync_user_cache(updated, replace=True) so the cache is overwritten to reflect DB renames. This ensures the cache no longer stays stale after a rename and centralizes the put-vs-put-if-absent logic in one function.

    if replace:
        cache_put(key, user["name"])
    else:
        cache_put_if_absent(key, user["name"])

def delete_user(user_id):

def rename_user(user_id, new_name):

def bulk_warm_cache(users):
