# Developer's Reasoning

## Root Cause
In process_batch, the function increments the module-level _counter for each item but calls snapshot() only once after the loop; as a result the module-level list _snapshots is appended a single time per batch instead of once per item. The causal relationship is: process_batch (function) updates _counter repeatedly but fails to invoke snapshot() inside the per-item loop, so _snapshots (variable) receives only one record regardless of the number of items processed.

## Failure Mechanism
For example, calling process_batch([1, 2, 3]) will add 1, then 2, then 3 to _counter (making _counter increase by 6), but snapshot() is invoked only once after the loop, so _snapshots increases length by 1 instead of by 3. Any code that relies on one snapshot per processed item (e.g., asserting snapshots count equals number of processed items) will observe a mismatch: expected 3 new snapshots, observed 1.

## Broken Invariant
For a call process_batch(items), the invariant that must hold is: len(_snapshots_after) - len(_snapshots_before) == len(items). This code violates that because snapshot() is only called once per batch instead of once per item.

## Fix Strategy
I moved the snapshot() call inside the per-item loop in process_batch so that a snapshot is recorded immediately after each increment of _counter. By invoking snapshot() for every item processed, the code now guarantees that the number of appended snapshots increases by exactly the number of items processed, restoring the invariant described above.

```python
 """Batch processor with per-item snapshots.

This module maintains a cumulative counter and records a snapshot of the counter
value for each item processed. The intended behavior is one snapshot per item.
"""

_counter = 0
_snapshots = []


def reset():
    """Reset the module state: counter and snapshots list."""
    global _counter, _snapshots
    _counter = 0
    _snapshots = []


def snapshot():
    """Record the current counter value into the snapshots list."""
    _snapshots.append(_counter)


def get_snapshots():
    """Return a copy of recorded snapshots."""
    return list(_snapshots)


def process_batch(items):
    """Process each item: increment counter and snapshot after each.

    For each item in the provided iterable, increment the module-level
    _counter by the item's value and record a snapshot immediately after
    that increment. Returns the new counter value.
    """
    global _counter
    for item in items:
        _counter += item
        # record a snapshot for this item so we get one snapshot per item
        snapshot()
    return _counter


def verify_consistency():
    """Return the number of snapshots recorded.

    By contract, this number should equal the total number of items processed
    across all calls to process_batch (i.e., one snapshot per processed item).
    """
    return len(_snapshots)

```
