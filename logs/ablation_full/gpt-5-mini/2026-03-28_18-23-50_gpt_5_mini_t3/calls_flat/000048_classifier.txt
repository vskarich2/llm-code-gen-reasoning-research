## Root Cause

## Failure Mechanism
call reset_config() in config.py → config._config is set to None and subsequent get_config() returns a NEW dict from _load_config() → client._client_cfg still points to the OLD dict captured at import time (no mutation of that variable occurs) → client.get_api_key() and client.get_base_url() read from the stale dict → handler.make_request() and other callers observe old api_key/base_url instead of the updated values

## Broken Invariant

## Fix Strategy

This breaks the causal chain because no module-level stale binding remains and handler uses a consistent snapshot for related fields.
