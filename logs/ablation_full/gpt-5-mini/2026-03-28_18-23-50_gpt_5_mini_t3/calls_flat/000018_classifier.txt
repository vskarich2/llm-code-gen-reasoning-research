# Developer's Reasoning

## Root Cause
In code_snippets_v2/partial_update_b/profile.py, the function update_profile updates user['first_name'] when key == 'first_name' but does not update user['full_name']. Specifically, the first_name branch sets user['first_name'] = value but omits recomputing user['full_name'], so full_name can remain stale after a first_name change.

## Failure Mechanism
If a client sends changes = {'first_name': 'Alice'} for a user whose current names are {'first_name': 'Bob', 'last_name': 'Smith', 'full_name': 'Bob Smith'}, update_profile sanitizes and validates the new first name and sets user['first_name'] = 'Alice' but leaves user['full_name'] as 'Bob Smith'. The resulting user becomes {'first_name': 'Alice', 'last_name': 'Smith', 'full_name': 'Bob Smith'}, so the displayed full name does not reflect the updated first name. If both first_name and last_name are provided and last_name is applied before first_name (iteration order of changes), last_name's branch will set full_name using the old first_name, and the later first_name branch will not correct full_name, producing the same mismatch.

## Broken Invariant
After update_profile(user, changes) returns, user['full_name'] must equal user['first_name'] + ' ' + user['last_name']. Currently this can be false when only first_name is updated (or when first_name is processed after last_name), e.g., before: {'first_name':'Bob','last_name':'Smith','full_name':'Bob Smith'}; changes={'first_name':'Alice'}; after: {'first_name':'Alice','last_name':'Smith','full_name':'Bob Smith'} violates user['full_name'] == user['first_name'] + ' ' + user['last_name'].

## Fix Strategy
Ensure full_name is recomputed whenever first_name or last_name is changed, independent of the iteration order. I added a changed_name flag set to True when either name is updated, and after processing all changes I recompute user['full_name'] = user['first_name'] + ' ' + user['last_name']. This guarantees the invariant holds even if both names are updated in any order.

```python
"""User profile with derived full_name field."""

from validation import validate_name, sanitize_string


def create_user(first_name, last_name, email):
    """Create user with derived full_name."""
    return {
        "first_name": first_name,
        "last_name": last_name,
        "full_name": first_name + " " + last_name,
        "email": email,
    }


def update_profile(user, changes):
    """Update profile fields. full_name must stay in sync.

    Invariant: full_name == first_name + ' ' + last_name
    """
    changed_name = False
    for key, value in changes.items():
        value = sanitize_string(value)
        if key == "first_name" and validate_name(value):
            user["first_name"] = value
            changed_name = True
        elif key == "last_name" and validate_name(value):
            user["last_name"] = value
            changed_name = True
        elif key == "email":
            user["email"] = value

    if changed_name:
        # Recompute full_name from the current first_name and last_name
        user["full_name"] = user.get("first_name", "") + " " + user.get("last_name", "")
    return user

```
