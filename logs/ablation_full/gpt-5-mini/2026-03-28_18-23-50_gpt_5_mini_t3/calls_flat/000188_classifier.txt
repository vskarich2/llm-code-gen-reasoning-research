# Developer's Reasoning

## Root Cause
The api.checkout function accepts the parameter use_new_pricing but never applies it. create_invoice (in billing.py) and compute_price / get_pricing_version (in pricing.py) read the global feature flag via flags.is_enabled("new_pricing"). Because checkout does not set or propagate the intended value into the flags module, the new_pricing flag remains at its prior global value and the requested pricing mode is ignored.

## Failure Mechanism
If a caller invokes checkout(customer, items, use_new_pricing=True) expecting v2 prices, checkout currently calls create_invoice without changing any flags. Since pricing.compute_price and pricing.get_pricing_version call flags.is_enabled("new_pricing") (which defaults to False in flags._flags), the produced invoice will use _v1_price and report pricing_version "v1" instead of using _v2_price and "v2". Concretely: use_new_pricing=True -> checkout() does nothing -> flags._flags['new_pricing'] remains False -> compute_price uses _v1_price -> invoice.total and pricing_version are for v1, violating caller expectation.

## Broken Invariant
Calling checkout(customer, items, use_new_pricing=True) must produce an invoice whose pricing_version is "v2" and whose line amounts are computed with the _v2_price formula; similarly, use_new_pricing=False must produce "v1" pricing. This is testable by asserting invoice['pricing_version'] matches the use_new_pricing argument and that totals match the corresponding pricing function.

## Fix Strategy
Make checkout explicitly set the global new_pricing flag for the duration of the billing call, then restore the previous flag value to avoid leaking a global state change. The change saves flags.is_enabled('new_pricing'), calls enable or disable according to use_new_pricing, invokes create_invoice, and finally restores the original flag in a try/finally. This ensures pricing.compute_price and get_pricing_version read the intended flag value during invoice creation while not permanently mutating global flags.

from billing import create_invoice, get_invoices
from flags import enable, disable, is_enabled


def checkout(customer, items, use_new_pricing=False):
    # Save current flag state so we can restore it after creating the invoice
    prev_new_pricing = is_enabled("new_pricing")

    # Set the global flag to the requested value for the duration of invoice creation
    if use_new_pricing:
        enable("new_pricing")
    else:
        disable("new_pricing")

    try:
        invoice = create_invoice(customer, items)
    finally:
        # Restore previous flag state to avoid leaking global changes
        if prev_new_pricing:
            enable("new_pricing")
        else:
            disable("new_pricing")

    return invoice
