# Developer's Reasoning

## Root Cause
In function enqueue the parameter queue is declared with a mutable default value queue=[] (the default list object). Because default parameter objects are created once at function definition time, the single list instance bound to the parameter name queue is reused across calls, so successive calls to enqueue without an explicit queue share and modify the same list.

## Failure Mechanism
When a caller relies on the documented invariant and calls enqueue(make_task('a')) expecting ['a'], the function appends the task to the shared default list and returns ['a']. A subsequent call enqueue(make_task('b')) without providing a queue uses the same default list and appends to it, returning ['a', 'b']. Concretely: first call returns [{'name':'a','priority':1}], second call returns [{'name':'a','priority':1}, {'name':'b','priority':1}] instead of returning only the new task list. This accumulation of tasks across independent calls is caused directly by modifying the single default list object declared in the function signature.

## Broken Invariant
The function enqueue violates its own documented invariant: 'each call with a single task (no explicit queue) must return a list containing only that task.' This can be expressed as a testable property: for any two distinct task objects t1 and t2, calling enqueue(t1) then enqueue(t2) (with no explicit queue argument) must yield lists of length 1 each and not contain tasks from the other call. The current implementation can produce lists whose length grows across calls, so that property does not hold.

## Fix Strategy
Replace the mutable default argument with None and create a fresh list inside the function when queue is None. Concretely, the function signature was changed from enqueue(task, queue=[]) to enqueue(task, queue: Optional[List[Task]] = None) and the body now does 'if queue is None: queue = []' before appending. This ensures each call without an explicit queue gets a newly allocated list, preventing cross-call sharing and restoring the documented invariant.
