# Developer's Reasoning

## Root Cause
In auth.py the dispatch dictionary _ROLE_DISPATCH is missing the 'guest' key, so the guest_access function from roles.py is never referenced. The variable _ROLE_DISPATCH is used by get_access(role) to select a handler, so omitting 'guest' causes lookup to fall back to _default_access.

## Failure Mechanism
When code calls get_access('guest') (or can_read('guest')), auth.py executes handler = _ROLE_DISPATCH.get(role, _default_access). Because 'guest' is not present in _ROLE_DISPATCH, handler becomes _default_access, and get_access returns {'read': False, 'write': False, 'delete': False} instead of the guest_access() result. Concretely, can_read('guest') returns False even though roles.guest_access() returns {'read': True, 'write': False, 'delete': False}.

## Broken Invariant
For every role with a corresponding access factory in roles.py, get_access(role) must return that factory's access dict. Specifically, get_access('guest') must equal guest_access() (i.e. its 'read' key must be True). Currently get_access('guest') != guest_access().

## Fix Strategy
Add the missing mapping 'guest': guest_access to the _ROLE_DISPATCH table in auth.py so that _ROLE_DISPATCH.get(role, _default_access) returns guest_access for role == 'guest'. This ensures get_access('guest') returns the correct guest access dict and can_read('guest') yields True.

```python
"""Authentication and authorization dispatch."""

from roles import admin_access, user_access, moderator_access, guest_access


# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {
    "admin": admin_access,
    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access,
}


def _default_access():
    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)

```
