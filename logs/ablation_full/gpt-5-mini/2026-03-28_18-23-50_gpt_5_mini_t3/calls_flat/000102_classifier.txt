# Developer's Reasoning

## Root Cause
order_service.place_order swallows the payment failure path: after calling reserve(product_id, qty) it catches the ValueError raised by _process_payment and immediately re-raises without calling release(product_id, qty). The missing call to release means inventory._reserved (tracked inside inventory module) is never decremented after a failed payment.

## Failure Mechanism
Concrete scenario: inventory.add_product('sku1', 5) sets _stock['sku1']==5 and _reserved['sku1']==0. set_gateway_fail(True) makes _process_payment raise. place_order('sku1', 2, 10) calls reserve('sku1',2) which sets inventory._reserved['sku1']==2. _process_payment raises ValueError, the except in place_order re-raises without calling release('sku1',2). Result: inventory.get_reserved('sku1') still returns 2 even though the payment failed and the order did not confirm, reducing available('sku1') from 5 to 3 permanently.

## Broken Invariant
If a call to place_order(product_id, qty, price) raises a payment-related ValueError, then inventory.get_reserved(product_id) must equal its value before place_order was called (i.e., the reservation for that failed order must be rolled back). Currently this invariant is violated: a failed payment can leave reserved count increased by qty.

## Fix Strategy
Call release(product_id, qty) when payment processing fails so the reservation is rolled back. I updated place_order to call release(product_id, qty) in the except ValueError branch before re-raising. Additionally, I fixed reset() to clear the inventory by delegating to inventory.reset() instead of creating unrelated globals in order_service. These changes ensure that when _process_payment raises, the reserved count is decremented and test setup/teardown properly resets inventory state.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release, reset as inventory_reset

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail
    _notifications = []
    _gateway_fail = False
    # Ensure inventory state is cleared when resetting the service in tests
    inventory_reset()


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Roll back the reservation if payment failed
        release(product_id, qty)
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
