# Developer's Reasoning

## Root Cause
The bug is in scheduler.with_history: the parameter history has a default value of the module-level list _shared_log (history=_shared_log). Because default argument values are evaluated once at function definition time, every function decorated with @with_history closes over the same list object (_shared_log) and therefore shares history state.

## Failure Mechanism
When schedule_one and schedule_batch are decorated with @with_history they both receive the same history list. As a concrete scenario: calling schedule_one(task1) appends an entry to the shared list; then calling schedule_batch([t2, t3]) appends additional entries to the same list. As a result schedule_one.get_history() will include entries produced by schedule_batch and vice versa. Clearing the history on one wrapper (schedule_one.clear_history()) clears the combined history for both, since they reference the same list object.

## Broken Invariant
Invariant violated: 'each decorated function must have its OWN independent history list.' Testable statement: after calling schedule_one(...) once and schedule_batch(...) zero times, len(schedule_one.get_history()) must equal 1 and all entries returned by schedule_one.get_history() must have 'func' == 'schedule_one'. Currently that statement can be false because histories are shared.

## Fix Strategy
Change with_history so it does not default history to the module-level _shared_log. Instead use history=None and, when history is None, allocate a new list per decoration (history = []). This ensures each invocation of the decorator creates and closes over a unique list object for that specific wrapped function. The wrapper's get_history and clear_history continue to operate on that per-function list.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


_shared_log = []


def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Ensure each decorated function gets its own history list
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }
