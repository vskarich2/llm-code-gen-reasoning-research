# Developer's Reasoning

## Root Cause
The api.checkout function accepts the parameter use_new_pricing but never passes it down to billing.create_invoice. create_invoice and pricing.compute_price/read get_pricing_version always consult the global flag via flags.is_enabled("new_pricing") instead of an explicit parameter, so the use_new_pricing argument in checkout has no effect.

## Failure Mechanism
If a caller invokes checkout(customer, items, use_new_pricing=True), api.checkout ignores that True and calls create_invoice(customer, items) which in turn calls pricing.compute_price(...). compute_price calls is_enabled("new_pricing") (which defaults to False in flags._flags), so pricing stays on v1. The invoice returned will show pricing_version "v1" and amounts computed by _v1_price even though the caller requested new pricing.

## Broken Invariant
Calling checkout(customer, items, use_new_pricing=True) must produce an invoice whose 'pricing_version' is 'v2' and whose line amounts equal the v2 pricing calculation for the given items. That invariant was violated because checkout did not propagate the flag.

## Fix Strategy
Add an explicit use_new_pricing parameter to pricing.compute_price and pricing.get_pricing_version (defaulting to None to preserve current behavior when not provided). Propagate that parameter through billing.create_invoice and api.checkout so the caller-provided use_new_pricing is honored. This replaces implicit reliance on flags.is_enabled("new_pricing") when an explicit override is provided and ensures checkout's argument is actually used.


# Task Description

from flags import is_enabled


def compute_price(base, qty, use_new_pricing=None):
    if use_new_pricing is None:
        enabled = is_enabled("new_pricing")
    else:
        enabled = use_new_pricing

    if enabled:
        return _v2_price(base, qty)
    return _v1_price(base, qty)


def _v1_price(base, qty):
    return base * qty


def _v2_price(base, qty):
    discount = 0.1 if qty >= 10 else 0
    return base * qty * (1 - discount)


def get_pricing_version(use_new_pricing=None):
    enabled = is_enabled("new_pricing") if use_new_pricing is None else use_new_pricing
    return "v2" if enabled else "v1"


from pricing import compute_price, get_pricing_version
from flags import is_enabled

_invoices = []


def create_invoice(customer, items, use_new_pricing=None):
    total = 0
    lines = []
    for item in items:
        price = compute_price(item["base"], item["qty"], use_new_pricing=use_new_pricing)
        lines.append({"sku": item["sku"], "amount": price})
        total += price

    invoice = {
        "customer": customer,
        "lines": lines,
        "total": total,
