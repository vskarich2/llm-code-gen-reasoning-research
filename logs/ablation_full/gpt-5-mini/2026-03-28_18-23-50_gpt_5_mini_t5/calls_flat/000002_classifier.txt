# Developer's Reasoning

## Root Cause
In create_config the local variable 'config' is set to the module-level dict DEFAULTS (config = DEFAULTS). Because create_config then calls config.update(overrides), the module-level DEFAULTS is mutated whenever overrides are provided. The causal relationship is: create_config assigns a reference to DEFAULTS instead of a copy, and update modifies DEFAULTS through that reference.

## Failure Mechanism
Concrete scenario: initially DEFAULTS == {'timeout': 30, 'retries': 3, 'debug': False}. Call create_config({'debug': True}). Because create_config used config = DEFAULTS and then config.update({'debug': True}), the module DEFAULTS becomes {'timeout': 30, 'retries': 3, 'debug': True}. A subsequent call to create_config() (with no overrides) will now return debug=True even though the defaults were expected to remain False. The bug is observable as persistent modification of DEFAULTS after a call that is intended to return an overridden copy only.

## Broken Invariant
After calling create_config({'timeout': 10}), the module-level DEFAULTS must remain unchanged: specifically DEFAULTS['timeout'] == 30. (Currently this invariant can be violated because create_config mutates DEFAULTS.)

## Fix Strategy
create_config now makes and returns a shallow copy of DEFAULTS before applying overrides (config = DEFAULTS.copy()), so updates do not affect the module-level DEFAULTS. I introduced FACTORY_DEFAULTS as the canonical default values and initialize DEFAULTS as a copy of FACTORY_DEFAULTS; reset_defaults() now restores DEFAULTS by assigning a fresh copy of FACTORY_DEFAULTS (DEFAULTS = FACTORY_DEFAULTS.copy()). These changes prevent aliasing between returned configs and the module defaults, preserving the invariant that DEFAULTS is not mutated by create_config.

```python
from typing import Any, Dict, Optional

# Canonical factory defaults; kept immutable as the source of truth.
FACTORY_DEFAULTS: Dict[str, Any] = {"timeout": 30, "retries": 3, "debug": False}

# Module-level defaults that callers may read but should not be mutated by create_config.
DEFAULTS: Dict[str, Any] = FACTORY_DEFAULTS.copy()


def create_config(overrides: Optional[Dict[str, Any]] = None) -> Dict[str, Any]:
    """Return a new config dict based on defaults, with optional overrides.

    This function returns a fresh dict on each call and does not mutate
    the module-level DEFAULTS.
    """
    # Make a shallow copy so updates do not mutate DEFAULTS.
    config = DEFAULTS.copy()
    if overrides:
        config.update(overrides)
    return config


def reset_defaults() -> None:
    """Restore DEFAULTS to the original factory values.

    Assign a fresh copy of FACTORY_DEFAULTS to avoid accidental aliasing.
    """
    global DEFAULTS
    DEFAULTS = FACTORY_DEFAULTS.copy()

```
