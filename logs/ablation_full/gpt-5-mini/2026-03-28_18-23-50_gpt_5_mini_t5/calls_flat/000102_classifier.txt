# Developer's Reasoning

## Root Cause
In order_service.place_order the except ValueError clause re-raises the exception without calling release(product_id, qty). The code calls reserve(product_id, qty) (which increments inventory._reserved) before attempting payment, but when _process_payment raises ValueError the reservation is never undone because release is not invoked.

## Failure Mechanism
Concrete scenario: inventory.add_product('widget', 5) then place_order('widget', 2, 10) with set_gateway_fail(True). place_order calls reserve('widget', 2) which sets inventory._reserved['widget'] += 2. _process_payment raises ValueError("payment declined"). The except block executes and re-raises immediately, so inventory._reserved remains increased by 2. Subsequent calls to inventory.available('widget') return 3 instead of the expected 5, and get_reserved('widget') stays at 2 even though the order failed — causing inventory to be incorrectly held and potentially blocking future orders.

## Broken Invariant
If place_order(product_id, qty, price) raises due to payment failure, then get_reserved(product_id) must be equal to its value before place_order was called (i.e., the reservation must be rolled back). Currently, after a payment failure get_reserved(product_id) == previous_reserved + qty, violating the invariant.

## Fix Strategy
On payment failure we now explicitly roll back the reservation before re-raising. I changed place_order to catch exceptions from _process_payment, call inventory.release(product_id, qty) to undo the prior reserve, and then re-raise the exception. I also make reset() call inventory.reset() so module-level inventory state is cleared consistently. This guarantees that any reservation made just before payment is reverted if payment does not succeed, restoring the invariant that failed orders do not leave inventory reserved.

```python
"""Order service coordinating inventory and payment."""

import inventory

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail
    _notifications = []
    _gateway_fail = False
    # ensure inventory module state is reset as well
    inventory.reset()


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    inventory.reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except Exception:
        # rollback reservation on payment/processing failure then re-raise
        inventory.release(product_id, qty)
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)

```
