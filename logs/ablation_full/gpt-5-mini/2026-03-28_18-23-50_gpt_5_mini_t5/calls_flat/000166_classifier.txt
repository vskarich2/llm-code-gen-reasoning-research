# Developer's Reasoning

## Root Cause
In report.Report.insert_column (file report.py) the method updates self.headers and inserts default values into each row, but it never updates self.column_widths. As a result the variable self.column_widths retains its previous length and content while self.headers grows, breaking the required correspondence between headers and widths.

## Failure Mechanism
Create a Report with three headers (so self.column_widths has length 3). Calling insert_column(position=1, header='New') runs self.headers.insert(1, 'New') and inserts default values into every row, so len(self.headers) becomes 4. Because insert_column does not change self.column_widths, len(self.column_widths) remains 3. Then render() calls format_table which does header_parts = [h.ljust(widths[i]) for i, h in enumerate(headers)] and attempts to access widths[3] for the fourth header, raising an IndexError (or otherwise producing misaligned output if widths are used incorrectly). validate() would also return False because validate_table checks len(headers) != len(widths).

## Broken Invariant
For any Report instance, after any mutation that changes the number of columns (headers), the number of column widths must match: len(self.headers) == len(self.column_widths). The code currently violates this invariant after insert_column.

## Fix Strategy
After inserting the new header and the default value into each row, recompute the column widths from the current headers and rows using the existing recalculate_widths function and assign the result to self.column_widths. This guarantees the widths list has the same length as headers and that each width is large enough to accommodate the header and present row values. Concretely, I added the line self.column_widths = recalculate_widths(self.headers, self.rows) at the end of insert_column in report.py.

from data import make_row, validate_table
from formatter import format_table, recalculate_widths


class Report:
    """A table with synchronized headers, rows, and column widths."""

    def __init__(self, headers, default_width=10):
        self.headers = list(headers)
        self.rows = []
        self.column_widths = [default_width] * len(headers)

    def add_row(self, *values):
        """Add a row, padding to match current column count."""
        row = make_row(values, len(self.headers))
        self.rows.append(row)

    def insert_column(self, position, header, default_value=""):
        """Insert a new column at the given position.

        Must update headers, every row, AND column_widths
        to keep all three arrays in sync.
        """
        self.headers.insert(position, header)
        for row in self.rows:
            row.insert(position, default_value)
        # Update column_widths so it stays in sync with headers and rows.
        # Recalculate widths based on current headers and rows to ensure
        # the new column has an appropriate width and the list lengths match.
        self.column_widths = recalculate_widths(self.headers, self.rows)

    def render(self):
        """Render the table using the formatter."""
        return format_table(self.headers, self.rows, self.column_widths)

    def validate(self):
        """Validate internal consistency."""
        return validate_table(self.headers, self.rows, self.column_widths)

    def column_count(self):
        """Return number of columns."""
        return len(self.headers)
