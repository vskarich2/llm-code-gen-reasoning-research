# Developer's Reasoning

## Root Cause
In payment.process_payment the duplicate-detection branch (if txn_id in _cache) returns the cached result immediately: `if txn_id in _cache: return _cache[txn_id]`. This early return happens before calling ledger.record(), so the ledger is not updated for duplicate calls. The specific variables/functions involved are payment._cache and ledger.record.

## Failure Mechanism
If process_payment is called twice with the same txn_id, the first call records the transaction and caches the result. The second call hits the early-return branch and returns the cached result without calling record(), so the ledger's _entries list remains one element while two process_payment calls were made. As a concrete example: process_payment('t1', 100) -> ledger has 1 entry; process_payment('t1', 100) again -> ledger still has 1 entry (no new record), so verify(2) will return False.

## Broken Invariant
For every call to process_payment (including duplicates), ledger.verify(expected_count) must return True when expected_count equals the total number of process_payment calls. Concretely: after N calls to process_payment, len(ledger.get_summary()['entries']) == N must hold.

## Fix Strategy
Instead of returning immediately for cached txn_id, call ledger.record(...) for that invocation and then return the cached result. The change ensures each process_payment call appends an entry to the ledger. Implementation: on cache hit we retrieve result = _cache[txn_id], call record(txn_id, amount, result.get('status','charged')), then return result. This preserves the cache semantics while meeting the ledger-counting contract.

"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # On duplicate, return cached result but still record this call.
    if txn_id in _cache:
        result = _cache[txn_id]
        # Record the duplicate invocation so ledger counts every call.
        record(txn_id, amount, result.get("status", "charged"))
        return result

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()
