# Developer's Reasoning

## Root Cause
In worker.py the function process_batch defines the parameter seen=set(), so the mutable default set created at function definition time is shared across all calls. The variable seen (the default) is mutated inside the function (seen.add(task_id)), causing later calls to observe previously added task IDs.

## Failure Mechanism
Example: call process_batch([{'name':'a'}, {'name':'b'}]) -> the function adds 'a' and 'b' to the default seen set and returns two results. A subsequent call process_batch([{'name':'a'}, {'name':'c'}]) with no explicit seen argument will check task_id 'a' against the same shared seen set, find it present, and skip it, returning only 'c'. That is, valid tasks from the second batch get skipped because seen persisted across calls.

## Broken Invariant
If process_batch is called without passing an explicit seen argument, the function must process every task in the provided tasks iterable (i.e., for input tasks, len(results) == len(tasks)). Currently this is violated when a later call contains names processed by earlier calls because the default seen persists and causes skips.

## Fix Strategy
Change the default value of the seen parameter from a mutable set to None and create a new set() inside the function when seen is None. This guarantees a fresh seen set for each call that doesn't explicitly share it, preventing cross-call retention of task IDs while preserving the ability for callers to provide a shared seen set if desired.

"""Worker that processes task batches."""


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    # Ensure a fresh seen set is created per call when the caller
    # doesn't provide one. Using None as the default avoids a
    # persistent mutable default that would carry state across calls.
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
