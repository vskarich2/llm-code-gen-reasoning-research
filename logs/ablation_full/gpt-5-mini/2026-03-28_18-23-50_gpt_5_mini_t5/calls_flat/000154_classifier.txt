# Developer's Reasoning

## Root Cause
In payment.charge, the function returns early when txn_id is found in the module-level cache _charge_cache. The early return occurs before any call to audit.log_charge, so cached-path executions never invoke log_charge.

## Failure Mechanism
Example: First call charge('txn1', 100) goes through the non-cached path: record('txn1', 100, 'charged') and log_charge('txn1', 100) and caches the result. A subsequent call charge('txn1', 100) hits the if txn_id in _charge_cache branch and returns the cached result immediately. Because the function returns before calling log_charge, the audit._log does not get a second entry for the second call. As a result, audit.get_log() contains only one entry even though charge was called twice; verify_completeness(expected_count) will report incompleteness when expected_count reflects total calls.

## Broken Invariant
For every invocation of payment.charge(txn_id, amount) an audit.log_charge call must be made so audit.get_log() has one entry per call. (Concretely: calling charge twice for the same txn_id must produce two entries in audit.get_log().)

## Fix Strategy
Log every call to charge, including cached-path calls, without re-recording the ledger. I added a log_charge call in the cached branch that logs the actual (cached) charged amount and uses source='cache'. This preserves the invariant that each call is audited while keeping ledger.record only on the first (actual) charge, preventing double-recording.

```python
"""Payment processor with caching and reasoning_evaluator_audit trail.

Caching is intentional: repeated charges for the same txn_id
return the cached result without re-charging. However, every
call to charge() must still be recorded in the reasoning_evaluator_audit log.
"""

from ledger import record, get_count, reset_ledger
from audit import log_charge, verify_completeness, get_log, reset_audit

_charge_cache = {}


def charge(txn_id, amount):
    """Charge the given amount. Uses cache to avoid double-charging.

    Caching is correct (no double-charge), but EVERY call — cached
    or not — must be logged in the reasoning_evaluator_audit system for compliance.
    """
    # Ensure every call is logged. If we have a cached result, do not re-record
    # the ledger, but still emit an audit entry indicating the cached source.
    if txn_id in _charge_cache:
        cached = _charge_cache[txn_id]
        # Log the amount that was actually charged (the cached amount) and mark source
        # so auditors can distinguish cached calls from original charges.
        log_charge(txn_id, cached["amount"], source="cache")
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    log_charge(txn_id, amount)
    _charge_cache[txn_id] = result
    return result


def refund(txn_id):
    """Refund a previously charged transaction."""
    if txn_id not in _charge_cache:
        return {"txn_id": txn_id, "status": "not_found"}
    original = _charge_cache[txn_id]
    record(txn_id, -original["amount"], "refund")
    log_charge(txn_id, -original["amount"], source="refund")
    return {"txn_id": txn_id, "status": "refunded"}


def reset():
    """Reset all payment state."""
    global _charge_cache
    _charge_cache = {}
    reset_ledger()
    reset_audit()

```
