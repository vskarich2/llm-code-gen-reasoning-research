# Developer's Reasoning

## Root Cause
In catalog.update_product the function calls invalidate_shared(product_id) but omits invalidate_local(product_id). The function imports invalidate_local but never invokes it, so the per-request local cache (_local in cache.py) can retain the old product dictionary stored earlier.

## Failure Mechanism
Sequence: a product is loaded via api.get_product -> get_local misses, get_shared misses, db_get returns the DB object which put_shared and put_local cache. Later catalog.update_product(product_id, price=...) updates _db and calls invalidate_shared(product_id) but does not clear the local cache. A subsequent api.get_product(product_id) immediately calls get_local(product_id), which returns the stale dictionary that was cached previously in _local, so the API returns stale product data even though the DB and shared cache were updated/invalidated.

## Broken Invariant
After a successful update_product(product_id, ...) returns True, both cache layers must not contain the old product value. Concretely: cache.get_local(product_id) is None and cache.get_shared(product_id) is None immediately after update_product returns.

## Fix Strategy
Call invalidate_local(product_id) inside update_product so the local (per-request) cache is cleared along with the shared cache. This uses the already-imported invalidate_local function and ensures api.get_product will not read a stale entry from the local cache; subsequent reads will fetch the updated value from the DB and repopulate caches.

"""Product catalog with two-layer cache integration."""

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()
