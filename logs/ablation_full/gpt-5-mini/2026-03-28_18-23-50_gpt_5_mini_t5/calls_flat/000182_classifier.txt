# Developer's Reasoning

## Root Cause
reducers.stage only set st['pending'], st['view'], and incremented st['meta']['version'], while reducers.commit (which set st['stable'] and st['meta']['frozen']) was removed from the pipeline. Because pipeline.process_batch and process_incremental call stage() but do not call commit(), st['stable'] is left empty and st['meta']['frozen'] remains False. The direct causal variables are st['stable'] (never written by stage) and st['meta']['frozen'] (never set when commit() was elided).

## Failure Mechanism
When process_batch(entries) runs, pipeline creates st = make_state(entries), computes merged = collapse(normalize(raw)), then calls stage(st, merged). Because stage did not copy merged into st['stable'] or set st['meta']['frozen'], materialize(st) returns items = list(st['stable']) which is empty, and selectors.get_committed_total(st) returns None (it checks if not st['meta']['frozen'] then returns None). Concretely: pipeline.process_batch -> stage (only sets pending/view/version) -> materialize -> out['items'] == [] and api.ingest reports total == None, even though merged contained data.

## Broken Invariant
After process_batch(entries) or process_incremental(prev_state, new_entries) returns, the state's stable list must contain the processed (normalized+collapsed) entries and meta.frozen must be True. Formally, for any entries, let processed = collapse(normalize(entries)); then after st, out = process_batch(entries): st['stable'] == list(processed) and st['meta']['frozen'] is True (and get_committed_total(st) equals sum(e.get('val',0) for e in st['stable'])).

## Fix Strategy
Update reducers.stage to perform the commit-like assignments that pipeline relied on when commit() was removed: set st['stable'] = list(processed) and set st['meta']['frozen'] = True in addition to existing pending/view/version updates. Remove the now-unused commit() and freeze_view() references from pipeline imports. This ensures materialize() reads a populated st['stable'] and selectors.get_committed_total() sees meta['frozen']==True and returns the committed total. Specifically, stage now writes st['stable'] and st['meta']['frozen'], and pipeline no longer imports commit or freeze_view.

def normalize(entries):
    seen = set()
    out = []
    for e in entries:
        k = e["id"]
        if k not in seen:
            seen.add(k)
            out.append(e)
    return out


def project(entries):
    return [{"id": e["id"], "label": e.get("label", ""), "val": e.get("val", 0)} for e in entries]


def collapse(entries):
    merged = {}
    for e in entries:
        k = e["id"]
        if k in merged:
            merged[k]["val"] = merged[k]["val"] + e.get("val", 0)
        else:
            merged[k] = dict(e)
    return list(merged.values())


def stage(st, processed):
    # stage now also commits: put processed into pending AND stable,
    # build the view and mark the state as frozen. This removes the
    # need to call commit() and freeze_view() separately.
    st["pending"] = list(processed)
    st["stable"] = list(processed)
    st["view"] = project(processed)
    st["meta"]["version"] += 1
    st["meta"]["frozen"] = True


def materialize(st):
    return {
        "items": list(st["stable"]),
        "display": list(st["view"]),
        "v": st["meta"]["version"],
    }


from state import make_state, copy_state
from reducers import normalize, collapse, stage, materialize, project


def process_batch(entries):
    st = make_state(entries)
    raw = st["raw"]

    # dedupe
    cleaned = normalize(raw)

    # merge values for same id
    merged = collapse(cleaned)

    # stage now also commits and builds the view
    stage(st, merged)

    out = materialize(st)
    return st, out


def process_incremental(prev_state, new_entries):
    st = copy_state(prev_state)
    combined = st["stable"] + new_entries

    cleaned = normalize(combined)
    merged = collapse(cleaned)

    stage(st, merged)

    out = materialize(st)
    return st, out


def recompute_view(st):
    st["view"] = project(st["pending"])
    return st
