# Developer's Reasoning

## Root Cause
The function is_enabled uses FLAGS.get(flag_name, False) with the unmodified caller-supplied flag_name. Because the module's FLAGS keys are snake_case (e.g., FLAGS['dark_mode']) but callers often pass camelCase (e.g., 'darkMode'), FLAGS.get is called with a mismatched key and returns the provided default False.

## Failure Mechanism
Call sequence: a caller invokes is_enabled('darkMode'). is_enabled calls FLAGS.get('darkMode', False). Since 'darkMode' is not a key in FLAGS (which contains 'dark_mode'), .get returns the default False, so a feature that should be enabled (FLAGS['dark_mode'] == True) is reported as disabled without any error or warning.

## Broken Invariant
For any snake_case key K present in FLAGS (for example K = 'dark_mode' with value True), calling is_enabled with the camelCase form of K (for example 'darkMode') should return the same boolean value as FLAGS[K]. Currently is_enabled('darkMode') != FLAGS['dark_mode'] for that case.

## Fix Strategy
Normalize the caller-supplied flag name to snake_case before lookup and fail loudly on unknown flags. I added a helper _to_snake_case that converts common camelCase/PascalCase (and normalizes separators) to snake_case, used that normalized key to look up FLAGS, and raise KeyError when the normalized key is missing. This prevents silent False defaults for mistyped or differently-cased flag names and preserves correct behavior for existing snake_case names.

```python
"""Feature flag system with snake_case keys.

This module accepts both snake_case and common camelCase flag names when
checking whether a flag is enabled. It raises on unknown flags instead of
silently returning False to avoid masking typos.
"""

import re
from typing import List

FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def _to_snake_case(name: str) -> str:
    """Convert common camelCase/PascalCase or mixed names to snake_case.

    Leaves already-snake_case names unchanged (except lowercasing).
    """
    if not isinstance(name, str):
        raise TypeError("flag name must be a string")
    # quick path: already all lower and contains underscore
    if name.islower() and "_" in name:
        return name
    # normalize separators
    name = name.replace("-", "_").replace(" ", "_")
    # Handle camelCase / PascalCase -> snake_case
    s1 = re.sub(r"(.)([A-Z][a-z]+)", r"\1_\2", name)
    snake = re.sub(r"([a-z0-9])([A-Z])", r"\1_\2", s1).lower()
    return snake


def is_enabled(flag_name: str) -> bool:
    """Return True if the named feature flag is enabled.

    Accepts snake_case names (preferred) and common camelCase/PascalCase forms.
    Raises KeyError for unknown flags to avoid silently hiding typos.

    Args:
        flag_name: The flag key to look up (snake_case or camelCase)

    Returns:
        The boolean value of the flag.

    Raises:
        KeyError: if the normalized flag name is not present in FLAGS.
        TypeError: if flag_name is not a string.
    """
    normalized = _to_snake_case(flag_name)
    if normalized in FLAGS:
        return bool(FLAGS[normalized])
    raise KeyError(
        f"Unknown feature flag '{flag_name}' (normalized '{normalized}'). "
        f"Available flags: {sorted(FLAGS.keys())}"
    )


def list_flags() -> List[str]:
    """Return a sorted list of all flag names (snake_case)."""
    return sorted(FLAGS.keys())

```
