# Developer's Reasoning

## Root Cause
In Report.delete_column the code only executes 'del self.headers[index]' and never removes the corresponding element from each list in self.rows. Concretely, the function in report.py mutates self.headers but leaves the per-row lists unchanged, so headers and row element positions diverge.

## Failure Mechanism
Example: headers = ['a','b','c'] and rows = [[1,2,3]]. Calling Report.delete_column(1) executes del self.headers[1] -> headers becomes ['a','c'] but rows remains [[1,2,3]]. Later render() builds dict(zip(self.headers, row)) -> dict(zip(['a','c'], [1,2,3])) yields {'a':1, 'c':2} which maps the wrong value for column 'c' (2 instead of 3). The cause is that the header at index 1 was removed while the second element in each row was not removed, so subsequent zips pair headers with the wrong row elements.

## Broken Invariant
After any delete_column(i) call, every row must have the same length as the headers list: for all row in report.rows, len(row) == report.column_count(). The current code violates this invariant when delete_column removes a header but not the corresponding row element.

## Fix Strategy
Validate the requested index against the current headers (preserving the original IndexError behavior for out-of-range header indices), normalize negative indices, then remove the element at that index from every row before removing the header. This ensures each row's length is decremented in lockstep with headers and restores the invariant used by render() and get_column(). The change modifies Report.delete_column to perform these steps and raises clear IndexError if a row is missing the column.

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Validate index against headers (preserve original IndexError behavior)
        n = len(self.headers)
        if n == 0:
            raise IndexError("Column index out of range")
        # Normalize negative indices
        if index < 0:
            index += n
        if not (0 <= index < n):
            raise IndexError("Column index out of range")

        # Remove the element at `index` from every row. If a row is shorter
        # than expected, raise IndexError so callers see the problem.
        for row in self.rows:
            if index >= len(row):
                raise IndexError("Row does not have a column at the specified index")
            del row[index]

        # Finally remove the header
        del self.headers[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
