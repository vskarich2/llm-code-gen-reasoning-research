## Root Cause
The bug is in the get_host function using the module-level variable _default_host. _default_host is initialized once at import time from _settings["host"] (line: _default_host = _settings["host"]) and thereafter never updated. This causes get_host to return a stale value that does not reflect later updates to the mutable _settings via configure.

## Failure Mechanism
When configure(host='127.0.0.1') is called, configure updates _settings['host'] to '127.0.0.1', but get_host() still returns the original _default_host value 'localhost' because _default_host was captured at import time and not changed by configure. Concretely: import service; service.get_host() -> 'localhost'. Then service.configure(host='127.0.0.1'); service.get_host() -> still 'localhost' (incorrect) instead of '127.0.0.1'.

## Broken Invariant
Calling configure(host=...) must update the value returned by get_host(). Formally: after any call configure(host=new_host), get_host() == new_host. This invariant is violated because get_host() reads _default_host (a stale, import-time snapshot) instead of the current _settings['host'].

## Fix Strategy
Removed the stale _default_host variable and made get_host read the live value from _settings['host']. Introduced _DEFAULT_SETTINGS constant and used dict(...) copies when exposing or resetting settings to avoid accidental external mutation. These changes ensure configure() updates are reflected by get_host() because get_host now reads the current _settings instead of a frozen snapshot.

```python
"""Service with lazily-read settings.

This module intentionally reads settings from the live _settings mapping whenever
a getter is called. A constant _DEFAULT_SETTINGS holds the canonical defaults
so reset_settings can restore them without relying on an import-time snapshot.
"""

# Canonical defaults for the service settings
_DEFAULT_SETTINGS = {"host": "localhost", "port": 8080, "debug": False}

# Current settings dictionary (mutable); start with a copy of defaults
_settings = dict(_DEFAULT_SETTINGS)


def get_host():
    """Return the current host setting (reads the live settings).

    This reads _settings['host'] each time so changes made by configure()
    are immediately visible.
    """
    return _settings["host"]


def get_settings():
    """Return a shallow copy of the current settings dict."""
    return dict(_settings)


def reset_settings():
    """Reset settings to the module defaults.

    The reset creates a fresh dict from _DEFAULT_SETTINGS to avoid accidental
    shared mutations between callers.
    """
    global _settings
    _settings = dict(_DEFAULT_SETTINGS)


def configure(host=None, port=None, debug=None):
    """Update settings in place for provided non-None values."""
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
        _settings["debug"] = debug

```
