# Developer's Reasoning

## Root Cause
In add_entry(), when a position argument is provided the function calls _labels.insert(position, label) but calls _values.append(value) instead of inserting into _values at the same index. This mismatch between using insert for _labels and append for _values causes the two parallel lists _labels and _values to diverge.

## Failure Mechanism
Given an initial state _labels = ['A', 'B'] and _values = [1, 2], calling add_entry('X', 99, position=0) will execute _labels.insert(0, 'X') producing ['X', 'A', 'B'] but will execute _values.append(99) producing [1, 2, 99]. As a result get_entry(0) returns ('X', 1) instead of the intended ('X', 99). The label 'X' has been inserted at index 0 while its value ended up at the end of the values list, misaligning entries.

## Broken Invariant
The report requires that for every valid index i, get_entry(i) returns the label and the corresponding value that were added together. Concretely, after calling add_entry(label, value, position=p), get_entry(p) must equal (label, value). This property is not preserved by the existing add_entry implementation when position is not None.

## Fix Strategy
Replace the incorrect _values.append(value) with _values.insert(position, value) so that both _labels and _values are updated symmetrically when inserting. This ensures labels and values remain aligned. I also clarified the function docstring to explicitly state that both lists are modified identically when inserting.

"""Report builder with parallel label/value lists.

This module maintains two parallel lists, _labels and _values. Entries must be
kept aligned: the label and value for the same entry occupy the same index in
their respective lists.
"""

_labels = []
_values = []


def add_entry(label, value, position=None):
    """Add an entry to the report.

    If position is given, insert at that index in both label and value lists.
    Otherwise, append to the end.
    """
    if position is not None:
        _labels.insert(position, label)
        _values.insert(position, value)
    else:
        _labels.append(label)
        _values.append(value)


def get_entry(index):
    """Return (label, value) at the given index."""
    return (_labels[index], _values[index])


def get_all():
    """Return list of (label, value) tuples."""
    return list(zip(_labels, _values))


def count():
    """Return the number of entries."""
    return len(_labels)


def reset():
    """Clear all entries."""
    _labels.clear()
    _values.clear()
