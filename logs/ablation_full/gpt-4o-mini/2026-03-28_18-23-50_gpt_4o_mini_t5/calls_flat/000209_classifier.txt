## Failure Mechanism

## Broken Invariant

## Fix Strategy
To fix the issue, I will modify the `make_increment_steps` function to ensure that the read and write operations are atomic. This can be achieved by combining the read and write into a single step that increments the value directly, thus preventing interleaving from causing lost updates.

def reset():
    global _value
    _value = 0


def get():

    _value = v


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_increment_steps():
    """Combine read and write into a single atomic increment step."""

    def step_increment():
        global _value
        _value += 1
        return ("increment", _value)

    return step_increment, lambda: None


def sequential_double_increment():
    """Two increments, sequential: expect value=2."""
    reset()
    increment_a, _ = make_increment_steps()
    increment_b, _ = make_increment_steps()

    """Two increments, interleaved: now correctly increments to 2."""
    reset()
    increment_a, _ = make_increment_steps()
    increment_b, _ = make_increment_steps()
