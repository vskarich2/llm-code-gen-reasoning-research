## Root Cause
The bug is in the 'enqueue' function where the 'queue' parameter has a mutable default argument (an empty list). This causes the same list to be shared across multiple calls to 'enqueue'.

## Failure Mechanism
When 'enqueue' is called multiple times without providing a specific queue, tasks accumulate in the same list. For example, calling 'enqueue(make_task('task1'))' followed by 'enqueue(make_task('task2'))' will result in a single queue containing both tasks instead of separate lists for each call.

## Broken Invariant
Each call to 'enqueue' with a single task must return a list containing only that task, which is violated when the default queue accumulates tasks across calls.

## Fix Strategy
Changing the default value of the 'queue' parameter to 'None' and initializing a new list inside the function ensures that each call to 'enqueue' starts with a fresh list, thus maintaining the invariant.
