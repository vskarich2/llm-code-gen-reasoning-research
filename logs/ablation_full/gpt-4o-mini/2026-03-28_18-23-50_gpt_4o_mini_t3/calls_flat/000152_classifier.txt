For example, if 'add_entry('Label1', 'Value1', 0)' is called, the expected behavior is to have 'Value1' at index 0, but it ends up at the end of the list instead.

## Broken Invariant

## Fix Strategy
The code change fixes the mechanism by replacing '_values.append(value)' with '_values.insert(position, value)' in the 'add_entry' function. This ensures that the value is inserted at the specified position, maintaining the integrity of the label/value pairing.
