# Developer's Reasoning

## Root Cause
In pipeline.py, the variable raw_stats is assigned the result of compute_raw_stats(cleaned), which is the normalized data, not the original raw data. This violates the expectation that raw_stats reflect the original data, but instead contains normalized values.

## Failure Mechanism
When pipeline() is called, raw_stats is computed after normalization, so it reports statistics on normalized data rather than the original data. This causes raw_stats to show values that are scaled between 0 and 1, not the actual raw data values, misleading any downstream analysis relying on raw_stats.

## Broken Invariant
compute_raw_stats must be called on the original, untransformed data to produce accurate raw_max, raw_min, and raw_sum, but currently it is called on normalized data, violating this contract.

## Fix Strategy
Changing the line in pipeline() from raw_stats = compute_raw_stats(cleaned) to raw_stats = compute_raw_stats(data) ensures that raw_stats are computed on the original data, preserving the invariant that raw_stats reflect the raw, unnormalized data.
