# Developer's Reasoning

## Root Cause
The make_increment_steps() function captures the current value of _value in a local variable 'captured' during the read step, but when multiple increments are interleaved, both read steps capture the same initial value (e.g., 0). Consequently, both write steps set _value to the same incremented value (e.g., 1), causing the second increment to overwrite the first, leading to a final value of 1 instead of 2.

## Failure Mechanism
When two increments are executed with interleaving, both read steps retrieve the same initial value (e.g., 0). Each then computes the new value as current + 1 (resulting in 1), and both write this value back to _value. The second write overwrites the first, so the counter only increases by 1 overall, despite two increment attempts.

## Broken Invariant
After two concurrent increments, the counter value should increase by 2, i.e., starting from 0, the final value should be 2, regardless of interleaving.

## Fix Strategy
Modify make_increment_steps() to read the current value directly from get() at the time of the write step, rather than relying on a captured value during the read step. This ensures each write uses the latest counter value, preventing overwrites due to stale reads.



# Task Description
Two concurrent increments produce value=1 instead of 2 under interleaving. Fix so counter is correct under any interleaving.

"""Counter with non-atomic read-modify-write, simulated via step functions."""

_value = 0


def reset():
    global _value
    _value = 0


def get():
    return _value


def _set(v):
    global _value
    _value = v


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_increment_steps():
    """Split a read-then-increment into separate read and write steps.

    BUG: under interleaving, two increments both read the same value
    and both write value+1, losing one update.
    """
    captured = {}

    def step_read():
        captured["current"] = get()
        return ("read", captured["current"])

    def step_write():
        # Read the latest value at the time of writing to prevent overwriting
        current_value = get()
        _set(current_value + 1)
        return ("write", current_value + 1)

    return step_read, step_write


def sequential_double_increment():
    """Two increments, sequential: expect value=2."""
    reset()
    read_a, write_a = make_increment_steps()
    read_b, write_b = make_increment_steps()
    run_steps([(read_a, ()), (write_a, ()), (read_b, ()), (write_b, ())])
    return get()


def interleaved_double_increment():
    """Two increments, interleaved: BUG — both read 0, both write 1."""
    reset()
    read_a, write_a = make_increment_steps()
    read_b, write_b = make_increment_steps()
    run_steps([(read_a, ()), (read_b, ()), (write_a, ()), (write_b, ())])
    return get()
