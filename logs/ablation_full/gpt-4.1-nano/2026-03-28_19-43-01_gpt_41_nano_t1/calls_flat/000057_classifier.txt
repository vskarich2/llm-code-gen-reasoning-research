## Root Cause
The decorator 'with_history' in 'scheduler.py' uses a default argument 'history=_shared_log', which is a reference to the module-level list '_shared_log'. This causes all decorated functions to share the same history list, leading to shared scheduler history across different jobs.

## Failure Mechanism
When multiple functions like 'schedule_one' and 'schedule_batch' are decorated with 'with_history', they all append their call records to the same '_shared_log' list. As a result, the history returned by 'get_history' for each function includes entries from all other functions, causing shared scheduler history across jobs.

## Broken Invariant
Each decorated function must have its own independent call history list, so that the call history of 'schedule_one' does not include calls from 'schedule_batch' and vice versa.

## Fix Strategy
Remove the default argument 'history=_shared_log' from the 'with_history' decorator, so that each call to 'with_history' creates a new, independent list for 'history'. This ensures that each decorated function maintains its own separate call history, preventing shared state.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


def with_history(func):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Remove default argument to avoid shared list
    history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)

@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)
