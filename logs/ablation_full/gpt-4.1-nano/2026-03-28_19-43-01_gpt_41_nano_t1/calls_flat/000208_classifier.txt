# Developer's Reasoning

## Root Cause
The process_batch function in pipeline.py was simplified by removing calls to commit(st) and freeze_view(st), which are responsible for updating the 'stable' data and setting the 'frozen' flag in the state. Without these steps, the 'meta.frozen' flag remains False, and the 'stable' data is not updated to reflect the latest committed state.

## Failure Mechanism
When process_batch is called, it updates the 'pending' and 'view' data but does not promote 'pending' to 'stable' or set 'frozen' to True. As a result, functions like get_committed_total and get_committed_digest, which rely on 'meta.frozen' being True to access 'stable' data, return None. This causes the system to behave as if no data has been committed, breaking invariants that depend on the 'frozen' state being correctly set after a commit.

## Broken Invariant
The invariant that 'meta.frozen' is True if and only if 'stable' contains the latest committed data is violated, because the code no longer sets 'frozen' to True after staging data, leading to inconsistent state where 'stable' is outdated or empty despite 'meta.frozen' being True or False.

## Fix Strategy
Reintroduce the commit(st) and freeze_view(st) calls in process_batch to ensure that after staging, the 'pending' data is promoted to 'stable' and the view is rebuilt from 'stable', and the 'frozen' flag is set to True. This restores the invariant that 'meta.frozen' accurately reflects whether 'stable' contains the latest committed data, enabling correct behavior of selectors and other dependent functions.

def normalize(raw):
    return [dict(e) for e in raw]


def collapse(entries):
    merged = {}
    for e in entries:
        merged[e["id"]] = e
    return list(merged.values())


def stage(st, data):
    st["pending"] = list(data)
    st["view"] = list(data)
    st["meta"]["version"] += 1


def commit(st):
    """Promote pending to stable. Sorts by id for canonical ordering. Sets frozen gate."""
    st["stable"] = sorted(st["pending"], key=lambda e: e["id"])
    st["meta"]["frozen"] = True


def freeze_view(st):
    """Rebuild view from committed (stable) data."""
    st["view"] = list(st["stable"])


def materialize(st):
    return list(st["view"])


def get_committed_total(st):
    """Returns total only if state is committed (frozen). None otherwise."""
    if not st["meta"]["frozen"]:
        return None
    return sum(e.get("val", 0) for e in st["stable"])


def get_view_digest(st):
    """Order-sensitive digest of view items."""
    return "|".join(e["id"] for e in st["view"])


def get_committed_digest(st):
    """Order-sensitive digest of committed items."""
    if not st["meta"]["frozen"]:
        return None
    return "|".join(e["id"] for e in st["stable"])
