## Root Cause
The enqueue function uses a mutable default argument 'queue=[]', which is shared across all calls, causing tasks to accumulate unintentionally.

## Failure Mechanism
When enqueue is called multiple times without specifying a queue, tasks from previous calls persist in the default list, leading to unexpected task accumulation and incorrect queue contents.

## Broken Invariant
Each call to enqueue with a single task (and no explicit queue) must return a new list containing only that task, ensuring no tasks from previous calls are included.

## Fix Strategy
Replacing the default argument 'queue=[]' with 'queue=None' and initializing a new list inside the function if 'queue' is None prevents shared state, ensuring each call creates a fresh queue.
