# Developer's Reasoning

## Root Cause
In the place_order function, if wallet.charge() raises a ValueError due to insufficient funds, the inventory reservation made earlier is not released, leading to a reserved inventory that is not actually allocated or sold.

## Failure Mechanism
When place_order reserves inventory and then attempts to charge the wallet, a failure in charging (e.g., insufficient funds) causes an exception to be raised. Since the exception is re-raised without releasing the reserved inventory, the inventory remains reserved indefinitely, causing inconsistency between reserved and available stock.

## Broken Invariant
The reserved inventory should be released if the wallet charge fails, ensuring that reserved and available stock are consistent and no inventory remains reserved without a successful order.

## Fix Strategy
Wrap the wallet.charge() call in a try-except block, and in the except clause, release the reserved inventory before re-raising the exception. This ensures that inventory reservation is always released if the order cannot be completed, maintaining consistency.

"""Order fulfillment with inventory and wallet."""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release on failure.""" 
    inventory.reserve(qty)
    try:
        wallet.charge(qty * price)
    except ValueError:
        inventory.release(qty)
        raise
    return {"status": "confirmed", "qty": qty, "total": qty * price}
