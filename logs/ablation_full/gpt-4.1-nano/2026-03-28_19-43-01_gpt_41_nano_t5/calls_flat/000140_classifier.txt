## Root Cause
The function should_allow in limiter.py uses the expression 'not expired and under_limit or exempt', which relies on Python's operator precedence. This causes the 'exempt' condition to be evaluated only when 'not expired' is True, allowing expired tokens for exempt users to bypass the rate limit.

## Failure Mechanism
When a token is expired (is_expired returns True), the 'not expired' condition becomes False. Due to operator precedence, the expression evaluates as '(False and under_limit) or exempt', which simplifies to 'False or exempt'. If the client is exempt, the function returns True, allowing expired tokens for exempt users, contrary to the intended policy that expired tokens should always be rejected regardless of exemption.

## Broken Invariant
The should_allow function should return False for any expired token, even if the client is exempt, ensuring expired tokens are always rejected regardless of exemption status.

## Fix Strategy
Adding parentheses around '(under_limit or exempt)' in the return statement enforces the correct evaluation order, ensuring that the token is allowed only if it is not expired and either under the limit or exempt. This aligns the code with the intended logic that expired tokens are always rejected, even for exempt clients.

def should_allow(client_id, count, limit, timestamp, now,

    """Decide whether to allow a request.

    Allow if:
      - token is not expired AND (under limit OR exempt)

    Exempt clients bypass the rate limit even if over it,
    but expired tokens are always rejected.
    """
    expired = is_expired(timestamp, now, window_seconds)

    exempt = is_exempt(client_id, exempt_list)

def process_request(request, client_states):
    """Process a request through the rate limiter.

    Args:
        request: dict with 'client_id' and 'timestamp'
        client_states: dict mapping client_id -> {count, first_seen}

    Returns:
        dict with 'allowed' and 'reason'
    """
    client_id = request["client_id"]
    now = request["timestamp"]

    state = client_states.get(client_id, {"count": 0, "first_seen": now})

    allowed = should_allow(

        now=now,
        window_seconds=DEFAULT_WINDOW,
        exempt_list=EXEMPT_CLIENTS,
    )

    if allowed:
        state["count"] = state.get("count", 0) + 1
        client_states[client_id] = state
        return {"allowed": True, "reason": "ok"}

    return {"allowed": False, "reason": "rate_limited"}

def is_expired(timestamp, now, window_seconds):

    """Check if count is under the allowed limit."""
    return count < limit
