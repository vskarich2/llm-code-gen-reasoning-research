# Developer's Reasoning

## Root Cause
The function is_allowed in policy.py uses the 'or' operator to combine check_rate and check_quota, allowing a request if it passes either the rate limit or the quota, rather than requiring both conditions to be satisfied.

## Failure Mechanism
When a request arrives, is_allowed returns True if either the per-minute rate is within limit or the daily quota is not exceeded, even if the other condition is violated. This causes the RateLimiter to permit requests that exceed either the rate limit or the quota, effectively allowing too many requests.

## Broken Invariant
The is_allowed function must only return True if both the rate limit and the daily quota are within bounds, i.e., requests_per_minute < rate_limit AND daily_total < daily_quota.

## Fix Strategy
Changing the logical operator in is_allowed from 'or' to 'and' ensures that a request is only allowed if it passes both the rate and quota checks, restoring the intended enforcement of the combined policy.

class RateLimiter:

        self._daily_count = 0

    def try_request(self):

            self._daily_count, self.daily_quota,
        )
        if allowed:
            self._minute_count += 1
            self._daily_count += 1
        return allowed

    def reset_minute(self):
        """Reset the per-minute counter (called each minute)."""
        self._minute_count = 0

    def get_stats(self):
        """Return current counters."""
        return {
            "minute": self._minute_count,
            "daily": self._daily_count,
        }


"""Rate and quota policy checks."""


def check_rate(requests_per_minute, rate_limit):
    """Return True if rate is within acceptable bounds."""
    return requests_per_minute < rate_limit


def check_quota(daily_total, daily_quota):
    """Return True if daily quota is not exceeded."""
    return daily_total < daily_quota


def is_allowed(requests_per_minute, rate_limit, daily_total, daily_quota):
    """Check if a request is allowed under BOTH rate and quota policies.

    A request should only be allowed if it passes rate AND quota checks.
    """
    rate_ok = check_rate(requests_per_minute, rate_limit)
    quota_ok = check_quota(daily_total, daily_quota)

    return rate_ok and quota_ok
