## Root Cause

Consequently, when apply_config() in middleware.py calls self._base = create_config(), self._base references DEFAULTS. Later, in apply_config(), cfg.update(request_overrides) mutates this shared DEFAULTS reference, causing side effects across all instances and requests.

This mutation alters the original DEFAULTS dictionary, so subsequent requests or default value reads reflect these unintended changes, leading to inconsistent or incorrect configuration behavior.

This change guarantees that apply_config() updates only the request-specific copy, preserving the integrity of DEFAULTS and avoiding side effects across requests.
