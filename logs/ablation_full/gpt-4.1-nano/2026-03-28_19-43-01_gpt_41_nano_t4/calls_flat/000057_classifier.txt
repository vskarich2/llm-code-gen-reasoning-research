# Developer's Reasoning

## Root Cause
The function with_history uses a default argument history=_shared_log, which is set to the module-level list _shared_log. This causes all decorated functions to share the same history list, leading to shared scheduler history across different jobs.

## Failure Mechanism
When multiple functions are decorated with with_history, they all append their call records to the same shared list _shared_log. As a result, the scheduler's history for schedule_one and schedule_batch is not isolated; calls from one affect the other's history, causing incorrect or confusing tracking of individual function call histories.

## Broken Invariant
Each decorated function must maintain its own independent call history list, so that the call history of schedule_one does not include calls from schedule_batch, and vice versa.

## Fix Strategy
Changing the default argument of with_history from the shared module-level list _shared_log to None, and initializing a new list inside the wrapper function if history is None, ensures each decorated function has its own separate history list. This prevents shared state and maintains the invariant that each function's call history is independent.

from worker import process, batch_process

_shared_log = []

def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Fix: default argument changed from _shared_log to None.

    def wrapper(*args, **kwargs):
        nonlocal history
        if history is None:
            history = []
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper

@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)

@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)
