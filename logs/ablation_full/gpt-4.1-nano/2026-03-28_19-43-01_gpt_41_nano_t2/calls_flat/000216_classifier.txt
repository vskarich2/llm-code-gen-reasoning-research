# Developer's Reasoning

## Root Cause
The function make_withdraw_steps creates separate check and act steps that do not coordinate to prevent overdraft. Specifically, the check_balance function verifies sufficient funds before withdrawal, but between the check and the do_withdraw call, the account balance can be modified by other interleaved steps, leading to multiple approvals and overdrafts. This is exacerbated by the interleaving order in interleaved_withdrawals, where both checks pass before either withdrawal occurs, resulting in both withdrawals being approved even when the initial balance is insufficient for both.

## Failure Mechanism
In interleaved_withdrawals, the sequence runs check_a (approves withdrawal of 80), check_b (also approves, since balance is still 100), then both act steps execute, each subtracting 80, leading to a final balance of -60. This occurs because the check steps do not lock or reserve funds, and the withdrawal steps execute after both checks have passed, allowing overdraft to occur despite initial sufficient balance at the time of each check.

## Broken Invariant
The account balance must never become negative after any sequence of withdrawals, regardless of interleaving, provided each withdrawal was approved based on the balance at the time of check.

## Fix Strategy
Modify make_withdraw_steps to perform the check and withdrawal atomically within a single function, ensuring that the balance is checked and decremented in one step, preventing interleaving from causing overdrafts. This can be achieved by combining check and do_withdraw into a single step that verifies the current balance and performs the withdrawal only if sufficient funds remain, thus maintaining the invariant that the balance never goes negative.

_accounts = {}


def reset():
    _accounts.clear()


def create_account(name, balance):

def get_balance(name):
    return _accounts.get(name, 0)


def check_balance(name, amount):
    """CHECK: is balance sufficient?"""
    return _accounts.get(name, 0) >= amount


def do_withdraw(name, amount):
    """ACT: decrement balance. Assumes caller verified."""
    _accounts[name] = _accounts.get(name, 0) - amount


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_withdraw_steps(name, amount):
    """Split withdrawal into separate check and act steps.

    BUG: under interleaving, both checks pass before either debits.
    """
    result = {"approved": False}

    def step_check():
        result["approved"] = check_balance(name, amount)
        return ("check", result["approved"])

    def step_act():
        if result["approved"]:
            do_withdraw(name, amount)
        return ("act", result["approved"])

    return step_check, step_act


def sequential_withdrawals():
    """Two withdrawals of 80 from balance=100. Sequential: second denied."""
    reset()
    create_account("alice", 100)
