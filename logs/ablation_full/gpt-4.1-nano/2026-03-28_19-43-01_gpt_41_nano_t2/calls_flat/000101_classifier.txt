# Developer's Reasoning

## Root Cause
In the order_service.py, the place_order function calls reserve() to reserve inventory but does not call release() to undo the reservation if the payment fails. This occurs because the exception handling block re-raises the exception without releasing the reserved inventory, leaving the reservation in place.

## Failure Mechanism
When a payment failure occurs during place_order, the exception is caught and re-raised without releasing the reserved inventory. As a result, the inventory remains reserved even though the payment was unsuccessful, causing the inventory to be stuck as reserved after a failed payment.

## Broken Invariant
After a payment failure during place_order, the reserved inventory for the product should be released, ensuring that available stock reflects the actual inventory and no reservations remain for failed transactions.

## Fix Strategy
Adding a call to release(product_id, qty) inside the except block in place_order ensures that the reservation is undone if payment processing fails, maintaining the invariant that reservations are only held for successful payments.

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        release(product_id, qty)
        raise  # Re-raise after releasing reservation
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
