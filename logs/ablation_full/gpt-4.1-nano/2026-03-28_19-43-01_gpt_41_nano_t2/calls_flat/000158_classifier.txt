In report.py, the delete_column method removes the header at the specified index but does not remove the corresponding element from each row in self.rows, causing misalignment of columns after deletion.

## Failure Mechanism
When delete_column is called, the header list shrinks but the data rows retain their original length, so subsequent rendering or data access based on headers and rows will be misaligned, with data in incorrect columns.

## Broken Invariant
After delete_column is called, the length of each row in self.rows must match the length of self.headers, ensuring that each header corresponds to exactly one element in each row.

## Fix Strategy
Adding code to delete the element at the specified index from each row in self.rows ensures that headers and data rows are consistently aligned after column removal, maintaining the invariant.

class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Remove the header at the specified index
        del self.headers[index]
        # Remove the element at the same index from each row
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
