# Developer's Reasoning

## Root Cause
In create_config, the local variable 'config' is assigned directly to the module-level dict DEFAULTS (config = DEFAULTS). Because dicts are mutable, calling config.update(overrides) mutates DEFAULTS itself; the function returns a reference to the shared DEFAULTS object instead of returning a fresh configuration dict.

## Failure Mechanism
If a caller does create_config({'debug': True}), create_config sets config = DEFAULTS and then config.update({'debug': True}), which updates DEFAULTS['debug'] to True. A subsequent call to create_config() with no overrides will return a dict that already has 'debug': True even though callers expected the original default of False. This can also silently change DEFAULTS for other modules that import it, causing unexpected state to leak across call sites.

## Broken Invariant
create_config(overrides) must not mutate module-level DEFAULTS; after calling create_config with any overrides, DEFAULTS must remain equal to {'timeout': 30, 'retries': 3, 'debug': False}. Concretely, assert create_config({'debug': True}) != DEFAULTS and assert DEFAULTS == {'timeout': 30, 'retries': 3, 'debug': False} must hold.

## Fix Strategy
Return a fresh dict copy of DEFAULTS and apply overrides to that copy so DEFAULTS is never mutated by create_config. Implemented by using DEFAULTS.copy() when building the returned config. Also make reset_defaults perform an in-place update of the DEFAULTS mapping (clear() + update()) to avoid breaking external references to the DEFAULTS object while restoring the original values.

DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    """Return a new config dict based on DEFAULTS, applying optional overrides.

    This function deliberately returns a new dict so callers can mutate
    the returned config without affecting the module-level DEFAULTS.
    """
    # Use a shallow copy because DEFAULTS holds only primitive values.
    config = DEFAULTS.copy()
    if overrides:
        config.update(overrides)
    return config


def reset_defaults():
    """Restore the module-level DEFAULTS to the original factory values.

    This performs an in-place mutation (clear + update) so that any external
    code holding a reference to the DEFAULTS dict continues to see the
    updated values rather than having its reference replaced.
    """
    DEFAULTS.clear()
    DEFAULTS.update({"timeout": 30, "retries": 3, "debug": False})
