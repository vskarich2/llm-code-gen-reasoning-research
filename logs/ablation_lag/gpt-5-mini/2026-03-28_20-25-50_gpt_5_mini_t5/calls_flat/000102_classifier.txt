# Developer's Reasoning

## Root Cause
In order_service.place_order, the except block for payment failure re-raises the ValueError without calling release(product_id, qty). The call to reserve(product_id, qty) increments inventory._reserved but there is no compensating call to release when _process_payment raises, leaving inventory._reserved higher than it should be.

## Failure Mechanism
Example: inventory.add_product('widget', 10) sets stock to 10 and reserved 0. place_order('widget', 2, price) calls reserve('widget', 2) so inventory._reserved becomes 2. If set_gateway_fail(True) causes _process_payment to raise ValueError, the except block currently executes 'raise' without calling release('widget', 2). As a result _reserved['widget'] remains 2 even though the order failed and payment was not captured, so available('widget') reports 8 less than actual available stock.

## Broken Invariant
If place_order(product_id, qty, ...) raises a ValueError due to payment failure, then get_reserved(product_id) must equal its value before the call to place_order. Currently get_reserved(product_id) increases by qty and is not decremented on payment failure, violating this invariant.

## Fix Strategy
Call release(product_id, qty) inside the except handler before re-raising the payment error. This compensating action undoes the prior reserve(product_id, qty) so inventory._reserved is restored to its previous value, preserving the invariant that failed orders do not leave reservations. The change only adds the release call and re-raises the same ValueError to preserve original error behavior.

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Ensure we release the inventory reservation before propagating the payment error
        release(product_id, qty)
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
