# Developer's Reasoning

## Root Cause
In worker.py, the function process_batch defines the parameter seen with a mutable default value seen=set(). Because default argument values are evaluated once at function definition time, the same set object is reused across multiple calls to process_batch, causing state to persist between invocations.

## Failure Mechanism
On the first call process_batch([{"name": "A"}, {"name": "B"}]) the code adds 'A' and 'B' to the default seen set and returns both as processed. On a subsequent call process_batch([{"name": "A"}, {"name": "C"}]) the persistent seen set already contains 'A', so the code skips 'A' (if task_id in seen: continue) and returns only 'C' as processed. Thus valid tasks present in the new batch are omitted because their names were recorded in the previously persisted seen set.

## Broken Invariant
When called without an explicit seen argument (i.e., using the default), process_batch(tasks) must return a results list containing one processed entry for every element in the provided tasks list (i.e., it must process all tasks in that batch regardless of prior calls). Currently, repeated calls with overlapping task names can cause missing processed entries.

## Fix Strategy
Change the default for seen to None and create a fresh set inside the function when seen is None. This makes each invocation that doesn't supply a seen argument use a new, per-call set, preventing cross-call persistence. Concretely, replaced the signature seen=set() with seen=None and added: if seen is None: seen = set(). This ensures prior calls cannot cause tasks in a later call to be skipped.

"""Worker that processes task batches."""

from queue import create_task


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
