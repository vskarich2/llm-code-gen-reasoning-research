# Developer's Reasoning

## Root Cause
In catalog.update_product the function invalidates the shared cache by calling invalidate_shared(product_id) but does not call invalidate_local(product_id). As a result, the per-process/module local cache (cache._local) can continue to hold the old product dict. api.get_product always checks get_local(product_id) first and will return that stale value if present.

## Failure Mechanism
Example sequence: add_product(42, 'Widget', 10) -> a consumer calls get_product(42) which misses local, misses shared, reads DB and then put_shared(42, {...}) and put_local(42, {...}) so cache._local[42] now contains the product. Later update_product(42, price=12) updates _db[42] and calls invalidate_shared(42) but does not remove cache._local[42]. A subsequent get_product(42) calls get_local(42) first, finds the old dict in cache._local and returns it, so callers see price 10 instead of the updated price 12.

## Broken Invariant
Invariant in catalog.update_product is: after update_product(product_id) returns True, all cache layers for that key must be invalidated. Concretely, for the updated product_id both get_local(product_id) and get_shared(product_id) must return None so that get_product(product_id) cannot return pre-update data.

## Fix Strategy
Call invalidate_local(product_id) from catalog.update_product immediately after updating the DB (and alongside invalidate_shared). This removes the stale entry from cache._local so subsequent api.get_product calls cannot return the old value; they will miss local and either hit shared or DB and then repopulate local with fresh data. The change is a single added call to invalidate_local(product_id) in update_product.

```python
"""Product catalog with two-layer cache integration."""

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Invalidate both shared and local caches so no stale data remains.
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()

```
