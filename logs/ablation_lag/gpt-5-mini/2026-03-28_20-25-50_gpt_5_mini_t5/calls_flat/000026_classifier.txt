## Root Cause
The bug is in update_product: the function updates the persistent store _db but does not update or invalidate the cached snapshot in _cache. Because update_product only mutates _db and leaves _cache untouched, subsequent calls to get_product may return the stale dictionary stored in _cache instead of the new data in _db.

## Failure Mechanism
Concrete scenario: add_product('p1', name='Widget', price=10) stores {'name': 'Widget', 'price': 10} in _db. A call to get_product('p1') caches a snapshot of that data in _cache. Then update_product('p1', price=15) updates _db['p1']['price'] to 15 but does not touch _cache. A later get_product('p1') finds an entry in _cache and returns the old snapshot with price 10, so callers observe the outdated price instead of the updated price 15.

## Broken Invariant
After update_product(product_id, **fields) returns True for an existing product_id, get_product(product_id) must return the product fields reflecting the updated values from _db. Formally: if update_product(pid, price=X) returns True, then get_product(pid)['price'] == X.

## Fix Strategy
Make cache consistent with _db whenever the database is changed and avoid returning the internal cached object directly. Changes made: (1) update_product now replaces the _cache entry with a fresh snapshot (dict(_db[product_id])) immediately after updating _db, ensuring get_product observes the update. (2) get_product always returns a shallow copy of the cached snapshot (dict(_cache[product_id]) or dict(snapshot)) so callers cannot mutate the cached object. (3) add_product also seeds the cache with the initial snapshot to keep _db and _cache in sync. These changes close the window where _db and _cache can diverge and ensure the invariant holds.

```python
"""Product catalog with caching.

The cache stores snapshots of product records. Functions maintain the
invariant that get_product() reflects the current database state
for existing products by keeping the cache updated and by returning
copies so callers cannot mutate internal cached objects.
"""

_db = {}
_cache = {}


def add_product(product_id, name, price):
    """Add a product to the database and seed the cache with a snapshot."""
    _db[product_id] = {"name": name, "price": price}
    # Ensure cache is consistent with the newly added product
    _cache[product_id] = dict(_db[product_id])


def get_product(product_id):
    """Return a snapshot of the product data or None if not present.

    Always return a fresh dict copy so callers cannot mutate the cached snapshot.
    """
    if product_id in _cache:
        return dict(_cache[product_id])
    product = _db.get(product_id)
    if product is None:
        return None
    snapshot = dict(product)
    _cache[product_id] = snapshot
    return dict(snapshot)


def update_product(product_id, **fields):
    """Update product fields in the database and refresh the cache.

    Invariant: get_product() must return current data after update.
    Returns True when update succeeds, False if product not found.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Replace cached snapshot with updated data so get_product sees changes
    _cache[product_id] = dict(_db[product_id])
    return True


def reset():
    """Clear all data and caches."""
    _db.clear()
    _cache.clear()

```
