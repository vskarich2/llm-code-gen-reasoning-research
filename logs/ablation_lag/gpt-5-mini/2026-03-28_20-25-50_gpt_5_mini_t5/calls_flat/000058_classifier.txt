## Root Cause
In code_snippets_v2/mutable_default_c/scheduler.py the decorator function with_history uses the default argument history=_shared_log, where _shared_log is a module-level list. Default argument values are evaluated at function definition time, so every call to with_history that doesn't provide a history argument closes over the same _shared_log list. As a result, the variable history inside each wrapper refers to the same shared list.

## Failure Mechanism
Because history defaulted to the single module-level list, both decorated functions schedule_one and schedule_batch append entries into the same list. For example, if schedule_one is called once and schedule_batch is called once, schedule_one.get_history() will contain two entries (one for the schedule_one call and one for the schedule_batch call) instead of only the schedule_one call. get_all_stats() then reports incorrect per-function counts because it computes lengths of these mixed histories.

## Broken Invariant
Invariant: each decorated function must have its OWN independent history list. Concretely, after calling schedule_one twice and schedule_batch once, len(schedule_one.get_history()) must equal 2 and len(schedule_batch.get_history()) must equal 1. With the current code both lengths reflect the combined number of calls and thus violate this invariant.

## Fix Strategy
I changed with_history to avoid using the module-level _shared_log as a default. The decorator now accepts an optional history argument defaulting to None; if None it creates a fresh empty list for each decoration, ensuring each decorated function captures its own independent history list. I also added a small helper path so the decorator can still be used either as @with_history or as @with_history(history=...). The wrapper continues to expose get_history() and clear_history() that operate on the captured, per-function history list.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process

_shared_log = []


def with_history(func=None, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.

    Usage:
    - @with_history
    - @with_history(history=some_list)
    """
    # If used as @with_history(...) return a decorator that will be
    # called with the function.
    if func is None:
        def decorator(f):
            return with_history(f, history=history)
        return decorator

    # Ensure each decorated function gets its own history list unless an
    # explicit history list was provided.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }
