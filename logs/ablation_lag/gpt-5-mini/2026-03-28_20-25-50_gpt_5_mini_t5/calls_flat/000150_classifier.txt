# Developer's Reasoning

## Root Cause
In payment.process_payment the function returns early when txn_id is found in the module-level cache _cache. That early return happens before calling ledger.record, so duplicate calls do not call record(txn_id, ...). The specific variables/functions involved are payment.process_payment, payment._cache, and ledger.record.

## Failure Mechanism
If process_payment is called twice with the same txn_id, the first call stores a result in _cache and calls record(...) once. On the second call payment.process_payment finds txn_id in _cache and returns immediately, skipping record(...). The net effect is two process_payment calls but only one ledger entry; calling ledger.verify(2) will return False because len(_entries) == 1.

## Broken Invariant
For any number N of calls to process_payment (including repeated calls with the same txn_id), the ledger must contain exactly N entries. Concretely: after calling process_payment N times, verify(N) must return True (i.e. len(_entries) == N).

## Fix Strategy
Instead of returning before recording when a duplicate txn_id is seen, the code now records a ledger entry for the duplicate call and then returns the cached result. Concretely, when txn_id is in _cache the code looks up the cached result, calls record(txn_id, cached["amount"], "duplicate"), and then returns cached. This guarantees that every invocation of process_payment results in exactly one call to ledger.record, restoring the invariant that ledger entry count equals number of calls.

```python
"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    if txn_id in _cache:
        # Record the duplicate call so the ledger count matches number of calls.
        cached = _cache[txn_id]
        # Use a 'duplicate' status for repeated attempts.
        record(txn_id, cached["amount"], "duplicate")
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()

```
