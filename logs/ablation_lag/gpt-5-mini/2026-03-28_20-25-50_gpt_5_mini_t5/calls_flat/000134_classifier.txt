# Developer's Reasoning

## Root Cause
The function is_rate_limited(count, limit) uses the wrong comparison operator: it returns count > limit instead of checking count >= limit. Because the code treats the variable 'count' as the number of requests already made, when count == limit the function incorrectly reports 'not rate limited' and allows one extra request.

## Failure Mechanism
Example: limit = 10. After 10 allowed requests the stored count becomes 10. Calling check_and_increment(10, 10) calls is_rate_limited(10, 10), which evaluated with '>' returns False (10 > 10 is False). check_and_increment then treats the client as not blocked and returns (False, 11), thereby permitting an 11th request even though the configured limit is 10.

## Broken Invariant
The limiter must block when the stored request count is greater than or equal to the configured limit. More precisely: for any non-negative integers current_count and limit, check_and_increment(current_count, limit) must return (True, current_count) whenever current_count >= limit.

## Fix Strategy
Change the comparison in is_rate_limited from '>' to '>=' so that a count equal to limit is considered rate-limited. I also clarified parameter naming and docstrings so the semantics (current_count = requests already made; limit = maximum allowed requests) are explicit; check_and_increment now uses those names and preserves the behavior of only incrementing when not blocked.

"""Simple rate limiter."""

from typing import Tuple


def is_rate_limited(current_count: int, limit: int) -> bool:
    """Return True when the caller has reached or exceeded the allowed requests.

    Semantics:
    - current_count is the number of requests that have already been made.
    - limit is the maximum allowed requests.

    A caller must be blocked when current_count >= limit.
    """
    # Correct comparison: block when the stored count is greater than or equal to the limit.
    return current_count >= limit


def check_and_increment(current_count: int, limit: int) -> Tuple[bool, int]:
    """Check rate limit and return (blocked, new_count).

    If not blocked, increments the count and returns (False, current_count + 1).
    If blocked, returns (True, current_count) without changing the count.
    """
    if is_rate_limited(current_count, limit):
        return True, current_count
    return False, current_count + 1
