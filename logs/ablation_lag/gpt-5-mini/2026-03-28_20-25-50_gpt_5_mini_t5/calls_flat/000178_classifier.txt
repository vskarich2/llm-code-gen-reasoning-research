## Root Cause
In code_snippets_v2/silent_default_c/flags.py the env var key for the 'dark_mode' flag is misspelled in _ENV_KEY_MAP as 'FEATURE_DARKMODE' (missing underscore), so the environment lookup never finds the intended 'FEATURE_DARK_MODE'. Separately, is_enabled() calls get_env_bool(env_key) and then tests its truthiness (if env_val: return True), which only returns when the env var is True; if the env var is explicitly set to a falsey value the function does not treat that as an override and falls through to read the config. Both the wrong key string and the truthiness check together cause environment overrides to be ignored.

## Failure Mechanism
Example: the simulated environment _ENV contains "FEATURE_DARK_MODE": "false". _ENV_KEY_MAP currently maps 'dark_mode' -> 'FEATURE_DARKMODE', so get_env_bool('FEATURE_DARKMODE') calls get_env('FEATURE_DARKMODE') and receives None, which get_env_bool converts to its default False. Even if the map were correct, when an env var exists but is 'false', get_env_bool returns False; the current code does 'if env_val: return True' so a False env_val does not short-circuit. Consequently the function continues to call get_config_bool('dark_mode') which returns True (from _FILE_CONFIG), and is_enabled() returns True despite the environment explicitly disabling the flag. So an explicit env=false does not override the config.

## Broken Invariant
When an environment variable for a flag is present, is_enabled(flag_name) must return the boolean interpretation of that environment variable (i.e., env presence must take precedence over config and hardcoded defaults). Concretely: if the environment contains FEATURE_DARK_MODE set to 'false', then is_enabled('dark_mode') must return False.

## Fix Strategy
I fixed the env key typo in _ENV_KEY_MAP to the correct 'FEATURE_DARK_MODE' and changed is_enabled() to first detect env presence via get_env(env_key). If an env var is present (get_env(...) is not None), the function returns get_env_bool(env_key) (True or False) immediately. If no env var is present, it checks for the config presence via get_config(flag_name) and returns get_config_bool(flag_name) only when config is present; otherwise it falls back to the hardcoded default. This uses get_env/get_config presence checks to distinguish "not present" from an explicit false value and enforces the env -> config -> hardcoded precedence.

  1. Environment variable (via env.get_env_bool)

  3. Hardcoded defaults
"""

from config import get_config, get_config_bool


HARDCODED_DEFAULTS = {
    "dark_mode": False,
    "beta": False,
    "analytics": False,
}

# Maps flag names to their env var keys
_ENV_KEY_MAP = {
    "dark_mode": "FEATURE_DARK_MODE",
    "beta": "FEATURE_BETA",
    "analytics": "FEATURE_ANALYTICS",
}


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Checks env first, then config, then hardcoded defaults.
    """
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        # Use get_env to detect presence vs absence. If present, return its boolean value
        # (this covers both True and False env overrides).
        if get_env(env_key) is not None:
            return get_env_bool(env_key)

    # Check whether config explicitly provides the flag; if so, return its boolean value.
    if get_config(flag_name) is not None:
        return get_config_bool(flag_name)

    return HARDCODED_DEFAULTS.get(flag_name, False)


def get_flag_source(flag_name):
    """Return which layer provides the flag value (for debugging)."""
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        if get_env(env_key) is not None:
            return "env"

    if get_config(flag_name) is not None:
        return "config"

    return "hardcoded"
