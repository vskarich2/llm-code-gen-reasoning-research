# Developer's Reasoning

## Root Cause
In report.py the method Report.delete_column removes only the header element via del self.headers[index] but does not remove the corresponding element from each row in self.rows. The causal relationship is that delete_column updates self.headers but leaves self.rows unchanged, so headers and rows become length-mismatched and misaligned.

## Failure Mechanism
Given headers = ['A','B','C'] and rows = [[1,2,3],[4,5,6]], calling Report.delete_column(1) executes del self.headers[1] producing headers = ['A','C'] while rows remain [[1,2,3],[4,5,6]]. Later Report.render zips headers with each row producing {'A':1,'C':2} for the first row and {'A':4,'C':5} for the second row — the header 'C' is incorrectly paired with the original column value 2/5 instead of 3/6, demonstrating misalignment.

## Broken Invariant
After calling Report.delete_column(i), for every row in report.rows the length of the row must equal len(report.headers) and for every valid column index j the value report.rows[r][j] must correspond to report.headers[j]. Specifically: len(row) == len(report.headers) for all row in report.rows and dict(zip(report.headers,row)) must map each header to its original corresponding column value.

## Fix Strategy
Fix delete_column so it removes the element at index from each row as well as from self.headers. The implementation retains the original IndexError behavior by performing del self.headers[index] and then iterating over self.rows and performing del row[index] for each row. Removing the per-row element ensures lengths stay equal and that zip(self.headers, row) continues to pair each header with its intended column value.

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Remove header first (preserves original IndexError behavior)
        del self.headers[index]
        # Also remove the corresponding element from each row to keep rows aligned
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
