# Developer's Reasoning

## Root Cause
In auth.py the dispatch table _ROLE_DISPATCH omitted the key 'guest', so the variable _ROLE_DISPATCH does not map the 'guest' role to the guest_access function. As a result, get_access(role) looks up 'guest' in _ROLE_DISPATCH and falls back to the _default_access handler instead of calling roles.guest_access().

## Failure Mechanism
When code calls get_access('guest') or can_read('guest'), get_access uses handler = _ROLE_DISPATCH.get(role, _default_access). Because 'guest' is not a key in _ROLE_DISPATCH, handler becomes _default_access and returns {'read': False, 'write': False, 'delete': False}. This causes callers to observe no permissions for guest users even though roles.guest_access() in roles.py defines read-only access.

## Broken Invariant
For every role string defined in roles.py (specifically 'guest'), get_access(role) must return the access dict produced by the corresponding access function (i.e., get_access('guest') == guest_access()). Currently get_access('guest') != guest_access(), violating the invariant that known roles are dispatched to their corresponding handlers.

## Fix Strategy
Add the missing 'guest' entry to the _ROLE_DISPATCH mapping so get_access will invoke guest_access for the 'guest' role instead of falling back to _default_access. This ensures get_access('guest') returns the dict from guest_access() (read: True, write: False, delete: False).

```python
"""Authentication and authorization dispatch."""

from roles import admin_access, user_access, moderator_access, guest_access


# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {
    "admin": admin_access,
    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access,
}


def _default_access():
    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)

```
