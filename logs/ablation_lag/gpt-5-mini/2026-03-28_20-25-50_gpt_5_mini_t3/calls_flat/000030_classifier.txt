## Root Cause
In code_snippets_v2/stale_cache_b/catalog.py the function update_product updates the in-memory DB entry _db[product_id] but does not call invalidate(product_id). Because the module-level cache is managed by cache.invalidate and catalog.py imported invalidate at the top, the missing call means the cached value in cache._store for that product_id remains the old dictionary while the DB has the new price.

## Failure Mechanism
Sequence demonstrating the failure: add_product(1, 'Widget', 100) stores _db[1] = {'name': 'Widget', 'price': 100}. get_product(1) sees no cache, reads product = _db[1] and put(1, dict(product)) stores {'name': 'Widget', 'price': 100} in the cache. update_product(1, price=150) executes _db[1].update({'price': 150}) but does not call invalidate(1), so the cache still holds {'name': 'Widget', 'price': 100}. A subsequent get_product(1) checks get(1), finds the stale cached dict, and returns it, so callers see price 100 instead of the updated 150.

## Broken Invariant
The function-level invariant in update_product's docstring: 'subsequent get_product() must reflect the update' is violated. Concretely, after update_product(product_id, price=new_price) returns True, calling get_product(product_id)['price'] must equal new_price; with the bug it can return the old price.

## Fix Strategy
After updating the DB entry, explicitly invalidate the cached entry for that product_id by calling invalidate(product_id). This removes the stale cached value from cache._store so the next get_product call will fetch the updated dict from _db and repopulate the cache with the current values. The change is minimal, uses the already-imported invalidate function, and restores the stated invariant.

"""Product catalog using external cache module."""

from cache import get, put, invalidate

_db = {}


def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Invalidate cache so subsequent get_product() returns the updated data
    invalidate(product_id)
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()
