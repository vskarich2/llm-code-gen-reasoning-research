# Developer's Reasoning

## Root Cause
In process_batch(), the function increments the module-level variable _counter for each item but calls snapshot() only once after the loop. As a result, the module list _snapshots is appended only a single time (with the final _counter value) instead of once per processed item.

## Failure Mechanism
For example, calling process_batch([1, 2, 3]) causes the loop to add 1, then 2, then 3 to _counter (ending at 6), but snapshot() is invoked only after the loop. That appends a single entry (6) into _snapshots. The code therefore produces len(_snapshots) == 1 while three items were processed, breaking the expectation that each item produces one snapshot.

## Broken Invariant
After calling process_batch(items), the number of recorded snapshots must equal the number of processed items (i.e., len(_snapshots) == number_of_processed_items).

## Fix Strategy
I moved snapshot() into the per-item loop inside process_batch so a snapshot is recorded immediately after each increment. I also introduced and maintain _processed_count to track how many items have been processed and changed verify_consistency() to return a boolean comparing len(_snapshots) to _processed_count. These changes ensure one snapshot per item and make the consistency check explicit.

```python
 """Batch processor with per-item snapshots."""

from typing import Iterable, List

_counter = 0
_snapshots: List[int] = []
_processed_count = 0


def reset():
    global _counter, _snapshots, _processed_count
    _counter = 0
    _snapshots = []
    _processed_count = 0


def snapshot():
    """Record the current counter value."""
    _snapshots.append(_counter)


def get_snapshots():
    return list(_snapshots)


def process_batch(items: Iterable[int]):
    """Process each item: increment counter and snapshot after each item.

    For each item in items, the global counter is incremented by the item's
    value and a snapshot of the counter is recorded immediately after.
    Returns the final counter value.
    """
    global _counter, _processed_count
    for item in items:
        _counter += item
        _processed_count += 1
        snapshot()
    return _counter


def verify_consistency():
    """Return True when each processed item produced exactly one snapshot.

    The invariant: number of snapshots == number of processed items.
    """
    return len(_snapshots) == _processed_count

```
