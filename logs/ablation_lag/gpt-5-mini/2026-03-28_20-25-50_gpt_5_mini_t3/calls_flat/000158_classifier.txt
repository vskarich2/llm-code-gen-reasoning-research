# Developer's Reasoning

## Root Cause
In add_entry, when position is provided the code calls _labels.insert(position, label) but mistakenly calls _values.append(value) instead of inserting the value at the same index. The causal relationship is that the two parallel lists (_labels and _values) are modified with different operations (insert vs append), which causes the label and value lists to become out of sync.

## Failure Mechanism
Example: start with _labels = ['A', 'B'] and _values = [1, 2]. Calling add_entry('X', 0, position=1) executes _labels.insert(1, 'X') producing ['A', 'X', 'B'], but uses _values.append(0) producing [1, 2, 0]. As a result get_entry(1) returns ('X', 2) instead of the expected ('X', 0), i.e., the inserted label is paired with the wrong value.

## Broken Invariant
The module promises that for every valid index i the stored label and value are the pair that were added together at index i. Formally: for any i in 0..count()-1, get_entry(i) == (labels_i, values_i) where labels_i and values_i are the label and value that were inserted/added at that position. After the buggy add_entry this invariant can be falsified (e.g., after an insertion the label at position p will not necessarily pair with the value that was inserted for that position).

## Fix Strategy
Replace the incorrect _values.append(value) used in the insertion branch with _values.insert(position, value) so both _labels and _values are mutated at the same index. I also clarified the code with type hints and a single consistent insertion/append path so it's obvious that labels and values are always updated together. This ensures that inserting at a given index preserves the label/value pairing and keeps the lists aligned.

- reset()

The implementation ensures the two lists are always updated at the same index so pairs remain aligned.
"""
from typing import Any, List, Optional, Tuple

_labels: List[str] = []
_values: List[Any] = []


def add_entry(label: str, value: Any, position: Optional[int] = None) -> None:
    """Add an entry to the report.

    If position is given, insert both label and value at that index so they remain aligned.
    Otherwise, append both to the ends of their respective lists.
    """
    if position is None:
        _labels.append(label)
        _values.append(value)
    else:
        # Insert both label and value at the same index to keep the parallel lists aligned.
        _labels.insert(position, label)
        _values.insert(position, value)


def get_entry(index: int) -> Tuple[str, Any]:
    """Return (label, value) at the given index."""
    return (_labels[index], _values[index])


def get_all() -> List[Tuple[str, Any]]:
    """Return list of (label, value) tuples."""
    return list(zip(_labels, _values))


def count() -> int:
    """Return the number of entries."""
    return len(_labels)


def reset() -> None:
    """Clear all entries."""
    _labels.clear()
    _values.clear()
