# Developer's Reasoning

## Root Cause
The bug is in the module-level variable _default_host and get_host(). _default_host is assigned once at import time from _settings (line: _default_host = _settings["host"]) and get_host() returns that captured value. Because _default_host is not updated when configure() mutates _settings, get_host() can return a stale host.

## Failure Mechanism
On import, _default_host is set to the initial value 'localhost'. If configure(host='example.com') is later called, configure() updates _settings['host'] to 'example.com' but get_host() still returns the earlier captured _default_host, producing 'localhost' instead of 'example.com'. For example: import service; service.configure(host='example.com'); service.get_host() -> 'localhost' (incorrect) instead of 'example.com'.

## Broken Invariant
After calling configure(host=NEW_HOST) or reset_settings(), get_host() must return the current value of _settings['host']. Formally testable: calling configure(host='x') followed by get_host() must return 'x', and after reset_settings(), get_host() must return the initial default host.

## Fix Strategy
Removed the eagerly captured _default_host and made get_host() read the current value directly from the mutable _settings mapping. Introduced a single _DEFAULT_SETTINGS constant to avoid duplicating the default literal and to make reset_settings() reinitialize _settings to a fresh copy of those defaults. These changes ensure get_host() always reflects the latest _settings state and that reset_settings() restores the documented defaults.

    """Return the current host setting.

    always reflects the most recent configure() or reset_settings() call.
    """
    return _settings["host"]


def get_settings():
    """Return a copy of the current settings dict."""
    return dict(_settings)


def reset_settings():
    """Reset settings to the default values.

    Replaces the module _settings with a fresh copy of _DEFAULT_SETTINGS so
    callers that mutate the returned dict from get_settings() cannot affect
    the module-level defaults.
    """
    global _settings
    _settings = dict(_DEFAULT_SETTINGS)


def configure(host=None, port=None, debug=None):
    """Update settings.

    Only provided arguments are applied; others are left unchanged.
    """
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
        _settings["debug"] = debug
