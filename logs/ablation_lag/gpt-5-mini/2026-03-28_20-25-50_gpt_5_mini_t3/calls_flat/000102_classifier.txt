# Developer's Reasoning

## Root Cause
In place_order (order_service.py) the reserve(product_id, qty) call increments inventory._reserved (in inventory.py) but the except ValueError branch simply re-raises the payment error without calling release(product_id, qty). As a result the inventory._reserved entry that was created/updated by reserve is never decremented when payment fails.

## Failure Mechanism
Concrete scenario: set_gateway_fail(True); call place_order('sku-1', 2, 10). place_order calls reserve('sku-1', 2) which sets inventory._reserved['sku-1'] += 2. Then _process_payment raises ValueError('payment declined'). The except ValueError block executes and re-raises the same ValueError without calling release('sku-1', 2). Because release is not called, inventory.get_reserved('sku-1') remains increased by 2 even though the order was not completed. Subsequent calls to available('sku-1') will report less available stock and the reservation is permanently stuck.

## Broken Invariant
If place_order raises a payment error for product_id with requested qty, then inventory.get_reserved(product_id) must be the same after place_order returns (i.e., the reservation performed for the failed attempt must be rolled back). Concretely: for any product_id and qty, if place_order(product_id, qty, price) raises ValueError due to payment, then get_reserved(product_id) after the call equals get_reserved(product_id) before the call.

## Fix Strategy
Release the inventory reservation when payment fails. I added a call to release(product_id, qty) inside the except ValueError handler in place_order so that any reservation created by reserve is undone before re-raising the payment error. This ensures inventory._reserved is decremented and restores the invariant that failed orders do not leave outstanding reservations.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Ensure reservation is released when payment fails
        release(product_id, qty)
        raise  # re-raise after cleanup
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
