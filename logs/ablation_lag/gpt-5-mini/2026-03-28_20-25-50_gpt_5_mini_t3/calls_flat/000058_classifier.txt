# Developer's Reasoning

## Root Cause
In code_snippets_v2/mutable_default_c/scheduler.py the decorator function with_history defines a default parameter history=_shared_log where _shared_log is a module-level list. Because default parameter values are evaluated once at function definition time, every time with_history is used as @with_history the same _shared_log list is captured and shared across all decorated functions.

## Failure Mechanism
When schedule_one and schedule_batch are decorated with @with_history they both get wrappers that append to the same list referred to by the history default. For example, calling schedule_one(task) appends an entry to that shared list; subsequently calling schedule_batch([task]) appends another entry to the same list. As a result schedule_one.get_history() and schedule_batch.get_history() both return a list containing both entries instead of each returning only their own calls.

## Broken Invariant
The module-level comment / invariant in with_history states: 'each decorated function must have its OWN independent history list.' This is violated: after calling schedule_one once and not calling schedule_batch, schedule_one.get_history() and schedule_batch.get_history() must return different lengths (1 and 0 respectively). With the current code they both return the same combined history length.

## Fix Strategy
Remove the mutable default history parameter and create a fresh history list inside the decorator closure so each invocation of with_history (i.e., each decoration) captures its own independent list. Concretely, I changed with_history to accept only func and do history = [] inside the function body; the wrapper then closes over that list. This ensures each decorated function has its own history list and fixes the sharing bug.

"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


def with_history(func):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Create a fresh history list for each decorated function so
    # histories are not shared across different wrappers.
    history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }
