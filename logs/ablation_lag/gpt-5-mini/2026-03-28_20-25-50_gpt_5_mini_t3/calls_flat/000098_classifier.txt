# Developer's Reasoning

## Root Cause
In function place_order the except handler 'except ValueError: raise' simply re-raises the exception raised by wallet.charge without calling inventory.release(qty). As a result, when wallet.charge fails, the earlier inventory.reserve(qty) is never undone and inventory.reserved remains incremented.

## Failure Mechanism
Concrete scenario: inventory.stock == 10 and inventory.reserved == 0. wallet.balance == 0. Call place_order(inventory, wallet, qty=2, price=5). inventory.reserve(2) sets inventory.reserved to 2. wallet.charge(2 * 5) raises ValueError due to insufficient funds. The except ValueError branch re-raises the ValueError without calling inventory.release(2). The call fails for the caller, but inventory.reserved remains 2. Subsequent calls see available() == 8 even though the order was not completed, causing misleading stock accounting and possible future 'insufficient stock' errors.

## Broken Invariant
If place_order raises an exception, it must leave inventory.reserved unchanged (i.e., reservation must be rolled back). Formally: given r0 = inventory.reserved before calling place_order that raises, afterwards inventory.reserved == r0. The current implementation violates this: the reserved counter is increased by qty and never decremented when wallet.charge fails.

## Fix Strategy
I changed place_order so that any exception raised while charging the wallet triggers inventory.release(qty) before re-raising. Concretely, I wrapped wallet.charge(...) in a try/except Exception block and in the except branch call inventory.release(qty) and then re-raise. This ensures the reservation is released on failure while preserving the reservation on success (we only release on exceptions), restoring the broken invariant.

"""Order fulfillment with inventory and wallet."""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release reservation on failure."""
    inventory.reserve(qty)
    try:
        wallet.charge(qty * price)
    except Exception:
        # Ensure we release the inventory reservation if charging fails,
        # then propagate the original error to the caller.
        inventory.release(qty)
        raise
    return {"status": "confirmed", "qty": qty, "total": qty * price}
