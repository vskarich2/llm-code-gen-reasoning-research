## Root Cause
In code_snippets_v2/silent_default_c/flags.py the _ENV_KEY_MAP entry for 'dark_mode' is wrong: it maps 'dark_mode' to 'FEATURE_DARKMODE' (missing underscore), so env.get_env/get_env_bool lookups never find the real environment key 'FEATURE_DARK_MODE' in env._ENV. Additionally, is_enabled() treats the environment boolean as an enable-only override by checking 'if env_val: return True', so an explicit env value of 'false' is ignored rather than overriding the config/hardcoded layers.

## Failure Mechanism
For example, env._ENV contains 'FEATURE_DARK_MODE': 'true'. _ENV_KEY_MAP['dark_mode'] returns 'FEATURE_DARKMODE' (nonexistent in _ENV). is_enabled('dark_mode') calls get_env_bool('FEATURE_DARKMODE'), which returns False (default) because the env key isn't present, so the function does not return at the env layer and falls back to config.get_config_bool('dark_mode') or hardcoded defaults. Even if an environment variable exists and is explicitly 'false', the current is_enabled only returns when env_val is truthy, so a present env var set to 'false' will be ignored and the system may incorrectly enable the flag from config or hardcoded values.

## Broken Invariant
If an environment variable key mapped from a flag (via _ENV_KEY_MAP) is present in env._ENV (i.e., get_env(env_key) is not None), then is_enabled(flag_name) must return the boolean interpretation of that environment variable (i.e., is_enabled(flag_name) == get_env_bool(env_key)).

## Fix Strategy
Fixes: 1) Correct the mapping for 'dark_mode' in _ENV_KEY_MAP to 'FEATURE_DARK_MODE' so lookups hit the actual env key. 2) Change is_enabled() to check presence of the env var via get_env(env_key) is not None and, if present, return get_env_bool(env_key). This ensures an environment-set value will override config/hardcoded layers for both true and false. get_flag_source already checks env presence correctly, so with the corrected map it will report 'env' when appropriate.

```python
"""Feature flag system with env -> config -> hardcoded fallback chain.

Lookup order:
  1. Environment variable (via env.get_env_bool)
  2. Config file (via config.get_config_bool)
  3. Hardcoded defaults
"""

from env import get_env, get_env_bool
from config import get_config_bool


HARDCODED_DEFAULTS = {
    "dark_mode": False,
    "beta": False,
    "analytics": False,
}

# Maps flag names to their env var keys
_ENV_KEY_MAP = {
    "dark_mode": "FEATURE_DARK_MODE",
    "beta": "FEATURE_BETA",
    "analytics": "FEATURE_ANALYTICS",
}


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Checks env first, then config, then hardcoded defaults.
    """
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        # If the env var is present at all, use its boolean interpretation as the
        # authoritative override (handles both "true" and "false").
        if get_env(env_key) is not None:
            return get_env_bool(env_key)

    config_val = get_config_bool(flag_name)
    if config_val is not None:
        return config_val

    return HARDCODED_DEFAULTS.get(flag_name, False)


def get_flag_source(flag_name):
    """Return which layer provides the flag value (for debugging)."""
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        from env import get_env
        if get_env(env_key) is not None:
            return "env"

    from config import get_config
    if get_config(flag_name) is not None:
        return "config"

    return "hardcoded"

```
