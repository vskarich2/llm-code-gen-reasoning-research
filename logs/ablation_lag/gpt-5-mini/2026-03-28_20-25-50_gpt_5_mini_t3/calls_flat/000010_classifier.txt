# Developer's Reasoning

## Root Cause
In config.create_config the function returns DEFAULTS directly (config = DEFAULTS) instead of returning a copy. The middleware stores that returned object in ConfigMiddleware._base at init time, and middleware.apply_config assigns cfg = self._base and calls cfg.update(request_overrides), which mutates the shared object referenced by DEFAULTS and by the cached _base.

## Failure Mechanism
Example: DEFAULTS = {'timeout': 30, 'retries': 3, 'debug': False}. create_config() returns that same dict reference. When handle_debug_request() calls middleware.apply_config({'debug': True}) the code does cfg = self._base followed by cfg.update({'debug': True}). Because cfg is the exact dict returned by create_config (and originally DEFAULTS), the cached _base now has 'debug': True. A subsequent call to handle_request() with no overrides will return the mutated cached config with debug True even though no per-request override was provided.

## Broken Invariant
A per-request override must not persist across requests. Formally: after calling handle_request({'debug': True}) a later call to handle_request() (with no overrides) MUST return a config where config['debug'] == False. The current code violates this invariant because apply_config mutates the cached base config object.

## Fix Strategy
create_config now returns a shallow copy of DEFAULTS so callers receive an independent dict. apply_config no longer mutates the cached base; it returns a new dict merging the cached base and the per-request overrides (using merge_overrides) or a shallow copy of the base when there are no overrides. These changes prevent request-specific updates from changing the cached _base or the global DEFAULTS reference.

DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides.

    This returns a fresh shallow copy of DEFAULTS so callers cannot mutate
    the global DEFAULTS by accident.
    """
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools.
    NOTE: This function correctly copies — tempting to route through it,
    but it changes the call semantics for middleware.
    """
    result = dict(base)
    result.update(overrides)
    return result


def get_default(key):
    """Read a single default value."""
    return DEFAULTS.get(key)


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


from config import create_config, merge_overrides


class ConfigMiddleware:
    """Middleware that loads config once and applies per-request overrides."""

    def __init__(self):
        # cache a base config snapshot at init time; it's a distinct dict
        # so later per-request merges won't mutate the global DEFAULTS.
        self._base = create_config()

    def apply_config(self, request_overrides=None):
        """Return config for this request, applying any overrides.

        This returns a fresh dict for each request and never mutates self._base.
        """
        if request_overrides:
            return merge_overrides(self._base, request_overrides)
        return dict(self._base)

    def get_timeout(self):
        return self._base.get("timeout", 30)
