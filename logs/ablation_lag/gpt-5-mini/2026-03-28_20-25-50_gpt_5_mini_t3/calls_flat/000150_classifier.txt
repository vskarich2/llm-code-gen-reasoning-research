# Developer's Reasoning

## Root Cause
In payment.process_payment the early return inside the if txn_id in _cache branch prevents calling ledger.record. The variable _cache holds previously computed results, and because the function returns immediately when a duplicate txn_id is found, the ledger._entries list is not appended for duplicate calls.

## Failure Mechanism
If process_payment is called twice with the same txn_id, e.g. process_payment('tx1', 100) then process_payment('tx1', 100) again, the first call records one entry (record is called) but the second call hits the if txn_id in _cache branch and returns the cached result without calling record. As a result ledger.get_summary()['count'] will be 1 while two calls to process_payment occurred; verify(2) will return False.

## Broken Invariant
For any number N of calls to process_payment (including calls with duplicate txn_id), ledger.verify(N) must return True (equivalently ledger.get_summary()['count'] == N). The current code violates this: duplicated txn_id calls do not increment ledger._entries, so ledger.get_summary()['count'] < number of process_payment calls.

## Fix Strategy
Ensure every invocation of process_payment invokes ledger.record before returning. I kept caching behavior for return values but added a record(...) call in the duplicate branch so the ledger is appended for duplicates too. This change guarantees that each call to process_payment increments ledger._entries by one, restoring the invariant that ledger counts equal number of process_payment calls.

```python
"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # On duplicates, still record the call before returning the cached result.
    if txn_id in _cache:
        cached = _cache[txn_id]
        # Record this duplicate invocation so ledger counts every call.
        record(txn_id, amount, cached.get("status", "charged"))
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()

```
