# Developer's Reasoning

## Root Cause
The api.checkout function declares the parameter use_new_pricing but never uses it. Instead of propagating that intent, create_invoice and compute_price read the global flag via flags.is_enabled("new_pricing"). Because checkout doesn't set the flag, calls that pass use_new_pricing=True still compute prices using the globally configured value.

## Failure Mechanism
If a caller runs checkout(customer, items, use_new_pricing=True) while the global flag _flags['new_pricing'] is False, compute_price (in pricing.compute_price) will call is_enabled("new_pricing") and choose _v1_price. The returned invoice will have 'pricing_version': 'v1' even though the caller requested new pricing. Concretely: checkout(..., use_new_pricing=True) -> checkout doesn't toggle the flag -> create_invoice -> compute_price uses v1 -> invoice total and pricing_version correspond to v1.

## Broken Invariant
Calling checkout(customer, items, use_new_pricing=True) must produce an invoice whose pricing_version is 'v2' and whose computed amounts reflect v2 pricing; similarly use_new_pricing=False must produce 'v1' pricing. Currently that invariant is false because checkout does not influence the flag read by pricing.compute_price.

## Fix Strategy
Make checkout temporarily set the 'new_pricing' feature flag to the requested value while creating the invoice and then restore the original flag. This ensures pricing.compute_price and get_pricing_version see the requested flag value during invoice creation without permanently mutating global state. The implementation saves the original flags.is_enabled('new_pricing'), sets or clears the flag using enable/disable as needed, invokes create_invoice, and then restores the original flag in a finally block so it's restored even if invoice creation fails.



# Task Description
The checkout function takes a use_new_pricing flag but pricing doesn't seem to respect it. Fix the flag propagation. Return the updated code.

# Code Produced
```python
from billing import create_invoice, get_invoices
from flags import enable, disable, is_enabled


def checkout(customer, items, use_new_pricing=False):
    # Preserve original flag state so we don't permanently mutate global flags
    original = is_enabled("new_pricing")
    try:
        # Only change the global flag if necessary
        if use_new_pricing and not original:
            enable("new_pricing")
        elif not use_new_pricing and original:
            disable("new_pricing")

        invoice = create_invoice(customer, items)
        return invoice
    finally:
        # Restore original flag state regardless of success/failure
        if original:
            enable("new_pricing")
        else:
            disable("new_pricing")

    return get_invoices()
```
