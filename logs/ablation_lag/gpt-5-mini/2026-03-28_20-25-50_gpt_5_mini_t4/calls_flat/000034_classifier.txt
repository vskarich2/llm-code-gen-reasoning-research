# Developer's Reasoning

## Root Cause
In catalog.update_product the code updates the database (_db[product_id].update(fields)) and then calls invalidate_shared(product_id) but does not call invalidate_local(product_id). The missing call to invalidate_local means the per-request local cache (_local in cache.py) can still hold the old product value after the DB has been changed.

## Failure Mechanism
Sequence: api.get_product first calls get_local(product_id). If a stale entry exists in the local cache, get_local returns it and api.get_product returns that stale dict immediately. If update_product is called afterwards, it updates _db and calls invalidate_shared(product_id) but because invalidate_local is not called, the stale value remains in _local. Subsequent calls to api.get_product still return the stale value from get_local, so users observe old product data despite the DB and shared cache being updated.

## Broken Invariant
After update_product(product_id, ...), both cache layers must be invalidated for that product_id: get_local(product_id) must return None and get_shared(product_id) must return None. Currently get_local(product_id) can remain non-None after update_product, violating this invariant.

## Fix Strategy
Call invalidate_local(product_id) inside catalog.update_product after the DB update and alongside invalidate_shared(product_id). This ensures the per-request local cache entry is removed so subsequent api.get_product calls cannot return stale data from _local; they will fall through to shared or DB and get the updated data.

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()
