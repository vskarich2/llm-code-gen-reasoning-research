# Developer's Reasoning

## Root Cause
In function place_order the except ValueError: block re-raises the exception without calling inventory.release(qty). As a result, inventory.reserve(qty) increments Inventory.reserved but the code never decrements it when wallet.charge(...) fails, leaving the Inventory.reserved field incorrect.

## Failure Mechanism
Concrete scenario: Inventory(stock=10) and Wallet(balance=5). Call place_order(inventory, wallet, qty=2, price=5). place_order first calls inventory.reserve(2) which sets inventory.reserved from 0 to 2. Then wallet.charge(2*5=10) raises ValueError('insufficient funds'). The except block currently does 'raise' immediately and never calls inventory.release(2). Effect: inventory.reserved remains 2 even though the order failed, so inventory.available() returns 8 instead of the expected 10. Subsequent orders may be incorrectly blocked by the leaked reservation.

## Broken Invariant
If place_order(inventory, wallet, qty, price) raises a ValueError due to insufficient funds, inventory.reserved must be unchanged from its value before the call (equivalently, inventory.available() must equal its pre-call value). The current code violates this: a failed place_order leaves inventory.reserved increased by qty.

## Fix Strategy
I ensured the reservation is released on any failure of wallet.charge by calling inventory.release(qty) in the exception handler before re-raising. Concretely I changed place_order to compute the total, attempt wallet.charge inside a try/except, and in the except block call inventory.release(qty) and then re-raise the original exception. This prevents the reservation leak described above while preserving the original behavior on success.

 """Order fulfillment with inventory and wallet."""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release on failure."""
    inventory.reserve(qty)
    total = qty * price
    try:
        wallet.charge(total)
    except Exception:
        # Ensure we do not leak the inventory reservation when charging fails
        inventory.release(qty)
        raise
    return {"status": "confirmed", "qty": qty, "total": total}
