# Developer's Reasoning

## Root Cause
In config.create_config(), the line `config = DEFAULTS` returns a direct reference to the module-level DEFAULTS dict rather than a copy. That means callers receive and can mutate the shared DEFAULTS object (e.g. via settings.update), so code that expects independent config dicts actually operates on the global DEFAULTS.

## Failure Mechanism
Example sequence showing the effect: 1) get_settings() is called and app._cached_settings is set to the dict returned by create_config() (which is DEFAULTS by reference). 2) apply_overrides({'debug': True}) calls settings.update(overrides), which mutates the same DEFAULTS dict. 3) An admin calls reset_defaults() which reassigns DEFAULTS to a new dict, but app._cached_settings still points to the old mutated dict. Subsequent get_settings() (without clear_cache) yields the stale mutated dict rather than the restored defaults. The root cause is the shared mutable DEFAULTS reference combined with mutation and caching.

## Broken Invariant
After resetting defaults, get_settings() should return settings that reflect the current DEFAULTS (i.e., reset_defaults() sets DEFAULTS so that get_settings()['debug'] == False). Currently, after apply_overrides({'debug': True}) followed by reset_defaults(), get_settings()['debug'] can still be True because a previously returned reference was mutated and cached.

## Fix Strategy
Two changes remove the failure mechanism: 1) make create_config() return a copy of DEFAULTS (config = dict(DEFAULTS)) so callers cannot mutate the shared DEFAULTS. 2) simplify loading in app.py so get_settings() always returns a fresh config from create_config(), and apply_overrides() returns a merged copy using merge_overrides instead of mutating any cached/global dict. These changes eliminate aliasing of DEFAULTS and avoid cache-induced staleness.

```python
from config import create_config, merge_overrides


def get_settings():
    """Return fresh app settings based on current defaults."""
    return create_config()


def apply_overrides(overrides):
    """Return a new settings dict with runtime overrides applied (no global mutation)."""
    return merge_overrides(get_settings(), overrides or {})


def clear_cache():
    """No-op kept for compatibility; get_settings always returns fresh settings."""
    pass


DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides."""
    # Return a copy to avoid exposing the module-level DEFAULTS for mutation
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}

```
