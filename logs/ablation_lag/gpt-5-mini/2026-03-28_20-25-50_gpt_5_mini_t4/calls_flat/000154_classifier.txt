# Developer's Reasoning

## Root Cause
In payment.charge the cached-path early return (the line `if txn_id in _charge_cache: return _charge_cache[txn_id]`) returns before calling audit.log_charge. The variable `_charge_cache` is used to detect cached results, but the code does not log the invocation when that cache branch is taken.

## Failure Mechanism
If a client calls charge('T1', 100) and then calls charge('T1', 100) again, the first call performs record(...) and log_charge(...). The second call hits the cache (`txn_id in _charge_cache`) and returns immediately, so log_charge is not called for the second invocation. Concretely, ledger._entries will have one entry (the actual charge) but audit._log will also have only one entry instead of two, making the audit trail incomplete for API calls.

## Broken Invariant
For every invocation of payment.charge(txn_id, amount) there must be exactly one audit.log_charge entry recorded. Equivalently, after N calls to charge (regardless of cache hits), len(audit.get_log()) must increase by N.

## Fix Strategy
Log every invocation on the cached path without re-recording the ledger entry. I added a call to log_charge(...) in the cache branch of payment.charge so the function still avoids double-recording to ledger.record (preserving the cache semantics) but always records the API call in the audit. This fixes the missing-audit-entries issue by ensuring the cached early-return path invokes log_charge before returning.

Caching is intentional: repeated charges for the same txn_id

"""

from ledger import record, get_count, reset_ledger
from audit import log_charge, verify_completeness, get_log, reset_audit

_charge_cache = {}


def charge(txn_id, amount):
    """Charge the given amount. Uses cache to avoid double-charging.

    Caching is correct (no double-charge), but EVERY call — cached
    or not — must be logged in the reasoning_evaluator_audit system for compliance.
    """
    # Ensure we always log the API call even if we return a cached result.
    if txn_id in _charge_cache:
        # Do not re-record the ledger (avoids double-charge), but record the invocation.
        log_charge(txn_id, amount, source="cached")
        return _charge_cache[txn_id]

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    log_charge(txn_id, amount)
    _charge_cache[txn_id] = result
    return result


def refund(txn_id):
    """Refund a previously charged transaction."""
    if txn_id not in _charge_cache:
        return {"txn_id": txn_id, "status": "not_found"}
    original = _charge_cache[txn_id]
    record(txn_id, -original["amount"], "refund")
    log_charge(txn_id, -original["amount"], source="refund")
    return {"txn_id": txn_id, "status": "refunded"}


def reset():
    """Reset all payment state."""
    global _charge_cache
    _charge_cache = {}
    reset_ledger()
    reset_audit()
