The code even contains a comment '# BUG: full_name not recomputed after first_name change' which pinpoints the missing assignment to user['full_name'].

## Failure Mechanism
Given a user like {'first_name': 'Alice', 'last_name': 'Smith', 'full_name': 'Alice Smith', 'email': 'a@example.com'} and changes = {'first_name': 'Alicia'}, update_profile will sanitize and validate the new first name and set user['first_name'] = 'Alicia' but will leave user['full_name'] unchanged as 'Alice Smith'. The returned user therefore has user['first_name'] == 'Alicia' but user['full_name'] == 'Alice Smith', so the displayed full name is stale and inconsistent.

## Broken Invariant
After calling update_profile(user, changes), the returned user's 'full_name' must equal user['first_name'] + ' ' + user['last_name']. The current code can return a user where user['full_name'] != user['first_name'] + ' ' + user['last_name'] (e.g., when only first_name is changed).

## Fix Strategy
When first_name is updated, also recompute and assign user['full_name'] using the new first name and the current last name. I added the line user['full_name'] = value + ' ' + user['last_name'] in the first_name branch so that both name-update branches symmetrically maintain the invariant. This ensures that whether first_name, last_name, or both are updated (in any order), full_name is kept in sync.

```python
"""User profile with derived full_name field."""

from validation import validate_name, sanitize_string


def create_user(first_name, last_name, email):
    """Create user with derived full_name."""
    return {
        "first_name": first_name,
        "last_name": last_name,
        "full_name": first_name + " " + last_name,
        "email": email,
    }


def update_profile(user, changes):
    """Update profile fields. full_name must stay in sync.

    Invariant: full_name == first_name + ' ' + last_name
    """
    for key, value in changes.items():
        value = sanitize_string(value)
        if key == "first_name" and validate_name(value):
            user["first_name"] = value
            # Recompute full_name after first_name change
            user["full_name"] = value + " " + user["last_name"]
        elif key == "last_name" and validate_name(value):
            user["last_name"] = value
            user["full_name"] = user["first_name"] + " " + value
        elif key == "email":
            user["email"] = value
    return user

```
