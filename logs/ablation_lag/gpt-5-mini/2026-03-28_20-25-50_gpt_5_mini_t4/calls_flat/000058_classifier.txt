## Root Cause
The decorator function with_history in code_snippets_v2/mutable_default_c/scheduler.py uses a mutable default capture: its parameter history has the default value _shared_log (a module-level list). Because with_history is used as a plain decorator (@with_history), Python calls with_history(func) and the default history parameter evaluates to the single module-level list _shared_log, so both schedule_one and schedule_batch close over the same list.

## Failure Mechanism
When schedule_one is called, wrapper appends an entry to the shared history list (history.append...). Because schedule_batch was decorated with the same with_history default list, schedule_batch.get_history() will include the entry added by schedule_one. Concretely: calling schedule_one(task) adds {'func': 'schedule_one', ...} into _shared_log; subsequently calling schedule_batch.get_history() returns a list that now contains that schedule_one entry, violating per-function isolation.

## Broken Invariant
Each decorated function must have its OWN independent history list. Testable statement: after calling schedule_one once and not calling schedule_batch, len(schedule_one.get_history()) == 1 and len(schedule_batch.get_history()) == 0. Under the bug, both lengths would be 1 because they share the same history list.

## Fix Strategy
Remove the shared mutable default by creating a fresh history list inside the decorator closure so each decoration gets its own list. Specifically, with_history now takes only the function argument and initializes history = [] inside the function. The wrapper still appends to that closure-local list and exposes get_history and clear_history that operate on that per-decorated-function list. This prevents appends from one decorated function affecting another.

```python
"""Scheduler with decorator that tracks call history."""

from functools import wraps
from worker import process, batch_process


def with_history(func):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Each decorated function gets its own history list created here.
    history = []

    @wraps(func)
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }

```
