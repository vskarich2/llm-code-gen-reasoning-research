# Developer's Reasoning

## Root Cause
The module-level variable _default_host is created once at import time with _default_host = _settings['host'], and get_host() returns that captured _default_host. Because _default_host is not updated when _settings is changed by configure(), get_host() continues to return the original import-time host instead of the current value in _settings.

## Failure Mechanism
If a caller calls configure(host='example.com') to change the host, _settings['host'] becomes 'example.com' but _default_host remains 'localhost' (the value captured at import). A subsequent call to get_host() returns 'localhost' (the stale _default_host) rather than 'example.com', causing callers to observe an out-of-date host.

## Broken Invariant
After calling configure(host=<NEW_HOST>), get_host() MUST return the same <NEW_HOST>. (Concretely: configure(host='x'); assert get_host() == 'x'). This invariant is violated because get_host() returns the import-time _default_host instead of the current _settings['host'].

## Fix Strategy
Removed the eagerly captured _default_host and made get_host() read the current value from the mutable _settings mapping. Also introduced a single source of truth _DEFAULT_SETTINGS and made reset_settings() and the initial _settings use copies of that constant. This ensures configure() updates are reflected immediately by get_host().

```python
"""Service with lazily-read settings."""

# Single source of truth for default settings
_DEFAULT_SETTINGS = {"host": "localhost", "port": 8080, "debug": False}

# Mutable runtime settings (start as a copy of defaults)
_settings = dict(_DEFAULT_SETTINGS)


def get_host():
    """Return the current host setting."""
    # Always read from the current settings so changes via configure()
    # are immediately visible.
    return _settings["host"]


def get_settings():
    """Return the current settings dict."""
    # Return a shallow copy to avoid external mutation of the internal dict.
    return dict(_settings)


def reset_settings():
    """Reset settings to default values (e.g., for testing)."""
    global _settings
    _settings = dict(_DEFAULT_SETTINGS)


def configure(host=None, port=None, debug=None):
    """Update settings."""
    if host is not None:
        _settings["host"] = host
    if port is not None:
        _settings["port"] = port
    if debug is not None:
        _settings["debug"] = debug

```
