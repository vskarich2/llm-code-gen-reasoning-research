# Developer's Reasoning

## Root Cause
In api.checkout the parameter use_new_pricing is accepted but never used. The function simply calls create_invoice(customer, items) without altering any feature flag. Because pricing.compute_price queries flags.is_enabled("new_pricing"), the provided use_new_pricing boolean is ignored and never propagated to the flags system.

## Failure Mechanism
If a caller invokes checkout(customer, items, use_new_pricing=True), api.checkout does not enable the "new_pricing" feature flag. create_invoice calls pricing.compute_price which calls is_enabled("new_pricing"). Since the flag was not set, compute_price continues to use _v1_price, so invoice['pricing_version'] is "v1" and prices do not reflect the intended v2 logic. In short: use_new_pricing=True -> checkout does nothing -> flag remains False -> pricing uses v1 results.

## Broken Invariant
Calling checkout(customer, items, use_new_pricing=True) must produce an invoice whose pricing_version is "v2" and whose line amounts are computed by pricing._v2_price. Conversely, calling checkout(..., use_new_pricing=False) must ensure pricing_version is "v1" and amounts use pricing._v1_price. This property is currently violated because checkout does not toggle the flag.

## Fix Strategy
Make checkout temporarily set the global "new_pricing" flag according to use_new_pricing while creating the invoice, then restore the original flag state. I use flags.get_all_flags() to snapshot the current setting, then enable() or disable() for the requested mode before calling create_invoice, and finally restore the original flag value in a finally block to avoid leaving global state changed. This ensures compute_price and get_pricing_version observe the requested flag during invoice creation but does not leak the override to other callers.



# Task Description
The checkout function takes a use_new_pricing flag but pricing doesn't seem to respect it. Fix the flag propagation. Return the updated code.

# Code Produced
```python
from billing import create_invoice, get_invoices
from flags import enable, disable, get_all_flags


def checkout(customer, items, use_new_pricing=False):
    # Snapshot current flags so we can restore after creating the invoice
    snapshot = get_all_flags()
    try:
        if use_new_pricing:
            enable("new_pricing")
        else:
            disable("new_pricing")
        invoice = create_invoice(customer, items)
    finally:
        # Restore the original new_pricing flag value
        if snapshot.get("new_pricing", False):
            enable("new_pricing")
        else:
            disable("new_pricing")

    return invoice


def admin_report():
    return get_invoices()
```
