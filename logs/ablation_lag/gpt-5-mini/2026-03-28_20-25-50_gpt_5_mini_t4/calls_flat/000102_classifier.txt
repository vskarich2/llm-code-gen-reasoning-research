# Developer's Reasoning

## Root Cause
In order_service.place_order, after calling reserve(product_id, qty) (which increments inventory._reserved for that product), the except ValueError block simply re-raises the payment exception instead of calling release(product_id, qty). Because the code never calls release in the payment-failure path, inventory._reserved remains incremented and the reservation is not rolled back.

## Failure Mechanism
Concrete scenario: add_product('A', 10) sets _stock['A']=10. place_order('A', 2, price) calls reserve('A', 2) which sets inventory._reserved['A'] += 2. If _process_payment raises ValueError (payment declined), the except ValueError: raise path in place_order re-raises without calling release('A', 2). As a result get_reserved('A') still returns 2 and available('A') returns 8 less 2 reserved (i.e. 8 - 2 depending on prior state), leaving inventory permanently reserved for a failed order.

## Broken Invariant
If place_order(product_id, qty, price) raises a payment-related ValueError, then the reservation count must be unchanged from before the call (i.e., inventory.get_reserved(product_id) after the exception must equal inventory.get_reserved(product_id) before the call). The current code violates this: after a payment failure the reserved count is increased by qty and not rolled back.

## Fix Strategy
Call release(product_id, qty) when payment fails so the inventory reservation is rolled back before re-raising the payment exception. This directly undoes the earlier reserve(product_id, qty) side-effect on inventory._reserved, restoring the invariant that a failed order does not leave reservations in place. The change is localized to order_service.place_order: on catching ValueError from _process_payment we call release(product_id, qty) and then re-raise.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Roll back the inventory reservation before propagating the payment error.
        release(product_id, qty)
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
