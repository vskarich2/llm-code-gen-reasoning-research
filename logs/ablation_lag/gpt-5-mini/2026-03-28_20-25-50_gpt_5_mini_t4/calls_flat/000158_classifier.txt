# Developer's Reasoning

## Root Cause
In add_entry(), the code updates _labels and _values inconsistently: it calls _labels.insert(position, label) but calls _values.append(value). Because _values.append(value) does not insert at the same index, the two parallel lists become misaligned. The causal relationship is direct: inserting the label at position but appending the value causes that new label to be paired with the wrong value index-wise.

## Failure Mechanism
Example: starting with _labels = ['a', 'b'] and _values = [1, 2], calling add_entry('x', 99, position=1) executes _labels.insert(1, 'x') producing ['a', 'x', 'b'] and then executes _values.append(99) producing [1, 2, 99]. When get_all() uses zip(_labels, _values) the results are [('a', 1), ('x', 2), ('b', 99)] — the inserted label 'x' is paired with the wrong value (2) because the value was appended instead of inserted at index 1.

## Broken Invariant
The module guarantees that the two internal lists are parallel: len(_labels) == len(_values) and for every index i in range(count()), _labels[i] corresponds to _values[i]. This is violated when add_entry uses _labels.insert(position, ...) but uses _values.append(...).

## Fix Strategy
Change the _values update to mirror the _labels update so both lists are modified at the same index. Concretely, replace _values.append(value) with _values.insert(position, value) in the branch that handles position. This preserves positional alignment. For clarity and maintainability I also added type hints and concise docstrings so the intended parallel-list invariant is clearer in the code.

```python
 """Report builder with parallel label/value arrays.

This module stores report entries in two parallel lists: _labels and _values.
Functions provided: add_entry, get_entry, get_all, count, reset.
"""

from typing import Any, List, Optional, Tuple

_labels: List[str] = []
_values: List[Any] = []


def add_entry(label: str, value: Any, position: Optional[int] = None) -> None:
    """Add an entry to the report.

    If position is given, insert label and value at that index (keeping the two
    parallel lists aligned). Otherwise append both to the end.
    """
    if position is not None:
        _labels.insert(position, label)
        _values.insert(position, value)
    else:
        _labels.append(label)
        _values.append(value)


def get_entry(index: int) -> Tuple[str, Any]:
    """Return (label, value) at the given index.

    This will raise IndexError if index is out of range.
    """
    return (_labels[index], _values[index])


def get_all() -> List[Tuple[str, Any]]:
    """Return list of (label, value) tuples."""
    return list(zip(_labels, _values))


def count() -> int:
    """Return the number of entries."""
    return len(_labels)


def reset() -> None:
    """Clear all entries."""
    _labels.clear()
    _values.clear()

```
