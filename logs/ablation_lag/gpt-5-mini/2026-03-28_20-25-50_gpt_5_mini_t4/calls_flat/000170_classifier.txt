# Developer's Reasoning

## Root Cause
The function is_enabled uses FLAGS.get(flag_name, False) without normalizing flag_name. Because FLAGS contains snake_case keys (e.g. 'dark_mode') but callers sometimes pass camelCase (e.g. 'darkMode'), the lookup fails and .get returns the default False instead of the actual stored value.

## Failure Mechanism
Example: FLAGS contains 'dark_mode': True. A caller calls is_enabled('darkMode'). The code executes FLAGS.get('darkMode', False). Since 'darkMode' is not a key in FLAGS, .get returns the provided default False, so the caller observes False even though the intended flag 'dark_mode' is True.

## Broken Invariant
For any flag present in FLAGS, calling is_enabled with either the flag's snake_case key or its camelCase form should return the same boolean as FLAGS[snake_case_key]. Concretely, given FLAGS['dark_mode'] is True, is_enabled('darkMode') must return True. The current implementation violates this invariant.

## Fix Strategy
Normalize incoming flag names to snake_case before lookup and stop using dict.get with a silent default. I added a helper _to_snake_case to convert camelCase/PascalCase to snake_case, validate input types, and then changed is_enabled to use the normalized key and to raise KeyError for unknown flags instead of silently returning False. This ensures camelCase callers map to the correct FLAGS entry and typos or unknown flags are surfaced explicitly.

```python
"""Feature flag system with snake_case keys.

is_enabled now accepts snake_case or camelCase inputs and raises on unknown flags
instead of silently returning False.
"""

import re

FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def _to_snake_case(name):
    """Convert camelCase or PascalCase to snake_case. If already snake_case, return as-is.

    Raises TypeError if the provided name is not a string.
    """
    if not isinstance(name, str):
        raise TypeError("flag_name must be a string")
    # If it's already lowercase with underscores, treat it as snake_case.
    if name == name.lower() and "_" in name:
        return name
    # Insert underscores before capital letters and lowercase the result.
    s = re.sub(r'(?<!^)(?=[A-Z])', '_', name).lower()
    return s


def is_enabled(flag_name):
    """Return whether the named feature flag is enabled.

    Accepts a flag name in snake_case (preferred) or camelCase (legacy callers).
    Raises KeyError for unknown flags to avoid silently returning False for typos.

    Args:
        flag_name: flag key to look up (str). May be snake_case or camelCase.

    Returns:
        True if the flag is enabled, False otherwise.

    Raises:
        TypeError: if flag_name is not a string.
        KeyError: if the (normalized) flag is not present in FLAGS.
    """
    normalized = _to_snake_case(flag_name)
    if normalized not in FLAGS:
        raise KeyError(f"Unknown feature flag: {flag_name!r} (normalized: {normalized!r})")
    return FLAGS[normalized]


def list_flags():
    """Return all flag names (snake_case)."""
    return list(FLAGS.keys())

```
