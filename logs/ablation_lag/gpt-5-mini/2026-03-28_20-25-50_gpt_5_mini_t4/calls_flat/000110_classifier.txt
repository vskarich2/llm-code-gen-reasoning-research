## Root Cause

## Failure Mechanism

The pipeline then calls compute_raw_stats(cleaned), so raw_stats['raw_max'] becomes 1.0 (max of normalized values) instead of 6 (max of the original data). Any downstream code that expects raw_stats to reflect the original scale will see incorrect statistics (e.g., format_report would return 'max=1.0' instead of 'max=6').

## Fix Strategy

The pipeline now converts the input to a concrete list named original_data, calls compute_raw_stats(original_data), then calls normalize(original_data) to produce cleaned. This ensures compute_raw_stats observes the original numeric values (restoring the broken invariant). The change is implemented by replacing raw_stats = compute_raw_stats(cleaned) with raw_stats = compute_raw_stats(original_data), renaming variables for clarity, and ensuring the input is materialized once to avoid iterator exhaustion.

```python
"""Metrics pipeline: compute raw stats before transforming data.

This module computes simple statistics on the untransformed input and then
produces a normalized (0-1) version of the data. The raw statistics are
intentionally computed on the original values so they reflect the original
scale.
"""
from typing import Iterable, List, Dict, Sequence


def compute_raw_stats(data: Sequence[float]) -> Dict[str, float]:
    """Compute statistics on raw (untransformed) data.

    If data is empty (or falsy), return zeros for max/min/sum to match prior
    behavior.
    """
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {"raw_max": max(data), "raw_min": min(data), "raw_sum": sum(data)}


def normalize(data: Sequence[float]) -> List[float]:
    """Normalize data to 0-1 range.

    If all values are identical, return 0.5 for each element to avoid
    division by zero and preserve length.
    """
    if not data:
        return []
    lo, hi = min(data), max(data)
    if hi == lo:
        return [0.5] * len(data)
    return [(x - lo) / (hi - lo) for x in data]


def pipeline(data: Iterable[float]) -> Dict[str, object]:
    """Run pipeline: compute raw stats on the original data, then normalize.

    raw_stats MUST reflect the original data values (not the normalized ones).
    To ensure we only iterate the input once, materialize it to a list named
    original_data and operate on that.
    """
    # Materialize the input so we can compute stats and then normalize
    original_data = list(data)

    # Compute stats on the original, untransformed data
    raw_stats = compute_raw_stats(original_data)

    # Produce the cleaned (normalized) version
    cleaned = normalize(original_data)

    return {"raw_stats": raw_stats, "cleaned": cleaned}


def format_report(result: Dict[str, object]) -> str:
    """Format pipeline result for display.

    This helper currently shows only the raw maximum.
    """
    return f"max={result['raw_stats']['raw_max']}"
```
