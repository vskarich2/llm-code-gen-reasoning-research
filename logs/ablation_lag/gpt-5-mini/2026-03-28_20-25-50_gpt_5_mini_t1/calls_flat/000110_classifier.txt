# Developer's Reasoning

## Root Cause
In pipeline(), the code calls compute_raw_stats(cleaned) where 'cleaned' is the normalized version of the input. The buggy line raw_stats = compute_raw_stats(cleaned) passes the normalized list instead of the original input 'data', so the computed raw statistics are derived from the transformed data rather than the original data.

## Failure Mechanism
For a concrete example, given data = [1, 2, 3]: normalize(data) returns [0.0, 0.5, 1.0]. Because pipeline() calls compute_raw_stats(cleaned), compute_raw_stats receives [0.0, 0.5, 1.0] and computes raw_max = 1.0, raw_min = 0.0, raw_sum = 1.5. As a result, format_report(pipeline([1,2,3])) returns 'max=1.0' even though the true maximum of the original data is 3. The cause-effect chain is: pipeline constructs 'cleaned' via normalize(data) and then incorrectly computes raw_stats from 'cleaned' instead of 'data', producing wrong summary numbers.

## Broken Invariant
The pipeline must produce 'raw_stats' computed over the original input list. Formally, for any input list data, pipeline(data)['raw_stats']['raw_max'] must equal max(data) (with the convention that for empty lists raw_max == 0). This invariant is violated when pipeline computes stats over the normalized list instead.

## Fix Strategy
I changed pipeline() to compute raw_stats from the original input by calling compute_raw_stats(data) and to compute the cleaned (normalized) list afterward. This ensures raw_stats reflect the untransformed data (the original 'data' variable) rather than the normalized 'cleaned' list. Concretely the buggy line raw_stats = compute_raw_stats(cleaned) was replaced with raw_stats = compute_raw_stats(data) and the order was adjusted so raw_stats is derived from the original input before normalization.

```python
"""Metrics pipeline: compute raw stats before transforming data."""


def compute_raw_stats(data):
    """Compute statistics on raw (untransformed) data."""
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {
        "raw_max": max(data),
        "raw_min": min(data),
        "raw_sum": sum(data),
    }


def normalize(data):
    """Normalize data to 0-1 range."""
    if not data:
        return []
    lo, hi = min(data), max(data)
    if hi == lo:
        return [0.5] * len(data)
    return [(x - lo) / (hi - lo) for x in data]


def pipeline(data):
    """Run pipeline: raw stats on original data, then normalize.

    raw_stats MUST reflect the original data, not the normalized version.
    """
    # Compute statistics from the original input data so raw_stats reflect
    # untransformed values.
    raw_stats = compute_raw_stats(data)
    cleaned = normalize(data)
    return {"raw_stats": raw_stats, "cleaned": cleaned}


def format_report(result):
    """Format pipeline result for display."""
    return f"max={result['raw_stats']['raw_max']}"

```
