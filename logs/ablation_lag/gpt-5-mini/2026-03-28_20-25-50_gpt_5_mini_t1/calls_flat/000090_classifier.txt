## Root Cause
In sender.send_with_retry the loop calls send(msg, ...) but does not stop after a successful call (no break/return). Because send increments the module-level _attempt_count and then calls store.append and store.notify, a successful send inside the retry loop can be followed by additional iterations that invoke send again, causing duplicate append/notify.

## Failure Mechanism
Example: caller invokes send_with_retry(msg, max_retries=3, fail_first=True). Iteration 0: send raises ConnectionError (simulated transient failure). Iteration 1: send succeeds and appends the message and notifies (store.append and store.notify). Because send_with_retry does not break or return after that success, the loop continues to iteration 2 and calls send again, causing a second append and notification for the same message. The result is two stored messages and two notifications for a single logical send.

## Broken Invariant
After a successful send_with_retry(msg, ...), the store must contain exactly one appended message for msg and exactly one notification for msg. Concretely, for any msg and any pattern of transient ConnectionError exceptions handled by send_with_retry, calling send_with_retry(msg, ...) must increase store.message_count() by exactly 1 and add exactly one notification entry with {'msg': msg, 'notified': True}.

## Fix Strategy
Stop retrying once a send succeeds by returning immediately from send_with_retry when send(msg, ...) completes without raising. This prevents additional iterations from calling send again and duplicating append/notify. If all attempts raise ConnectionError, re-raise the last observed ConnectionError so callers can observe failure.

from store import append, notify, get_messages, get_notifications

_attempt_count = 0


def reset():
    global _attempt_count, _messages, _notifications
    _attempt_count = 0
    _messages = []
    _notifications = []


def send(msg, fail_first=False):
    """Send a message: store it and notify.

    If fail_first is True, raises on first call to simulate transient error.
    """
    global _attempt_count
    _attempt_count += 1
    if fail_first and _attempt_count == 1:
        raise ConnectionError("transient failure")
    append(msg)
    notify(msg)
    return True


def send_with_retry(msg, max_retries=2, fail_first=False):
    """Retry send on transient errors."""
    last_error = None
    for attempt in range(max_retries):
        try:
            send(msg, fail_first=fail_first)
            # Stop retrying after a successful send to avoid duplicate append/notify
            return True
        except ConnectionError as e:
            last_error = e
            continue
    # All attempts failed: surface the last ConnectionError
    if last_error is not None:
        raise last_error
    return False


def get_attempt_count():
    return _attempt_count
