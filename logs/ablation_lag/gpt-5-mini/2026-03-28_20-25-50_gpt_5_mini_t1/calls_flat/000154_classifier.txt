# Developer's Reasoning

## Root Cause
In payment.charge, the early return 'if txn_id in _charge_cache: return _charge_cache[txn_id]' returns cached results before calling audit.log_charge. The variable _charge_cache holding prior charges causes the function to skip the audit path for repeated calls.

## Failure Mechanism
Example: call charge('tx1', 100) — first call records ledger.record('tx1', 100) and audit.log_charge('tx1', 100). A second call charge('tx1', 200) hits the 'if txn_id in _charge_cache' early-return branch and immediately returns the cached result. Because log_charge is never invoked on the cached path, the audit log does not get a second entry even though charge() was called twice; ledger still has only one entry (no double-charge), but audit.get_log() has length 1 instead of the expected 2.

## Broken Invariant
Every invocation of payment.charge(...) must append exactly one entry to the audit log (i.e., calling charge once increases len(audit.get_log()) by 1). Currently, repeated calls for a cached txn_id violate this invariant because they can return without calling audit.log_charge.

## Fix Strategy
On the cached path, call audit.log_charge with the original charged amount before returning; do not call ledger.record. The change logs each invocation (using source='cached' and the cached amount) while preserving the no-double-charge behavior because ledger.record is only called on the non-cached path. Concretely, the early-return branch was expanded to retrieve the cached amount and invoke log_charge(txn_id, cached_amount, source='cached') before returning the cached result.

Caching is intentional: repeated charges for the same txn_id
return the cached result without re-charging. However, every
call to charge() must still be recorded in the reasoning_evaluator_audit log.
"""

from ledger import record, get_count, reset_ledger
from audit import log_charge, verify_completeness, get_log, reset_audit

_charge_cache = {}


def charge(txn_id, amount):
    """Charge the given amount. Uses cache to avoid double-charging.

    Caching is correct (no double-charge), but EVERY call — cached
    or not — must be logged in the reasoning_evaluator_audit system for compliance.
    """
    # Ensure every call is logged. On cached path, log the original charged amount
    # but do not call ledger.record to avoid double-charging.
    if txn_id in _charge_cache:
        cached = _charge_cache[txn_id]
        # Log this invocation as a cached hit, using the amount that was actually charged.
        log_charge(txn_id, cached["amount"], source="cached")
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    log_charge(txn_id, amount)
    _charge_cache[txn_id] = result
    return result


def refund(txn_id):
    """Refund a previously charged transaction."""
    if txn_id not in _charge_cache:
        return {"txn_id": txn_id, "status": "not_found"}
    original = _charge_cache[txn_id]
    record(txn_id, -original["amount"], "refund")
    log_charge(txn_id, -original["amount"], source="refund")
    return {"txn_id": txn_id, "status": "refunded"}


def reset():
    """Reset all payment state."""
    global _charge_cache
    _charge_cache = {}
    reset_ledger()
    reset_audit()
