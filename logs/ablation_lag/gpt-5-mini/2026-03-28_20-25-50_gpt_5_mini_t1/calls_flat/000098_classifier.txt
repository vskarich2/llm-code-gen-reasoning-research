# Developer's Reasoning

## Root Cause
In function place_order, after calling inventory.reserve(qty) the code catches ValueError from wallet.charge but re-raises immediately without calling inventory.release(qty). The variable inventory.reserved is incremented by reserve() but never decremented on a failed charge, so the reservation is leaked.

## Failure Mechanism
Example: Inventory(stock=5) and Wallet(balance=0). place_order(inventory, wallet, qty=3, price=10) calls inventory.reserve(3) which sets inventory.reserved to 3. wallet.charge(30) raises ValueError('insufficient funds'), the except block does 'raise' without releasing the reservation, so inventory.reserved remains 3 even though the order failed. Future calls to available() will incorrectly report 2 available (5 - 3) even though no successful order consumed stock.

## Broken Invariant
If place_order raises an exception (e.g. due to insufficient funds), then inventory.reserved must be unchanged from its value before place_order was called (i.e. the reservation must be released). Testable statement: calling place_order that raises must not increase inventory.reserved.

## Fix Strategy
I added an Inventory.commit method to convert a successful reservation into an actual stock decrement, and I changed place_order to release the reservation on any exception raised while charging the wallet. Concretely, place_order now: (1) inventory.reserve(qty); (2) tries wallet.charge(amount); (3) on exception calls inventory.release(qty) before re-raising; (4) on success calls inventory.commit(qty) and returns confirmation. This ensures failed charges don't leak reservations and successful orders reduce stock.

```python
 """Order fulfillment with inventory and wallet.

This module ensures reservations are rolled back on failure and committed on success.
"""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        """Reserve qty units if available.

        Raises ValueError if there is not enough available stock.
        """
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        """Release a previously made reservation.

        Raises ValueError if attempting to release more than reserved.
        """
        if qty > self.reserved:
            raise ValueError("cannot release more than reserved")
        self.reserved -= qty

    def commit(self, qty):
        """Commit a reservation: decrement stock and remove the reservation.

        Raises ValueError if there is not enough reserved to commit.
        """
        if qty > self.reserved:
            raise ValueError("cannot commit more than reserved")
        self.reserved -= qty
        self.stock -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, charge wallet, commit on success, release on failure.

    Behavior:
    - Reserve qty from inventory.
    - Attempt to charge wallet for qty * price.
    - If charging fails, release the reservation and re-raise the exception.
    - If charging succeeds, commit the reservation (decrement stock) and return
      a confirmation dict.
    """
    inventory.reserve(qty)
    amount = qty * price
    try:
        wallet.charge(amount)
    except Exception:
        # Ensure reservation is released if charging fails.
        inventory.release(qty)
        raise
    # Charge succeeded: commit the reservation into actual stock decrease.
    inventory.commit(qty)
    return {"status": "confirmed", "qty": qty, "total": amount}

```
