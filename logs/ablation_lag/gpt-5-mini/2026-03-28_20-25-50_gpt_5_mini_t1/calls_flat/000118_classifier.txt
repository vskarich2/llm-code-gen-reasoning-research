## Failure Mechanism

For example, given data = [10, 20, 30], normalize(data) -> [0.0, 0.5, 1.0]; compute_raw_stats(normalized) produces {'raw_max': 1.0, 'raw_min': 0.0, 'raw_sum': 1.5, 'raw_count': 3} and compute_derived yields {'raw_mean': 0.5}. The expected raw stats for the original data would be {'raw_max': 30, 'raw_min': 10, 'raw_sum': 60, 'raw_count': 3} and raw_mean 20. This causes the pipeline output to show raw metrics that are inconsistent with the original input while display/cleaned metrics remain based on the transformed data.

## Broken Invariant

Concretely: pipeline(data)['raw_stats']['raw_max'] == max(data) (or 0 when empty), and similarly for raw_min, raw_sum and raw_count. The existing code violates this invariant by computing raw stats from the normalized variable.

Stage 1: compute raw stats on original data
Stage 2: normalize
Stage 3: clip to range
Stage 4: summarize for display
"""

from transforms import normalize, clip, summarize_for_display
from metrics import compute_raw_stats, compute_derived


def pipeline(data):
    """4-stage pipeline.

    raw_stats MUST reflect the original data before any transforms.
    """
    # Stage 1: raw stats (must be computed on original data)
    raw_stats = compute_raw_stats(data)
    derived = compute_derived(raw_stats)
    # Stage 2: normalize
    normalized = normalize(data)
    # Stage 3: clip
    clipped = clip(normalized, 0.05, 0.95)
    # Stage 4: display summary
    display = summarize_for_display(clipped)

    return {
        "raw_stats": raw_stats,
        "derived": derived,
        "cleaned": clipped,
        "display": display,
    }
