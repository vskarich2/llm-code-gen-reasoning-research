# Developer's Reasoning

## Root Cause
In process_payment, the early return when amount == 0 prevents any modification of the module-level _ledger. The function returns {'status': 'skipped', 'amount': 0} before the code that appends an entry to _ledger is reached, so _ledger is never updated for zero-amount calls.

## Failure Mechanism
When a caller invokes process_payment(0, description), the function hits the if amount == 0: return ... branch and returns immediately. Because the code that creates entry = {...} and _ledger.append(entry) comes after that return, no ledger entry is created. The observable effect is that get_ledger() does not include the zero-amount transaction and verify_ledger(expected_count) can report an incorrect count.

## Broken Invariant
All payments, including zero-amount payments, must be recorded in the _ledger. Concretely: after calling process_payment(0, desc), len(_ledger) must increase by 1 and the last ledger entry must equal {'amount': 0, 'description': desc, 'status': 'skipped'}.

## Fix Strategy
Removed the early return for amount == 0 and instead set a status variable to either 'skipped' or 'charged', then always create and append the ledger entry before returning. This ensures that process_payment(0, ...) appends the {'amount': 0, 'description': ..., 'status': 'skipped'} entry to _ledger while preserving the original return value structure.

"""Simple payment processor with reasoning_evaluator_audit ledger."""

_ledger = []


def process_payment(amount, description="payment"):
    """Process a payment and record it in the ledger.

    All payments — including zero-amount — must be recorded in the
    ledger for reasoning_evaluator_audit compliance. Zero-amount payments are
    recorded with status 'skipped' but still appear in the ledger.
    """
    # Ensure every payment is recorded in the ledger.
    status = "charged"
    if amount == 0:
        status = "skipped"

    entry = {"amount": amount, "description": description, "status": status}
    _ledger.append(entry)
    return {"status": status, "amount": amount}


def get_ledger():
    """Return a copy of the current ledger."""
    return list(_ledger)


def verify_ledger(expected_count):
    """Verify that ledger has exactly expected_count entries."""
    return len(_ledger) == expected_count
