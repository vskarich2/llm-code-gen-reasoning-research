# Developer's Reasoning

## Root Cause
In code_snippets_v2/missing_branch_b/auth.py the dispatch dictionary _ROLE_DISPATCH omits the key "guest" that should map to the guest_access function. Because _ROLE_DISPATCH is used by get_access (handler = _ROLE_DISPATCH.get(role, _default_access)), the missing "guest" entry causes get_access to never call roles.guest_access for the 'guest' role.

## Failure Mechanism
When get_access('guest') is called, _ROLE_DISPATCH.get('guest', _default_access) returns _default_access (the fallback) instead of guest_access. As a result get_access('guest') returns {'read': False, 'write': False, 'delete': False} even though roles.guest_access() is defined to return {'read': True, 'write': False, 'delete': False}. Consequently can_read('guest') returns False (via get_access) despite the intended guest read permission.

## Broken Invariant
For the role name 'guest', get_access('guest') must return the dictionary produced by guest_access(), specifically get_access('guest')['read'] == True. Currently get_access('guest')['read'] == False, violating that invariant.

## Fix Strategy
Add the missing mapping 'guest': guest_access to the _ROLE_DISPATCH dictionary so that get_access looks up and calls the correct handler instead of falling back to _default_access. This directly ensures get_access('guest') invokes guest_access() and returns its {'read': True, ...} result.

def guest_access():

    return {"read": True, "write": False, "delete": False}


"""Authentication and authorization dispatch."""

from roles import admin_access, user_access, moderator_access, guest_access


# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {
    "admin": admin_access,
    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access,
}


def _default_access():
    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)
