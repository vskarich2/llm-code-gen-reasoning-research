The missing assignments to user["verified"] and user["cached_greeting"] (and the lack of use of should_reverify) cause the stale state to persist.

## Failure Mechanism
Given a user like {"name": "Alice", "email": "alice@old.com", "verified": True, "cached_greeting": "Hello, Alice!"} and changes {"email": "alice@new.com"}, update_profile currently executes the branch that sets user["email"] = "alice@new.com" but does not set user["verified"] = False nor clear user["cached_greeting"]. As a result the user remains verified and still has the old greeting "Hello, Alice!" even though the email changed, violating the intended re-verification behavior.

## Broken Invariant

(This is the precise, testable invariant that was violated: changing email must set verified=False and clear cached_greeting.)

## Fix Strategy
Change update_profile to (1) explicitly handle the email update first, (2) call should_reverify(old_email, new_email) and when it returns True set user["verified"] = False and clear user["cached_greeting"] by assigning None, and (3) then handle a name update so that simultaneous name+email updates produce a final cached_greeting reflecting the new name. This fixes the bug by performing the missing assignments and by using should_reverify to decide when to reset verification.

```python
"""User profile with email verification and cached greeting."""

from validation import validate_email, validate_name
from notifications import build_greeting, should_reverify


def create_user(name, email):
    """Create a user with verified status and cached greeting."""
    return {
        "name": name,
        "email": email,
        "verified": False,
        "cached_greeting": build_greeting({"name": name}),
    }


def verify_user(user):
    """Mark user as verified."""
    user["verified"] = True
    return user


def update_profile(user, changes):
    """Update profile fields.

    Invariant: changing email must set verified=False and clear cached_greeting.
    Invariant: changing name must update cached_greeting.
    """
    # Process email first so that simultaneous name+email updates produce
    # a final cached_greeting that reflects the (possibly updated) name.
    if "email" in changes:
        value = changes["email"]
        if validate_email(value):
            old_email = user.get("email")
            user["email"] = value
            if should_reverify(old_email, value):
                user["verified"] = False
                user["cached_greeting"] = None

    if "name" in changes:
        value = changes["name"]
        if validate_name(value):
            user["name"] = value
            user["cached_greeting"] = build_greeting(user)
    return user

```
