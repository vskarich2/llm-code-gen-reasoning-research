# Developer's Reasoning

## Root Cause
config.create_config sets config = DEFAULTS (the module-level dict) and returns that same object. app._cached_settings stores that object from create_config(). Because create_config returned the DEFAULTS reference rather than a copy, subsequent mutations (settings.update(...) in app.apply_overrides) modify DEFAULTS itself.

## Failure Mechanism
Concrete scenario: get_settings() is called; _cached_settings is set to the object returned by create_config(), which is DEFAULTS. Then apply_overrides({'debug': True}) calls get_settings() and does settings.update(overrides), mutating the same object referenced by DEFAULTS. Even after clear_cache() sets _cached_settings = None, calling get_settings() again yields create_config() which returned DEFAULTS (now already mutated). The result is that a runtime override permanently changes the factory defaults and new callers see the mutated values.

## Broken Invariant
Modifying a settings dict returned by get_settings() or apply_overrides(overrides) must not change the module DEFAULTS or affect subsequent calls to get_settings(). Testable statement: after calling get_settings(); apply_overrides({'debug': True}); clear_cache(); then get_settings()['debug'] must be False (the factory default). Currently that invariant is violated.

## Fix Strategy
1) Make create_config return a shallow copy of DEFAULTS (config = dict(DEFAULTS)) so callers can mutate the returned dict without aliasing the module DEFAULTS. 2) Simplify loading by removing the module-level cache in app.py: get_settings() now always returns create_config(), and apply_overrides returns create_config(overrides). This eliminates cached-state bugs and ensures each caller gets a fresh dict built from DEFAULTS. Together these changes prevent accidental persistent mutations of DEFAULTS and remove stale-cache behavior.

DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    '''Return a config dict based on defaults, with optional overrides.'''
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    '''Merge overrides into a copy of base. Used by admin tools.'''
    result = dict(base)
    result.update(overrides)
    return result


def reset_defaults():
    '''Restore defaults to factory values.'''
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}
