# Developer's Reasoning

## Root Cause
In catalog.py the function update_product updates the in-memory database _db (via _db[product_id].update(fields)) but does not call invalidate(product_id) on the cache module. As a result the cache (accessed via get/put in get_product) can still contain the old product dict for product_id after the database update.

## Failure Mechanism
Example: add_product('p1','Widget', 10) stores _db['p1'] = {'name':'Widget','price':10}. A call to get_product('p1') caches a copy via put('p1', dict(product)). Later update_product('p1', price=12) runs _db['p1'].update({'price':12}) but because update_product does not call invalidate('p1'), the cache still contains the previous {'name':'Widget','price':10}. A subsequent get_product('p1') returns the cached stale value (10) instead of the updated value (12).

## Broken Invariant
After update_product(product_id, **fields) returns True, a following call to get_product(product_id) must return product data that reflects the updated fields present in _db[product_id].

## Fix Strategy
After applying _db[product_id].update(fields) the code now calls invalidate(product_id) to remove any stale cached entry. This ensures the next get_product will not return the old cached dict and will either populate the cache with the updated product or return the fresh _db value.

```python
"""Product catalog using external cache module."""

from cache import get, put, invalidate

_db = {}


def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Ensure cache does not hold stale data for this product
    invalidate(product_id)
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()

```
