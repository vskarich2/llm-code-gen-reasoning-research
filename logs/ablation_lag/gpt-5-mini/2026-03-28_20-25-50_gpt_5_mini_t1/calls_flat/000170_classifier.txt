# Developer's Reasoning

## Root Cause
The is_enabled function uses FLAGS.get(flag_name, False) without normalizing the incoming flag_name. Callers often pass camelCase names (e.g. "darkMode") while FLAGS keys are snake_case (e.g. "dark_mode"). Because .get() looks up the exact string, a mismatched format results in .get returning the default False even when a corresponding snake_case flag exists.

## Failure Mechanism
If a caller invokes is_enabled("darkMode"), is_enabled receives flag_name == "darkMode" and calls FLAGS.get("darkMode", False). The dictionary has no key "darkMode" (it only has "dark_mode"), so .get returns the default False. The caller observes the feature as disabled even though FLAGS["dark_mode"] == True.

## Broken Invariant
is_enabled(flag_name) must return True for an enabled feature when the caller provides either the snake_case key or an equivalent camelCase key. Concretely: given FLAGS["dark_mode"] == True, is_enabled("darkMode") should return True.

## Fix Strategy
I added a helper _normalize_flag_name that converts camelCase/PascalCase inputs to snake_case (and leaves existing snake_case unchanged). is_enabled now normalizes the input, checks membership explicitly (raising KeyError for unknown flags to avoid silently returning False), and returns the boolean value from FLAGS[norm_name]. This prevents silent defaults and makes acceptable input formats explicit.

```python
import re

"""Feature flag system with snake_case keys.

This module accepts either snake_case or camelCase/PascalCase flag names when
checking whether a flag is enabled. Unknown flags raise KeyError instead of
silently returning False.
"""

FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def _normalize_flag_name(name):
    """Normalize a flag name to snake_case.

    Accepts snake_case, camelCase, and PascalCase. Examples:
      "dark_mode" -> "dark_mode"
      "darkMode"  -> "dark_mode"
      "DarkMode"  -> "dark_mode"
    """
    if not isinstance(name, str):
        raise TypeError("flag_name must be a string")
    # Fast path: already snake_case
    if "_" in name and name.lower() == name:
        return name
    # Convert CamelCase / camelCase to snake_case
    s1 = re.sub(r"(.)([A-Z][a-z]+)", r"\1_\2", name)
    s2 = re.sub(r"([a-z0-9])([A-Z])", r"\1_\2", s1)
    return s2.replace("-", "_").lower()


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Args:
        flag_name: the flag key to look up. Accepts snake_case or camelCase/PascalCase.

    Returns:
        True if the flag is enabled, False if the flag exists and is disabled.

    Raises:
        KeyError: if the normalized flag name does not exist in FLAGS.
        TypeError: if flag_name is not a string.
    """
    norm = _normalize_flag_name(flag_name)
    if norm not in FLAGS:
        # Fail loudly rather than silently returning a default value.
        raise KeyError(f"Unknown feature flag: {flag_name!r} (normalized: {norm!r})")
    return bool(FLAGS[norm])


def list_flags():
    """Return all flag names (snake_case) as a list copy."""
    return list(FLAGS.keys())

```
