# Developer's Reasoning

## Root Cause
In add_entry(), the function inserts the label into the _labels list using _labels.insert(position, label) but then appends the value to the _values list with _values.append(value). This mismatch between using insert for _labels and append for _values causes the label and value for an inserted entry to be stored at different indices.

## Failure Mechanism
Example concrete scenario based on the original code: call add_entry('A', 1), add_entry('B', 2), then add_entry('C', 3, position=1). After these calls _labels becomes ['A', 'C', 'B'] (because 'C' was inserted at index 1) while _values becomes [1, 2, 3] (because every value was appended). Zipping the two lists yields [('A', 1), ('C', 2), ('B', 3)], so the value 2 (originally for 'B') is paired with label 'C' instead of 'B'. The causal relationship is the mismatched use of insert vs append in add_entry().

## Broken Invariant
After any sequence of add_entry calls (with or without position), for every index i in 0..count()-1 the label and value at that index must originate from the same add_entry call; equivalently, get_entry(i) must return the label and value that were paired together when added. (In the original code this invariant can be violated because labels and values can become misaligned.)

## Fix Strategy
Replace the parallel _labels and _values lists with a single _entries list that stores (label, value) tuples. add_entry() now inserts/appends the tuple as a single atomic object, so a label and its value cannot become separated. All accessors (get_entry, get_all, count, reset) are updated to operate on _entries. This eliminates the root cause (inserting label but appending value) because label and value are stored together.

# Code Produced
```python
 """Report builder that stores entries as label/value pairs.

This refactor avoids parallel arrays by keeping a single list of (label, value)
entries so inserts and appends are atomic and cannot produce misalignment.
"""

_entries = []


def add_entry(label, value, position=None):
    """Add an entry to the report.

    If position is given, insert the (label, value) tuple at that index.
    Otherwise, append it to the end.
    """
    if position is None:
        _entries.append((label, value))
    else:
        if not isinstance(position, int):
            raise TypeError("position must be an int or None")
        _entries.insert(position, (label, value))


def get_entry(index):
    """Return (label, value) at the given index."""
    return _entries[index]


def get_all():
    """Return a list copy of (label, value) tuples."""
    return list(_entries)


def count():
    """Return the number of entries."""
    return len(_entries)


def reset():
    """Clear all entries."""
    _entries.clear()

```
