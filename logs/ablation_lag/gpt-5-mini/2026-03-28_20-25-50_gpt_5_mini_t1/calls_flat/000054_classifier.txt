# Developer's Reasoning

## Root Cause
In file code_snippets_v2/mutable_default_b/worker.py the function process_batch defines the parameter seen with a mutable default value seen=set(). Because default argument expressions are evaluated once at function definition time, the same set object is reused across multiple calls to process_batch, so the variable seen retains task IDs between calls.

## Failure Mechanism
Concretely: call process_batch([{"name":"a"}, {"name":"b"}]) -> both 'a' and 'b' are added to the default seen set and two results are returned. A subsequent call process_batch([{"name":"a"}, {"name":"c"}]) with no explicit seen argument should process both 'a' and 'c', but because the default seen set already contains 'a' from the previous call, 'a' is skipped and only 'c' is processed. The persistent set causes valid tasks in later batches to be erroneously treated as already-seen.

## Broken Invariant
The documented invariant is violated: 'each call to process_batch with a fresh batch must process ALL tasks in that batch, regardless of prior calls.' With the current default seen=set(), calling process_batch on a new batch can return fewer processed results than there are unique-named tasks in that batch because names recorded from prior calls are reused.

## Fix Strategy
Change the default for seen from a mutable set to None and create a new empty set inside the function when seen is None. This ensures a fresh set is used for each call that does not supply a seen argument, eliminating cross-call state leakage. The only code change is replacing the parameter default seen=set() with seen=None and adding an if seen is None: seen = set() line at the start of process_batch.

```python
"""Worker that processes task batches."""


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
```
