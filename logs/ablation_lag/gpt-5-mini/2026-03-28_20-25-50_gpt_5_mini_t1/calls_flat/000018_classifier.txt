## Root Cause
In update_profile (code_snippets_v2/partial_update_b/profile.py) the function updates user['first_name'] when key == 'first_name' but does not update user['full_name'] afterwards. The code even contains a comment '# BUG: full_name not recomputed after first_name change' which pinpoints that the assignment to user['full_name'] is missing in the first_name branch.

## Failure Mechanism
If a client sends changes containing only a new first_name (e.g. {'first_name': 'Jane'}), update_profile sets user['first_name'] = 'Jane' but leaves user['full_name'] unchanged, so full_name still contains the old first name (e.g. 'John Doe'). Additionally, if both first_name and last_name are provided but the dictionary iteration visits last_name before first_name, the last_name branch sets user['full_name'] = user['first_name'] + ' ' + value using the old first_name, and then the first_name branch updates user['first_name'] without recomputing full_name — leaving an inconsistent full_name such as 'John Smith' even though first_name is now 'Jane'.

## Broken Invariant
After update_profile(user, changes) returns, user['full_name'] must equal user['first_name'] + ' ' + user['last_name']. Currently this equality can be false (e.g. user['full_name'] == 'John Doe' while user['first_name'] == 'Jane' and user['last_name'] == 'Doe').

## Fix Strategy
Always recompute full_name from the authoritative fields after applying all validated, sanitized updates. Concretely, remove the partial/full_name maintenance from the last_name branch and add a single assignment at the end: user['full_name'] = user['first_name'] + ' ' + user['last_name']. This guarantees the invariant regardless of which name(s) were changed and regardless of iteration order of changes.

def create_user(first_name, last_name, email):

def update_profile(user, changes):
    """Update profile fields. full_name must stay in sync.

    Invariant: full_name == first_name + ' ' + last_name
    """
    for key, value in changes.items():
        value = sanitize_string(value)
        if key == "first_name" and validate_name(value):
            user["first_name"] = value
        elif key == "last_name" and validate_name(value):

        elif key == "email":
            user["email"] = value
    # Recompute full_name from the authoritative fields to maintain the invariant
    user["full_name"] = user["first_name"] + " " + user["last_name"]
    return user
