# Developer's Reasoning

## Root Cause
The bug is in scheduler.with_history: the parameter history defaulted to the module-level list _shared_log (history=_shared_log). That caused every call to with_history (i.e., every decorated function) to capture the same list object, so all decorated functions appended events to the same shared list.

## Failure Mechanism
Because with_history bound the default history parameter to the single module-level list _shared_log, both schedule_one and schedule_batch used the same history list. For example: calling schedule_one(task1) appends an entry to the shared list, then calling schedule_batch([t2, t3]) appends additional entries to that same list. As a result schedule_one.get_history() returns a list containing entries for schedule_batch calls (and vice versa), so per-function history queries and counts (e.g., get_all_stats()) are polluted and inaccurate.

## Broken Invariant
Invariant violated: "Each decorated function must have its OWN independent history list." Concretely, schedule_one.get_history() and schedule_batch.get_history() should return histories containing only events produced by their respective decorated functions, but under the bug both returned events from both functions.

## Fix Strategy
Make the decorator create a new history list for each decoration. Change with_history so its history parameter defaults to None and, when None, assign a fresh list (history = []) inside the function. This ensures each call to with_history (each decoration) gets its own independent list for recording events. The wrapper still exposes .get_history() and .clear_history() operating on that per-function list.

```python
"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Create a fresh history list for each decorated function when
    # no explicit history is provided.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }

```
