## Root Cause
The bug is in update_product: it updates the database dictionary _db[product_id] but does not update or invalidate the corresponding entry in the cache _cache. As a result, _cache can contain an outdated mapping for product_id after update_product mutates _db.

## Failure Mechanism
Example: add_product(1, 'Widget', 10) stores {'name':'Widget','price':10} in _db and also (after the fix) in _cache. get_product(1) returns the cached entry. If update_product(1, price=12) is called, the current code writes price=12 into _db[1] but leaves _cache[1] unchanged. A subsequent get_product(1) returns the stale _cache[1] showing price 10, so callers observe old data even though _db has been updated.

## Broken Invariant
After update_product(product_id, **fields) returns True for an existing product_id, a subsequent call to get_product(product_id) must return data reflecting the updated fields. (Formally: for every product_id present in _db, update_product must ensure get_product(product_id) returns a mapping equal to _db[product_id] immediately after update_product completes.)

## Fix Strategy
update_product now updates the cache entry for product_id to a fresh copy of the updated _db[product_id] (if the product exists). get_product also returns a defensive copy of the cached mapping so callers cannot mutate the cached object. add_product populates both _db and _cache consistently. These changes ensure the cache cannot become stale relative to _db and that callers cannot accidentally corrupt cached state.

```python
"""Product catalog with caching.

This module maintains a simple in-memory database (_db) and a read cache (_cache).
Functions ensure the cache is kept consistent with the database and that callers
receive defensive copies to avoid accidental mutation of cached objects.
"""

_db = {}
_cache = {}


def add_product(product_id, name, price):
    """Add a product to the database and cache.

    Stores a fresh copy in both _db and _cache so that subsequent get_product
    calls return the current data.
    """
    _db[product_id] = {"name": name, "price": price}
    # Keep cache consistent with the db when a new product is added.
    _cache[product_id] = dict(_db[product_id])


def get_product(product_id):
    """Get product by ID, using cache for repeated lookups.

    Always return a copy of the stored mapping so callers cannot mutate the
    cached object directly.
    """
    if product_id in _cache:
        # Return a defensive copy of the cached data
        return dict(_cache[product_id])
    product = _db.get(product_id)
    if product is not None:
        # Cache a copy of the database entry and return a copy to the caller
        _cache[product_id] = dict(product)
        return dict(_cache[product_id])
    return None


def update_product(product_id, **fields):
    """Update product fields in the database and keep the cache consistent.

    Returns True if the product existed and was updated, False otherwise.

    Invariant: get_product() must return current data after update.
    To maintain that invariant, update the cached copy immediately when the
    database entry is changed.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Ensure cache reflects the updated database entry. Store a fresh copy.
    _cache[product_id] = dict(_db[product_id])
    return True


def reset():
    """Clear all data."""
    _db.clear()
    _cache.clear()

```
