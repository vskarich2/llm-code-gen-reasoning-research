# Developer's Reasoning

## Root Cause
config.create_config returns the DEFAULTS dict itself (config = DEFAULTS) rather than a copy, and middleware.ConfigMiddleware.apply_config assigns cfg = self._base and calls cfg.update(...). Together this causes request-specific overrides to mutate shared dictionaries: create_config hands out a reference to the global DEFAULTS, and apply_config mutates the cached base reference instead of working on a per-request copy.

## Failure Mechanism
Example: handle_debug_request() -> handle_request({'debug': True}) -> ConfigMiddleware.__init__ created self._base from create_config(), which returned DEFAULTS by reference; apply_config does cfg = self._base and cfg.update({'debug': True}) (middleware.py line cfg.update(request_overrides)), mutating the cached base/default. A subsequent call to handle_request() with no overrides returns config['debug'] == True even though no override was provided for that request.

## Broken Invariant
Calling ConfigMiddleware.apply_config(request_overrides) must not change the middleware's cached base configuration (ConfigMiddleware._base) and create_config() must return a fresh dictionary each call; specifically, after apply_config({'debug': True}) the value ConfigMiddleware._base.get('debug') must remain the original default (False).

## Fix Strategy
Make create_config return a shallow copy of DEFAULTS so callers get an independent dict (config = dict(DEFAULTS)). In middleware.apply_config, do not update the cached base in-place; instead operate on a copy (cfg = dict(self._base)) and apply request_overrides to that copy before returning. These changes prevent per-request overrides from mutating the shared DEFAULTS or the cached base used across requests.

def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides."""

def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools.
    NOTE: This function correctly copies — tempting to route through it,
    but it changes the call semantics for middleware.
    """
    result = dict(base)
    result.update(overrides)
    return result


def get_default(key):
    """Read a single default value."""
    return DEFAULTS.get(key)


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


from config import create_config


class ConfigMiddleware:
    """Middleware that loads config once and applies per-request overrides."""

    def __init__(self):
        # Cache the base configuration for this middleware instance.
        # create_config() now returns an independent dict, so _base is safe to keep.
        self._base = create_config()  # cached at init time

    def apply_config(self, request_overrides=None):
        """Return config for this request, applying any overrides.

        Do not mutate self._base; create and return a per-request copy.
        """
        cfg = dict(self._base)
        if request_overrides:
            cfg.update(request_overrides)
        return cfg

    def get_timeout(self):
        return self._base.get("timeout", 30)
