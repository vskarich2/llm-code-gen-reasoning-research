# Developer's Reasoning

## Root Cause
In profile.update_profile the email branch assigns user['email'] = value but never updates user['verified'] or user['cached_greeting']. Specifically, update_profile(user, changes) contains: if key == 'email' and validate_email(value): old_email = user.get('email') user['email'] = value # BUG: verified not set to False, cached_greeting not cleared — this omission causes state to remain stale after an email change.

## Failure Mechanism
Concrete scenario: create_user('Alice', 'a@b.com') produces a user, then verify_user(user) sets user['verified'] = True and user['cached_greeting'] = 'Hello, Alice!'. Calling update_profile(user, {'email': 'alice@new.com'}) runs the email branch that only executes user['email'] = 'alice@new.com' and leaves user['verified'] == True and user['cached_greeting'] == 'Hello, Alice!'. As a result the system still treats the account as verified and continues to show the old cached greeting even though the email changed.

## Broken Invariant
When update_profile applies an email change where validate_email(new_email) is True and notifications.should_reverify(old_email, new_email) is True, then after update_profile returns: user['verified'] must be False and user['cached_greeting'] must be None. This is currently violated because update_profile does not reset those fields in the email branch.

## Fix Strategy
In update_profile I check should_reverify(old_email, value) after assigning user['email'] and, when it returns True, explicitly set user['verified'] = False and user['cached_greeting'] = None. This enforces the invariant that effective email changes require re-verification and clear the cached greeting. The change is localized to the email branch and does not affect the name-update branch.

```python
"""User profile with email verification and cached greeting."""

from validation import validate_email, validate_name
from notifications import build_greeting, should_reverify


def create_user(name, email):
    """Create a user with verified status and cached greeting."""
    return {
        "name": name,
        "email": email,
        "verified": False,
        "cached_greeting": build_greeting({"name": name}),
    }


def verify_user(user):
    """Mark user as verified."""
    user["verified"] = True
    return user


def update_profile(user, changes):
    """Update profile fields.

    Invariant: changing email must set verified=False and clear cached_greeting.
    Invariant: changing name must update cached_greeting.
    """
    for key, value in changes.items():
        if key == "email" and validate_email(value):
            old_email = user.get("email")
            user["email"] = value
            # When the effective email changes (per should_reverify) require re-verification
            # and clear the cached greeting so it doesn't reflect stale information.
            if should_reverify(old_email, value):
                user["verified"] = False
                user["cached_greeting"] = None
        elif key == "name" and validate_name(value):
            user["name"] = value
            user["cached_greeting"] = build_greeting(user)
    return user

```
