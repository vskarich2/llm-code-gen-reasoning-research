## Root Cause
In code_snippets_v2/silent_default_c/flags.py the environment-key mapping for the dark_mode flag is wrong: _ENV_KEY_MAP maps 'dark_mode' to 'FEATURE_DARKMODE' (missing underscore) so lookups never find the actual env var. Additionally, is_enabled uses get_env_bool(env_key) and only returns early when that boolean is truthy (if env_val: return True), so an environment variable explicitly set to false cannot override the config layer. The combination of the wrong key name and the truthy-only env check causes env overrides to be ignored.

## Failure Mechanism
Concrete scenario: _ENV in env.py contains 'FEATURE_DARK_MODE': 'false' and config._FILE_CONFIG contains 'dark_mode': True. When is_enabled('dark_mode') runs, _ENV_KEY_MAP returns 'FEATURE_DARKMODE' (the wrong key). get_env('FEATURE_DARKMODE') -> None, so get_env_bool returns False. The current code does `if env_val: return True` which does not return for a False env_val, so it falls through and reads the config value get_config_bool('dark_mode') which is True, and returns True. The effect is that FEATURE_DARK_MODE='false' fails to disable dark_mode; the env layer did not override config.

## Broken Invariant
Presence of an environment variable for a flag must deterministically override lower-priority layers: for any flag_name with env key K, if get_env(K) is not None then is_enabled(flag_name) must return the boolean value equivalent to get_env(K). For example, when get_env('FEATURE_DARK_MODE') == 'false', is_enabled('dark_mode') must return False.

## Fix Strategy
Fix by (1) correcting the ENV key mapping for 'dark_mode' to the actual env var name 'FEATURE_DARK_MODE', and (2) changing is_enabled to detect presence of the env var (get_env(env_key) is not None) and, if present, return the boolean conversion get_env_bool(env_key) regardless of whether it's True or False. This ensures the env layer both enables and disables flags as intended. The change touches _ENV_KEY_MAP and the env-check logic in is_enabled.

Lookup order:
  1. Environment variable (via env.get_env_bool)

  3. Hardcoded defaults
"""

from config import get_config, get_config_bool


HARDCODED_DEFAULTS = {
    "dark_mode": False,
    "beta": False,
    "analytics": False,
}

# Maps flag names to their env var keys
_ENV_KEY_MAP = {
    "dark_mode": "FEATURE_DARK_MODE",       # fixed: was "FEATURE_DARKMODE"
    "beta": "FEATURE_BETA",
    "analytics": "FEATURE_ANALYTICS",
}


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Checks env first, then config, then hardcoded defaults.
    """
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        # If the env var is present, it should override lower layers even when false.
        raw = get_env(env_key)
        if raw is not None:
            return get_env_bool(env_key)

    config_raw = get_config(flag_name)
    if config_raw is not None:
        return get_config_bool(flag_name)

    return HARDCODED_DEFAULTS.get(flag_name, False)


def get_flag_source(flag_name):
    """Return which layer provides the flag value (for debugging)."""
    env_key = _ENV_KEY_MAP.get(flag_name)
    if env_key:
        from env import get_env
        if get_env(env_key) is not None:
            return "env"

    from config import get_config
    if get_config(flag_name) is not None:
        return "config"

    return "hardcoded"
