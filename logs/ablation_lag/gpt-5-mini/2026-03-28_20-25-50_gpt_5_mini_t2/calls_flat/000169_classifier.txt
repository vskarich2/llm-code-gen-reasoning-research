## Root Cause
The bug is in the function is_enabled which uses FLAGS.get(flag_name, False). The code expects callers to pass snake_case keys, but callers sometimes pass camelCase (e.g. 'darkMode'). Because is_enabled directly looks up the raw flag_name in the FLAGS dict with a silent default of False, the camelCase key is treated as missing and the default False is returned instead of surfacing the mismatch.

## Failure Mechanism
A concrete scenario: a caller invokes is_enabled('darkMode'). The function calls FLAGS.get('darkMode', False). The FLAGS dict only contains 'dark_mode', so .get returns the provided default False. The caller receives False even though the intended flag 'dark_mode' is True. The cause-effect chain is: caller-provided camelCase -> no normalization -> FLAGS.get missing key -> silent default False returned.

## Broken Invariant
The semantic contract violated is: For any input flag_name where its snake_case form exists in FLAGS, is_enabled(flag_name) must return the value stored in FLAGS for that snake_case key. Formally: for any flag_name such that _to_snake_case(flag_name) in FLAGS, is_enabled(flag_name) == FLAGS[_to_snake_case(flag_name)]. The original implementation can return False for inputs like 'darkMode' even though FLAGS['dark_mode'] is True, breaking this invariant.

## Fix Strategy
I added a clear normalization step _to_snake_case(flag_name) to convert camelCase, kebab-case, and other common variants to snake_case, enforced string input, and then perform an exact lookup in FLAGS. If the normalized name is not present in FLAGS the function raises a KeyError instead of silently returning False. This ensures caller mistakes are surfaced and guarantees that is_enabled('{camelCase equivalent}') returns FLAGS[snake_case_name] when the flag exists.

```python
"""Feature flag system with snake_case keys.

This module normalizes common flag-name styles (camelCase, kebab-case, spaces)
to snake_case before looking them up in FLAGS. Unknown flags raise KeyError so
callers don't get silent defaults.
"""

import re

FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def _to_snake_case(name):
    """Normalize a flag name to snake_case.

    Accepts camelCase, kebab-case, space-separated, or already snake_case.
    Raises TypeError if name is not a string.
    """
    if not isinstance(name, str):
        raise TypeError("flag_name must be a string")

    # Replace hyphens and spaces with underscores first
    s = name.replace('-', '_').replace(' ', '_')

    # Convert camelCase/PascalCase to snake_case using two-step regex
    # (common approach to handle boundaries like 'MyURLValue' -> 'my_url_value').
    s = re.sub(r'(.)([A-Z][a-z]+)', r"\1_\2", s)
    s = re.sub(r'([a-z0-9])([A-Z])', r"\1_\2", s)

    return s.lower()


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    The function normalizes the provided flag_name to snake_case before
    checking the FLAGS mapping. If the normalized name is not present in
    FLAGS a KeyError is raised to avoid silent failures caused by
    misspelled or mis-cased names.

    Args:
        flag_name: the flag key to look up (supports camelCase, kebab-case,
                   space-separated, or snake_case)

    Returns:
        True if the flag is enabled, False if it exists and is set to False.

    Raises:
        TypeError: if flag_name is not a string.
        KeyError: if the normalized flag name is not known.
    """
    normalized = _to_snake_case(flag_name)

    if normalized not in FLAGS:
        # Fail fast so callers notice unknown or misspelled flags instead of
        # receiving a silent False default.
        raise KeyError(f"Unknown feature flag: {flag_name!r} (normalized to {normalized!r})")

    return bool(FLAGS[normalized])


def list_flags():
    """Return all flag names (snake_case) as a sorted list."""
    return sorted(FLAGS.keys())

```
