## Root Cause
The bug is in update_product: after calling _db[product_id].update(fields) the function does not update or invalidate the cached entry stored in the module-level variable _cache. Because _cache continues to hold the previous snapshot, subsequent calls to get_product can return the old data from _cache instead of the updated data in _db.

## Failure Mechanism
Example sequence: add_product('p1', 'Pen', 1.0) stores {'name':'Pen','price':1.0} in _db and also leaves that product absent from _cache until get_product is called. If get_product('p1') is called it caches a copy in _cache. Then update_product('p1', price=1.5) updates _db['p1'] to {'name':'Pen','price':1.5'} but does not change _cache['p1']. A subsequent get_product('p1') checks _cache, finds the stale entry (price 1.0) and returns it, so callers observe price 1.0 instead of the current 1.5.

## Broken Invariant
After a successful update_product(product_id, **fields) call, get_product(product_id) must return a product dict whose key/value pairs exactly match _db[product_id]. (Testable: call update_product, then assert get_product(...) == dict(_db[product_id]).)

## Fix Strategy
On every write that changes _db we now make the cache reflect the updated authoritative data. Concretely: add_product writes to _db and then writes a copied dict into _cache; update_product updates _db and then sets _cache[product_id] = dict(_db[product_id]). get_product always returns a fresh copy of the cached data (dict(...)) so callers cannot mutate the internal cache. These changes ensure get_product returns the current _db state and that external mutation of returned dicts cannot corrupt the cache.

```python
"""Product catalog with caching.

This module stores products in an in-memory database and a read-through cache.
Cache entries are kept in sync with the authoritative _db so get_product always
returns current data.
"""

_db = {}
_cache = {}


def add_product(product_id, name, price):
    """Add a product to the database and update the cache.

    Parameters:
    - product_id: hashable product identifier
    - name: product name
    - price: numeric price
    """
    _db[product_id] = {"name": name, "price": price}
    # Keep the cache consistent with the database.
    _cache[product_id] = dict(_db[product_id])


def get_product(product_id):
    """Return a copy of the product data for product_id or None if missing.

    The function always returns a fresh dict so callers cannot mutate the
    internal cache or database record.
    """
    if product_id in _cache:
        return dict(_cache[product_id])
    product = _db.get(product_id)
    if product is None:
        return None
    _cache[product_id] = dict(product)
    return dict(_cache[product_id])


def update_product(product_id, **fields):
    """Update product fields in the database and keep the cache in sync.

    Returns True if the product existed and was updated, False otherwise.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Update cache so subsequent get_product calls reflect the latest data.
    _cache[product_id] = dict(_db[product_id])
    return True


def reset():
    """Clear all data."""
    _db.clear()
    _cache.clear()

```
