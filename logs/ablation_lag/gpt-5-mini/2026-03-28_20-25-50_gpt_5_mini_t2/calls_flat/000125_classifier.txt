# Developer's Reasoning

## Root Cause
In auth.py the dispatch table _ROLE_DISPATCH is missing the 'guest' key. The variable _ROLE_DISPATCH controls which handler function get_access calls for a given role, so omitting 'guest' causes get_access to select _default_access for 'guest' instead of guest_access.

## Failure Mechanism
When code calls get_access('guest') or can_read('guest'), get_access looks up _ROLE_DISPATCH.get(role, _default_access). Because 'guest' is not present in _ROLE_DISPATCH, the default handler _default_access is returned and invoked, producing {'read': False, 'write': False, 'delete': False}. This contradicts the intended behavior from roles.guest_access(), which returns {'read': True, 'write': False, 'delete': False}, so guests end up with no access instead of read-only access.

## Broken Invariant
For any role that has a corresponding handler function imported from roles.py (e.g., guest_access), get_access(role) must return the dictionary produced by that handler. Specifically, get_access('guest') MUST return {'read': True, 'write': False, 'delete': False}.

## Fix Strategy
Add the missing 'guest': guest_access entry to the _ROLE_DISPATCH mapping in auth.py so that get_access('guest') resolves to the intended handler. This changes the handler lookup from returning _default_access to returning guest_access for role 'guest', restoring the correct read-only access for guests.

```python
"""Authentication and authorization dispatch."""

from roles import admin_access, user_access, moderator_access, guest_access


# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {
    "admin": admin_access,
    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access,
}


def _default_access():
    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)

```
