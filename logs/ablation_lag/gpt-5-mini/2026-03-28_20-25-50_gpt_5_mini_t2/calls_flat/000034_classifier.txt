# Developer's Reasoning

## Root Cause
In catalog.update_product the function invalidates only the shared cache by calling invalidate_shared(product_id) but does not call invalidate_local(product_id). The local cache is stored in cache._local and read first by api.get_product via cache.get_local; leaving cache._local populated with the old value causes subsequent reads to return stale data.

## Failure Mechanism
Example scenario: add_product('p1', 'Shoe', 50) causes a request to populate both _shared and _local with the product. Calling update_product('p1', price=60) updates _db['p1'] and calls invalidate_shared('p1') but does not remove the stale entry in _local. A later call to api.get_product('p1') invokes get_local('p1'), which returns the stale entry from cache._local and returns it immediately, so the updated price from db_get is never observed and the stale price 50 is served.

## Broken Invariant
After update_product(product_id, ... ) returns True, no cache layer should contain the previous value for that product_id. Concretely: cache.get_local(product_id) must return None and cache.get_shared(product_id) must return None (so that api.get_product(product_id) will read the DB and return the updated data). The current code violates this invariant by leaving cache.get_local(product_id) non-None.

## Fix Strategy
Call invalidate_local(product_id) inside update_product immediately after updating the DB and alongside invalidate_shared(product_id). This ensures the per-request local cache (cache._local) is cleared so subsequent api.get_product calls cannot return a stale local entry; they will miss local and shared, read the updated DB via db_get, and then repopulate caches with the fresh value. The change is a single-line addition in catalog.update_product: invalidate_local(product_id).

```python
"""Product catalog with two-layer cache integration."""

from cache import put_local, put_shared, invalidate_shared, invalidate_local

_db = {}


def add_product(product_id, name, price):
    """Add product to database."""
    _db[product_id] = {"name": name, "price": price}


def db_get(product_id):
    """Raw DB lookup."""
    p = _db.get(product_id)
    return dict(p) if p else None


def update_product(product_id, **fields):
    """Update product in DB and invalidate caches.

    Invariant: after update, all cache layers must be invalidated.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate_shared(product_id)
    invalidate_local(product_id)
    return True


def reset():
    """Clear DB."""
    _db.clear()

```
