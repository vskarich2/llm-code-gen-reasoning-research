In code_snippets_v2/stale_cache_b/catalog.py the function update_product mutates the in-memory database _db (via _db[product_id].update(fields)) but does not call invalidate(product_id). Because the cache entry for product_id (managed by the cache module and accessed via get/put) remains present, the cached value becomes inconsistent with the updated _db entry.

## Failure Mechanism
Concrete scenario: add_product(1, 'Widget', 100) stores _db[1] = {'name': 'Widget', 'price': 100}. A subsequent get_product(1) finds no cache entry, reads _db[1] and calls put(1, dict(product)) so the cache now holds price 100. Calling update_product(1, price=80) executes _db[1].update({'price': 80}) but does not call invalidate(1). Later get_product(1) calls get(1), sees the cached entry (price 100) and returns it, so the caller observes the old price even though _db[1]['price'] == 80.

## Broken Invariant
After update_product(product_id, **fields) returns True, a subsequent call to get_product(product_id) must return product data that reflects the updated fields (i.e., the values present in _db[product_id]); currently get_product can return a stale cached copy and thus violate this invariant.

## Fix Strategy
Call invalidate(product_id) inside update_product after updating _db so the cache entry is removed. This ensures the next get_product will miss the cache, read the updated _db entry, and repopulate the cache with the fresh data via put. The change is minimal and targeted: it addresses the missing invalidation without altering cache.py or other behavior.

"""Product catalog using external cache module."""

from cache import get, put, invalidate

_db = {}


def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    # Ensure cache does not hold a stale copy after DB update
    invalidate(product_id)
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()
