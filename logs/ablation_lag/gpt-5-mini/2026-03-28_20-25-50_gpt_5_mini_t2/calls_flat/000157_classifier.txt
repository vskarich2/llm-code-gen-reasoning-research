# Developer's Reasoning

## Root Cause
The bug is in add_entry(): it inserts into the _labels list but appends into the _values list. Specifically, add_entry calls _labels.insert(position, label) and then calls _values.append(value) instead of _values.insert(position, value). Because the two lists are manipulated with different operations, their indexes no longer correspond.

## Failure Mechanism
Concretely, start with add_entry('A', 1) and add_entry('B', 2) which produce _labels = ['A', 'B'] and _values = [1, 2]. Then call add_entry('X', 99, position=1). The code does _labels.insert(1, 'X') producing ['A', 'X', 'B'] but calls _values.append(99) producing [1, 2, 99]. Now get_entry(1) returns (_labels[1], _values[1]) == ('X', 2), so the value associated with label 'X' is wrong.

## Broken Invariant
For any index i, the label and value at that index must be the pair that was added together by a single add_entry call. Equivalently, get_entry(i) must return the exact (label, value) tuple passed in a single add_entry call; this property can be tested by adding known pairs and asserting get_entry returns the same pair. The original code violates this when insertions with a position are used.

## Fix Strategy
I replaced the parallel _labels and _values lists with a single _entries list that stores (label, value) tuples. add_entry now inserts or appends a single tuple, which preserves the association between label and value regardless of position. The other functions (get_entry, get_all, count, reset) are adapted to use _entries. This removes the possibility of misaligned parallel arrays (the precise bug was _values.append used instead of _values.insert), because there is now a single list that always keeps each label together with its value.

```python
"""Report builder storing entries as a single list of (label, value) tuples.

This avoids parallel-array misalignment by keeping each label and its
value together in one place.
"""

_entries = []


def add_entry(label, value, position=None):
    """Add an entry to the report.

    If position is given, insert at that index. Otherwise, append to the end.
    """
    entry = (label, value)
    if position is None:
        _entries.append(entry)
    else:
        _entries.insert(position, entry)


def get_entry(index):
    """Return (label, value) at the given index."""
    return _entries[index]


def get_all():
    """Return list of (label, value) tuples."""
    return list(_entries)


def count():
    """Return the number of entries."""
    return len(_entries)


def reset():
    """Clear all entries."""
    _entries.clear()

```
