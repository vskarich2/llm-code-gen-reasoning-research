# Developer's Reasoning

## Root Cause
The bug is in scheduler.with_history: the parameter history has a mutable default value set to the module-level list _shared_log (def with_history(func, history=_shared_log)). Because default argument objects are created once at function definition time, every decorated function receives the same history list object.

## Failure Mechanism
Because schedule_one and schedule_batch are both decorated with with_history, they both close over the same list object _shared_log. When schedule_one is called, wrapper appends an entry to history (the shared list). Later, schedule_batch.get_history() will include entries produced by schedule_one as well. Concretely: after calling schedule_one(task1) and then schedule_batch([t2,t3]), schedule_one.get_history() and schedule_batch.get_history() will both show two entries instead of each showing only their own call(s).

## Broken Invariant
Invariant in with_history docstring: 'each decorated function must have its OWN independent history list.' This is violated: schedule_one.get_history() must return only entries from calls to schedule_one, and schedule_batch.get_history() must return only entries from calls to schedule_batch. Currently they both return entries from both functions.

## Fix Strategy
Change the decorator to avoid using a shared mutable default. Accept history=None and, inside with_history, if history is None create a new empty list for that specific decorated function. This ensures each wrapper closes over its own list. The wrapper.get_history and wrapper.clear_history lambdas continue to operate on the per-wrapper history variable, preserving the API but making histories independent.

_shared_log = []

    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # FIX: do not use a mutable module-level default. If no history is
    # provided, create a fresh list for this decorated function so that
    # different decorated functions do not share the same history.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper
