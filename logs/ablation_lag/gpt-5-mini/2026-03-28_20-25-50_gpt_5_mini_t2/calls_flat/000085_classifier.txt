# Developer's Reasoning

## Root Cause
In retry_send, the loop never stops when send succeeds. The code calls result = send(msg) and then only checks `if not result: continue`, so when send returns True the loop does not break or return and send is invoked again. Because send appends messages to the module list _sent, a successful first send still leads to additional send calls and duplicate entries in _sent.

## Failure Mechanism
Example: reset(); retry_send('hello', max_retries=3). send('hello') returns True on the first attempt, but retry_send does not stop and calls send two more times. As a result get_sent() returns ['hello', 'hello', 'hello'] instead of the expected single 'hello'. The root cause is the missing termination on success in retry_send's for-loop.

## Broken Invariant
If send(msg) succeeds on the first attempt, then retry_send(msg, max_retries=N) must call send at most once and append msg to _sent no more than one time. Concretely, after reset(); retry_send('x', max_retries=K); get_sent() must have length 1 when send succeeds immediately.

## Fix Strategy
Change retry_send so it stops and returns immediately when send returns a truthy success value, and return False only after exhausting retries. Also implement clear_log to actually clear the _sent list. Concretely, the loop now checks `if result: return True` right after calling send, and after the loop returns False. clear_log uses _sent.clear() to empty the list in-place.

def retry_send(msg, max_retries=2):
    """Send with retry. Stops after the first successful send.

    Attempts to send up to max_retries times. Returns True on the first
    successful send, otherwise returns False after all attempts fail.
    """
    if max_retries < 1:
        raise ValueError("max_retries must be >= 1")

    for _attempt in range(max_retries):
        result = send(msg)
        if result:
            # Success: stop retrying and report success
            return True
        # Failure: try again until retries are exhausted
    return False


def get_sent():
    """Return a shallow copy of the sent messages log."""
    return list(_sent)
