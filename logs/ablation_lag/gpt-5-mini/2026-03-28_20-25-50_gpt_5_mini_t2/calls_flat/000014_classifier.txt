# Developer's Reasoning

## Root Cause
In update_profile, when the incoming change has key == 'name' the code sets user['name'] but does not update user['display_name']. The causal line is user['name'] = value in the branch for key == 'name' without changing user['display_name'], so display_name lags behind name after name updates.

## Failure Mechanism
If you call u = create_user('Alice', 'a@example.com') then update_profile(u, {'name': 'Alicia'}), the function executes the 'name' branch and sets u['name'] to 'Alicia' but leaves u['display_name'] as 'Alice'. Code that later reads display_name (for example rendering a UI) will see 'Alice' while name is 'Alicia', causing inconsistent displays and violating the intended invariant.

## Broken Invariant
For any user dict produced or updated by this module, user['display_name'] must equal user['name']. Concretely, after create_user(...) or update_profile(user, changes) completes, evaluating user['display_name'] == user['name'] should always be True.

## Fix Strategy
I introduced a single helper _set_name that updates both user['name'] and user['display_name'] together, and refactored update_profile to dispatch changes through small handlers. This ensures any change to 'name' also updates 'display_name', preserving the invariant. The function still mutates and returns the same user dict, and unknown keys are ignored as before.

```python
"""User profile management.

This module keeps the invariant that display_name always matches name.
"""


def _set_name(user, name):
    """Set both name and display_name so they stay synced."""
    user["name"] = name
    user["display_name"] = name


def _set_email(user, email):
    user["email"] = email


def _set_age(user, age):
    user["age"] = age


def update_profile(user, changes):
    """Update user profile fields from changes dict.

    This function mutates and returns the provided user dict. It guarantees
    that when the 'name' field is updated, 'display_name' is updated to the
    same value so the module invariant holds.
    """
    handlers = {
        "name": lambda u, v: _set_name(u, v),
        "email": lambda u, v: _set_email(u, v),
        "age": lambda u, v: _set_age(u, v),
    }

    for key, value in changes.items():
        handler = handlers.get(key)
        if handler is not None:
            handler(user, value)
        # Unknown keys are ignored.
    return user


def create_user(name, email):
    """Create a new user profile with synced display_name."""
    return {
        "name": name,
        "display_name": name,
        "email": email,
        "age": None,
    }

```
