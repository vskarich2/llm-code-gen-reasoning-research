# Developer's Reasoning

## Root Cause
In pipeline() the variable passed to compute_raw_stats is 'cleaned' (the normalized data) instead of the original 'data'. Specifically, the line raw_stats = compute_raw_stats(cleaned) computes statistics from the transformed values rather than from the original input.

## Failure Mechanism
Because compute_raw_stats() is given the normalized list, raw statistics reflect the 0-1 scaled values. For example, with input data = [1, 2, 3], normalize(data) returns [0.0, 0.5, 1.0], so raw_stats['raw_max'] becomes 1.0 (max of cleaned) instead of 3 (max of original data). This manifests wherever callers expect raw_stats to represent the original data.

## Broken Invariant
For any non-empty input list data, pipeline(data)['raw_stats']['raw_max'] must equal max(data) (and similarly raw_min == min(data), raw_sum == sum(data)). For empty or falsy inputs, raw_max/raw_min/raw_sum must be 0. The current implementation violates this by computing those values from the normalized list.

## Fix Strategy
Compute raw_stats from the original input before performing normalization and make the code intent explicit. I changed pipeline() to call compute_raw_stats(data) first and then call normalize(data). This ensures raw_stats are derived from the untransformed input (restoring the invariant). I also clarified the docstring to state the ordering and preserved the returned key name 'cleaned' so external consumers are unaffected.

```python
"""Metrics pipeline: compute raw stats before transforming data."""


def compute_raw_stats(data):
    """Compute statistics on raw (untransformed) data."""
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0}
    return {
        "raw_max": max(data),
        "raw_min": min(data),
        "raw_sum": sum(data),
    }


def normalize(data):
    """Normalize data to 0-1 range."""
    if not data:
        return []
    lo, hi = min(data), max(data)
    if hi == lo:
        return [0.5] * len(data)
    return [(x - lo) / (hi - lo) for x in data]


def pipeline(data):
    """Run pipeline: compute stats on original data, then normalize.

    raw_stats MUST reflect the original data, not the normalized version.
    """
    # Compute statistics on the original input first so they reflect
    # untransformed values.
    raw_stats = compute_raw_stats(data)
    cleaned = normalize(data)
    return {"raw_stats": raw_stats, "cleaned": cleaned}


def format_report(result):
    """Format pipeline result for display."""
    return f"max={result['raw_stats']['raw_max']}"

```
