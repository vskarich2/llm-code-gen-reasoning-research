# Developer's Reasoning

## Root Cause
The bug is in process_batch's default parameter seen in code_snippets_v2/mutable_default_b/worker.py: seen=set() is evaluated once at function definition time, so the single set object is shared across all calls. As a result, the local variable seen retains entries added by previous calls instead of being a fresh set for each call.

## Failure Mechanism
Concrete scenario: call process_batch([{'name': 't1'}]) — the function adds 't1' to the default seen set and returns [{'name':'t1','result':'processed'}]. A subsequent call process_batch([{'name': 't1'}]) with an otherwise identical fresh batch now checks if 't1' is in seen (it is, from the prior call) and skips it, returning an empty list. This manifests as valid tasks in later batches being skipped because the shared seen set contains names from earlier, unrelated calls.

## Broken Invariant
The function-level invariant in worker.py is violated: 'each call to process_batch with a fresh batch must process ALL tasks in that batch, regardless of prior calls.' Specifically, for any list tasks, calling process_batch(tasks) with no explicit seen argument must return a results list with length equal to len(tasks) (i.e., process every task) — but with the current code repeated calls can return fewer results when names were added to the shared default seen set in earlier calls.

## Fix Strategy
Change the mutable default argument to None and create a new set inside the function when seen is not provided. This ensures that when callers do not pass a seen set, each invocation gets its own fresh set and no state is shared across calls. If a caller explicitly passes a set, the function still uses it to allow intentional shared tracking.

"""Worker that processes task batches."""

from queue import create_task


def process_batch(tasks, seen=None):
    """Process a batch of tasks, skipping already-seen ones.

    Invariant: each call to process_batch with a fresh batch must
    process ALL tasks in that batch, regardless of prior calls.
    """
    if seen is None:
        seen = set()
    results = []
    for task in tasks:
        task_id = task["name"]
        if task_id in seen:
            continue
        seen.add(task_id)
        results.append({"name": task["name"], "result": "processed"})
    return results


def summarize(results):
    """Summarize processing results (distractor)."""
    return f"{len(results)} tasks processed"
