# Developer's Reasoning

## Root Cause
The bug is in place_order: after calling inventory.reserve(qty), the except block for wallet.charge re-raises the ValueError without calling inventory.release(qty). As a result the variable inventory.reserved (modified by Inventory.reserve) is never rolled back when wallet.charge fails.

## Failure Mechanism
Concrete scenario: Inventory.stock == 10, Inventory.reserved == 0. place_order(inventory, wallet_with_balance_0, qty=3, price=5) calls inventory.reserve(3) which sets inventory.reserved to 3. wallet.charge(15) raises ValueError due to insufficient funds. The original code's except ValueError: raise re-raises immediately and never calls inventory.release(3). The reservation remains (reserved == 3), reducing available() from 10 to 7 permanently, effectively leaking inventory and preventing other orders from using those 3 units.

## Broken Invariant
If wallet.charge raises a ValueError during place_order, the function must not change inventory.reserved (i.e., inventory.reserved after the call must equal inventory.reserved before the call). Equivalently, inventory.available() must remain the same after a failed place_order. The original code violates this invariant because it leaves the reservation in place when charging fails.

## Fix Strategy
I added an explicit rollback: when wallet.charge raises, place_order now calls inventory.release(qty) before re-raising, ensuring the reservation is undone. I also hardened Inventory.release to validate that releases do not drive reserved negative (raising a ValueError if a release exceeds reserved). These changes ensure that a failed charge returns inventory to its pre-call state and preserve the reserved/available invariants.

"""Order fulfillment with inventory and wallet."""


class Inventory:
    def __init__(self, stock):
        self.stock = stock
        self.reserved = 0

    def reserve(self, qty):
        if qty > self.stock - self.reserved:
            raise ValueError("insufficient stock")
        self.reserved += qty

    def release(self, qty):
        # Prevent releasing more than currently reserved to keep internal state consistent
        if qty > self.reserved:
            raise ValueError("release exceeds reserved")
        self.reserved -= qty

    def available(self):
        return self.stock - self.reserved


class Wallet:
    def __init__(self, balance):
        self.balance = balance

    def charge(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount


def place_order(inventory, wallet, qty, price):
    """Reserve inventory, then charge wallet. Release reservation on failure."""
    inventory.reserve(qty)
    try:
        wallet.charge(qty * price)
    except ValueError:
        # Roll back the reservation if charging fails so inventory isn't leaked
        inventory.release(qty)
        raise
    return {"status": "confirmed", "qty": qty, "total": qty * price}
