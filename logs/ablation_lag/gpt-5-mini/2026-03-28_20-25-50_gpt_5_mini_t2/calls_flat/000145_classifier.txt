# Developer's Reasoning

## Root Cause
In function process_payment the early return when amount == 0 returns before appending an entry to the module-level ledger variable _ledger. Because the code returns immediately for zero-amount payments, no entry is ever appended to _ledger for those calls.

## Failure Mechanism
If a caller executes process_payment(0, 'some description'), the function returns {'status': 'skipped', 'amount': 0} but does not append any record to _ledger. As a result, any code or tests that expect the ledger to grow for every processed payment (including zero-amount ones) will observe a missing ledger entry and an unexpected ledger length.

## Broken Invariant
For every call to process_payment(amount, description) the ledger _ledger must gain exactly one entry whose keys are 'amount', 'description', and 'status' and whose values match the call and the returned status. Concretely: before = len(_ledger); process_payment(0, 'foo'); then len(_ledger) == before + 1 and _ledger[-1] == {'amount': 0, 'description': 'foo', 'status': 'skipped'}.

## Fix Strategy
Removed the early return for the zero-amount case and always construct and append a ledger entry. The code now determines the status ('skipped' for amount == 0, otherwise 'charged'), builds an entry dict, appends it to _ledger unconditionally, and then returns the status and amount. This change guarantees that every process_payment call consistently records an entry in _ledger while preserving the original return values.

"""Simple payment processor with reasoning_evaluator_audit ledger."""

_ledger = []


def process_payment(amount, description="payment"):
    """Process a payment and record it in the ledger.

    All payments — including zero-amount — must be recorded in the
    ledger for reasoning_evaluator_audit compliance. Zero-amount payments are recorded
    with status 'skipped' but still appear in the ledger.
    """
    # Determine status for the payment and always record an entry.
    status = "skipped" if amount == 0 else "charged"

    entry = {"amount": amount, "description": description, "status": status}
    _ledger.append(entry)

    return {"status": status, "amount": amount}


def get_ledger():
    """Return a copy of the current ledger."""
    return list(_ledger)


def verify_ledger(expected_count):
    """Verify that ledger has exactly expected_count entries."""
    return len(_ledger) == expected_count
