# Developer's Reasoning

## Root Cause
In Report.insert_column the list self.column_widths is not updated when a new header (and corresponding cells in each row) is inserted. The function inserts into self.headers and into each row, but leaves self.column_widths at its old length, so headers, rows and column_widths become unsynchronized.

## Failure Mechanism
When insert_column is called (e.g. report.insert_column(1, 'NewCol')), self.headers grows by one but self.column_widths remains the previous length. Later, Report.render() calls format_table(self.headers, self.rows, self.column_widths). In formatter.format_table the list comprehension header_parts = [h.ljust(widths[i]) for i, h in enumerate(headers)] attempts to access widths[i] for the new header index i, causing an IndexError because widths is shorter than headers. Thus inserting a column triggers a runtime failure during rendering.

## Broken Invariant
After any call that mutates columns (including insert_column), len(self.headers) == len(self.column_widths) must hold. Currently insert_column violates this invariant by not inserting a corresponding element into self.column_widths.

## Fix Strategy
Update insert_column to insert a new width at the same position as the header and row insertions. The change inserts self.column_widths.insert(position, new_width) where new_width = max(len(header), len(str(default_value))). This restores the invariant that headers and column_widths have the same length and chooses a sensible initial width derived from the header text and the supplied default cell value, preventing the IndexError in format_table.

class Report:
    """A table with synchronized headers, rows, and column widths."""

    def __init__(self, headers, default_width=10):
        self.headers = list(headers)
        self.rows = []
        self.column_widths = [default_width] * len(headers)

    def add_row(self, *values):
        """Add a row, padding to match current column count."""
        row = make_row(values, len(self.headers))
        self.rows.append(row)

    def insert_column(self, position, header, default_value=""):
        """Insert a new column at the given position.

        Must update headers, every row, AND column_widths
        to keep all three arrays in sync.
        """
        self.headers.insert(position, header)
        for row in self.rows:
            row.insert(position, default_value)
        # Update column_widths to keep in sync with headers and rows.
        # Choose a width based on the header text and the default value so
        # the table remains consistently formatted after insertion.
        new_width = max(len(header), len(str(default_value)))
        self.column_widths.insert(position, new_width)

    def render(self):
        """Render the table using the formatter."""
        return format_table(self.headers, self.rows, self.column_widths)

    def validate(self):
        """Validate internal consistency."""
        return validate_table(self.headers, self.rows, self.column_widths)

    def column_count(self):
        """Return number of columns."""
        return len(self.headers)
