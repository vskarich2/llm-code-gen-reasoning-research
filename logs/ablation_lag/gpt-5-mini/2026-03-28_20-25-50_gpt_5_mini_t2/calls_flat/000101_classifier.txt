# Developer's Reasoning

## Root Cause
In order_service.place_order the except block for _process_payment re-raises the ValueError without releasing the inventory reservation. Concretely, reserve(product_id, qty) increments the inventory module's _reserved, but the code never calls release(product_id, qty) when _process_payment raises, leaving inventory._reserved elevated for that product.

## Failure Mechanism
Example: inventory.add_product('sku1', 5) makes _stock['sku1']==5. set_gateway_fail(True) causes _process_payment to raise. Calling place_order('sku1', 2, price) executes reserve('sku1',2) which sets inventory._reserved['sku1'] == 2, then _process_payment raises. place_order's except re-raises without calling release, so inventory._reserved['sku1'] remains 2. Subsequent calls to available('sku1') return 3 (5 - 2) even though payment failed and the reservation should have been rolled back, causing incorrect availability and potential persistent reservation leakage.

## Broken Invariant
If place_order raises a payment error, the inventory reservation must be rolled back. Formally: for any product_id and qty, if place_order(product_id, qty, price) raises ValueError due to payment, then inventory.get_reserved(product_id) after the call equals the value before the call (i.e., no net increase in _reserved).

## Fix Strategy
On payment failure, call release(product_id, qty) before re-raising so the reservation is undone. Also ensure order_service.reset clears the inventory state by invoking inventory.reset() instead of attempting to clear _stock/_reserved locally. The changes add a release(...) call in the except block and replace the incorrect reset logic with a call to the inventory reset function, guaranteeing reservations are reverted when payment fails and that reset actually clears inventory state.

"""Order service coordinating inventory and payment."""

from inventory import reserve, release, reset as inventory_reset

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail
    _notifications = []
    _gateway_fail = False
    # Ensure inventory module state is reset as well
    inventory_reset()


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Roll back the inventory reservation before propagating the error
        try:
            release(product_id, qty)
        except Exception:
            # release should not fail under normal conditions; if it does,
            # do not mask the payment error.
            pass
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
