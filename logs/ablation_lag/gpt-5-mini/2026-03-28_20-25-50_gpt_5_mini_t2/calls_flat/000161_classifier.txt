# Developer's Reasoning

## Root Cause
In Report.delete_column the code deletes an entry from self.headers (del self.headers[index]) but never removes the corresponding element from any lists in self.rows. The bug is in the delete_column method operating on self.headers only, leaving self.rows unchanged.

## Failure Mechanism
When delete_column is called (for example headers=['A','B','C'] and rows=[[1,2,3]] with index=1), the header 'B' is removed so self.headers becomes ['A','C'] but the row remains [1,2,3]. Later render() builds dict(zip(self.headers, row)) which zips the two lists positionally and produces {'A': 1, 'C': 2} — the value for 'C' is now the previous value for 'B', so columns are misaligned and data maps to the wrong headers.

## Broken Invariant
After any call to Report.delete_column(index), for every row in self.rows the statement len(row) == len(self.headers) must hold. Currently that invariant can be violated because headers are shortened without removing the corresponding element from each row.

## Fix Strategy
Modify delete_column to (1) validate that the provided index is in range (supporting negative indices consistently), (2) verify every row currently has the same number of elements as headers using data.validate_row before making changes, and only then (3) delete the header AND delete the element at the same index from every row. This ensures the invariant len(row) == len(self.headers) holds after deletion and prevents misalignment. The change also raises a clear error if rows are not aligned prior to deletion.

from data import make_row, validate_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        expected = len(self.headers)
        # normalize and validate index (support negative indices like list semantics)
        if not -expected <= index < expected:
            raise IndexError("column index out of range")
        if index < 0:
            index = expected + index

        # Ensure all rows currently have the same number of columns as headers
        for i, row in enumerate(self.rows):
            if not validate_row(row, expected):
                raise ValueError(
                    f"Row {i} has length {len(row)} but expected {expected}; cannot safely delete column"
                )

        # Now remove the header and the corresponding element from every row
        del self.headers[index]
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
