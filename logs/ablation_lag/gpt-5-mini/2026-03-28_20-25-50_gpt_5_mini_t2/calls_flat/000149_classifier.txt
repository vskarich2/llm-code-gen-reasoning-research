## Root Cause
In code_snippets_v2/early_return_b/payment.py the function process_payment uses the module-level cache _cache to detect duplicates and returns early when txn_id is found (if txn_id in _cache: return _cache[txn_id]) before calling ledger.record. The early return prevents ledger.record from being invoked for duplicate calls.

## Failure Mechanism
If process_payment is called twice with the same txn_id (e.g. process_payment('t1', 100) followed by process_payment('t1', 100)), the first call creates a ledger entry and caches the result. The second call hits the early-return branch and returns the cached result without calling record, so the ledger._entries list contains only one entry but two process_payment calls were made. As a concrete manifestation: after two calls ledger.verify(2) returns False because len(_entries) == 1.

## Broken Invariant

Concretely, after calling process_payment('x', a) twice, ledger.verify(2) should be True; with the current code it is False.

## Fix Strategy
On a cache hit we now still call ledger.record before returning the cached result. I fetch the cached result and call record(txn_id, result['amount'], result['status']) and then return result. This preserves the original caching behavior (same returned result) while ensuring every call appends an entry to the ledger, so ledger._entries length increments for duplicates and ledger.verify will reflect the total number of process_payment calls.

"""Payment processor with duplicate detection."""

from ledger import record, verify, reset_ledger

_cache = {}


def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # Ensure every call is recorded. On cache hit, record the cached result
    # (so ledger reflects each invocation) and then return the cached result.
    if txn_id in _cache:
        result = _cache[txn_id]
        # record this invocation as well (use the actual charged amount/status)
        record(txn_id, result["amount"], result["status"])
        return result

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result


def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)


def reset():
    """Reset payment state."""
    _cache.clear()
    reset_ledger()
