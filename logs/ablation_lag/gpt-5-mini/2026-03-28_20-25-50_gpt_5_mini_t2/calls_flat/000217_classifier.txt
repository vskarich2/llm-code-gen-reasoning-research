# Developer's Reasoning

## Root Cause
In make_increment_steps() the nested step_write() uses the snapshot stored in captured['current'] (set by step_read()) when calling _set(captured['current'] + 1). That causes step_write to overwrite the shared variable _value with a stale value+1 instead of incrementing the current global _value.

## Failure Mechanism
In interleaved_double_increment() run_steps is called with ordering [(read_a, ()), (read_b, ()), (write_a, ()), (write_b, ())]. Both step_read calls store 0 into their own captured['current']. Then write_a calls _set(captured['current'] + 1) -> _set(0 + 1) sets _value to 1. Then write_b calls _set(captured['current'] + 1) -> _set(0 + 1) again sets _value to 1, overwriting the previous update. The net effect is one lost increment and get() returns 1 instead of 2.

## Broken Invariant
Starting from reset() (so _value == 0), performing two increments implemented as the pair of steps returned by make_increment_steps() must result in get() == 2 for any interleaving of their read/write steps. Currently, an interleaving where both reads happen before either write violates this invariant.

## Fix Strategy
Make the write step compute the new value from the current global state at write time instead of from the earlier captured snapshot. Concretely, change step_write() to call get() and use _set(get() + 1). This guarantees each write performs an increment of the then-current _value, so even if both reads were stale, the two writes compose to +2 under any ordering.



# Task Description

def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_increment_steps():
    """Split a read-then-increment into separate read and write steps.

    FIX: compute the increment at write-time from the current global value
    so that writes don't overwrite each other when reads were interleaved.
    """

        captured["current"] = get()

        # Use the live global value at write time to avoid lost updates.
        new = get() + 1
        _set(new)
        return ("write", new)

    return step_read, step_write
