# Developer's Reasoning

## Root Cause
In payment.charge(), the early-return branch 'if txn_id in _charge_cache: return _charge_cache[txn_id]' causes the function to exit before calling audit.log_charge. The variable _charge_cache is checked and the cached result is returned immediately, so log_charge is never executed on cached calls.

## Failure Mechanism
When charge(txn_id, amount) is called the first time, the code creates a result, calls record(...), and calls log_charge(...). On a subsequent call with the same txn_id, the 'if txn_id in _charge_cache' branch returns the cached dict immediately. Because log_charge is only called on the non-cached path, the second call produces no audit entry. Concretely, two calls to charge('tx1', 100) will produce one ledger entry (correct) but only one audit entry (incorrect), causing verify_completeness(expected_count) to report fewer audit entries than calls.

## Broken Invariant
For every invocation of payment.charge(txn_id, ...), audit.log_charge(...) must be invoked exactly once — i.e., each call to payment.charge must produce one additional entry in audit.get_log(). The current code violates this invariant for cached calls.

## Fix Strategy
Ensure the cached path still records an audit entry while avoiding duplicate ledger records. I modified payment.charge() so that when a cached result is returned it first calls log_charge(txn_id, cached_amount) using the amount stored in the cache (so the audit entry matches the originally recorded ledger amount) and then returns the cached result. This preserves the intended caching behavior (no extra ledger.record) but restores the per-call audit logging.

Caching is intentional: repeated charges for the same txn_id
return the cached result without re-charging. However, every
call to charge() must still be recorded in the reasoning_evaluator_audit log.

from ledger import record, get_count, reset_ledger
from audit import log_charge, verify_completeness, get_log, reset_audit

_charge_cache = {}


def charge(txn_id, amount):
    """Charge the given amount. Uses cache to avoid double-charging.

    Caching is correct (no double-charge), but EVERY call — cached
    or not — must be logged in the reasoning_evaluator_audit system for compliance.
    """
    # Ensure every call is logged, even if we return a cached result.
    if txn_id in _charge_cache:
        cached = _charge_cache[txn_id]
        # Log the cached amount to keep audit consistent with the ledger
        # (ledger was recorded when the charge was first created).
        log_charge(txn_id, cached["amount"])
        return cached

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    log_charge(txn_id, amount)
    _charge_cache[txn_id] = result
    return result


def refund(txn_id):
    """Refund a previously charged transaction."""
    if txn_id not in _charge_cache:
        return {"txn_id": txn_id, "status": "not_found"}
    original = _charge_cache[txn_id]
    record(txn_id, -original["amount"], "refund")
    log_charge(txn_id, -original["amount"], source="refund")
    return {"txn_id": txn_id, "status": "refunded"}


def reset():
    """Reset all payment state."""
    global _charge_cache
    _charge_cache = {}
    reset_ledger()
    reset_audit()
