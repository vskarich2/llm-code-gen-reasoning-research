# Developer's Reasoning

## Root Cause
In config.create_config() the line `config = DEFAULTS` (config.py) returns a reference to the module-level DEFAULTS dict instead of a fresh dict. That reference is then cached by app.get_settings() (via the module-level _cached_settings), so callers receive an alias to DEFAULTS rather than an independent snapshot.

## Failure Mechanism
Concrete scenario: 1) First call app.get_settings() -> create_config() returns the DEFAULTS dict object (not a copy) and app stores it in _cached_settings. 2) Later config.reset_defaults() runs and reassigns the module-level DEFAULTS to a new dict. Because _cached_settings still points to the original dict object (the old DEFAULTS), subsequent app.get_settings() returns the old values (stale) instead of the updated defaults. Another manifestation: app.apply_overrides() calls settings.update(...) on the cached reference which mutates the shared DEFAULTS dict object, causing unexpected global mutations.

## Broken Invariant
After calling config.reset_defaults() (or otherwise changing module-level defaults), a subsequent call to app.get_settings() must return the current defaults (i.e., a dict equal to DEFAULTS). Currently, get_settings() can return the previously cached dict (alias of former DEFAULTS) and therefore may not equal the current DEFAULTS.

## Fix Strategy
Two changes remove the aliasing and stale-cache problems: 1) create_config() now builds and returns a fresh copy of DEFAULTS (dict(DEFAULTS)), so callers cannot accidentally mutate the module-level DEFAULTS. 2) get_settings() no longer caches a settings object; it calls create_config() each time and returns a fresh config dict. Together these changes prevent stale references and unintended mutations of DEFAULTS. clear_cache() is retained as a no-op to preserve the public API.

def get_settings():
    """Return app settings as a fresh dict each call (no caching)."""
    return create_config()


def apply_overrides(overrides):
    """Return a config dict with runtime overrides applied. Does not mutate cached state."""
    settings = create_config()
    settings.update(overrides)
    return settings


def clear_cache():
    """No-op kept for compatibility: caching removed, so nothing to clear."""
    return None


DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}


def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides.

    Always return a new dict so callers cannot accidentally mutate the module-level DEFAULTS
    and so callers get a fresh snapshot when requested.
    """
    config = dict(DEFAULTS)
    if overrides:
        config.update(overrides)
    return config


def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result


def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}
