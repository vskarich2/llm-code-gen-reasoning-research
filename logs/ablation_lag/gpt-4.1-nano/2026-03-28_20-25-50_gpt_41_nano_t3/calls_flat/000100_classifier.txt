# Developer's Reasoning

## Root Cause
In the order_service.py, the place_order function calls reserve() to reserve inventory but does not call release() to free the reservation if the payment fails, leaving the inventory stuck as reserved.

## Failure Mechanism
When a payment failure occurs during place_order, the exception is re-raised without releasing the reserved inventory, causing the reserved count to remain elevated and the inventory to appear unavailable for future reservations.

## Broken Invariant
After a payment failure during place_order, the reserved quantity for the product should be released, ensuring available stock reflects only unreserved inventory.

## Fix Strategy
Adding a finally block that calls release() with the reserved quantity if an exception occurs during payment processing ensures the reservation is freed, maintaining the invariant that reservations are only held for successful payments.

from inventory import reserve, release

_notifications = []
_gateway_fail = False


def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        # Release the reservation if payment fails
        release(product_id, qty)
        raise  # Re-raise the exception after releasing
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
