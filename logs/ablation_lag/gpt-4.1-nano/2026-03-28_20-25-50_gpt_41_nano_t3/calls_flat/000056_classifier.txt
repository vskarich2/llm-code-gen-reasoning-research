## Root Cause
The decorator 'with_history' in 'scheduler.py' uses a default argument 'history=_shared_log', which is a reference to the module-level list '_shared_log'. This causes all decorated functions to share the same history list, leading to shared scheduler history across different functions.

## Failure Mechanism
When multiple functions like 'schedule_one' and 'schedule_batch' are decorated with 'with_history', they all append their call records to the same '_shared_log' list. As a result, calling 'get_all_stats' will report combined call counts, not separate histories, and the shared history persists across different functions and tests, causing incorrect or misleading scheduler history data.

## Broken Invariant
Each decorated function must have its own independent call history list, so that call counts and histories are isolated per function, preventing shared state across different decorated functions.

## Fix Strategy
Changing the default argument of 'history' in 'with_history' from '_shared_log' to None, and initializing a new list inside the wrapper if 'history' is None, ensures each decorated function gets its own separate history list. This prevents shared state and maintains correct, isolated call histories per function.

from worker import process, batch_process

_shared_log = []

def with_history(func, history=None):
    """Decorator that records call history for a function.

    Invariant: each decorated function must have its OWN
    independent history list.
    """
    # Fix: default argument changed from _shared_log to None.
    if history is None:
        history = []

    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(history)
    wrapper.clear_history = lambda: history.clear()
    return wrapper

@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)

@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)

def get_all_stats():
    """Get combined stats (distractor)."""
