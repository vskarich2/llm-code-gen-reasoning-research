# Developer's Reasoning

## Root Cause
The get_access function uses _ROLE_DISPATCH.get(role, _default_access), which defaults to _default_access when the role is not found in _ROLE_DISPATCH. Since 'guest' is missing from _ROLE_DISPATCH, it falls back to _default_access, returning no access, even though guest roles should have read-only access.

## Failure Mechanism
When get_access is called with role='guest', the role is not in _ROLE_DISPATCH, so _default_access is used, returning no permissions. This causes can_read('guest') to return False, denying guest users read access, which violates the intended behavior that guests should have read-only access.

## Broken Invariant
The role 'guest' should be mapped in _ROLE_DISPATCH to guest_access, ensuring guests receive read-only access, i.e., get_access('guest') should return {'read': True, 'write': False, 'delete': False}.

## Fix Strategy
Adding 'guest': guest_access to the _ROLE_DISPATCH dictionary ensures that get_access('guest') invokes guest_access, returning the correct read-only permissions for guest users, aligning with the intended access control policy.

```python
def admin_access():
    """Full access for admins."""

def user_access():

    return {"read": True, "write": True, "delete": False}


def moderator_access():
    """Moderators can read and delete but not write."""
    return {"read": True, "write": False, "delete": True}


def guest_access():
    """Guests get read-only access."""
    return {"read": True, "write": False, "delete": False}


"""Authentication and authorization dispatch."""

from roles import admin_access, user_access, moderator_access, guest_access


# Dispatch table mapping roles to access handlers
_ROLE_DISPATCH = {
    "admin": admin_access,
    "user": user_access,
    "moderator": moderator_access,
    "guest": guest_access
}


def _default_access():
    """Default: no access for unknown roles."""
    return {"read": False, "write": False, "delete": False}


def get_access(role):
    """Return the access dict for a given role."""
    handler = _ROLE_DISPATCH.get(role, _default_access)
    return handler()


def can_read(role):
    """Check if role has read access."""
    return get_access(role).get("read", False)

```
