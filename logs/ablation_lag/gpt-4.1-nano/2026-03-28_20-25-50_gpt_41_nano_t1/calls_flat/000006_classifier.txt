# Developer's Reasoning

## Root Cause
In config.py, create_config() assigns config = DEFAULTS, which references the global DEFAULTS dictionary directly, causing the returned config to be the same object as DEFAULTS. Therefore, any update to config modifies DEFAULTS itself, leading to stale data when defaults are reset or reloaded.

## Failure Mechanism
When get_settings() calls create_config(), it receives a reference to DEFAULTS. If apply_overrides() updates this config, it modifies DEFAULTS directly. Subsequent calls to get_settings() will return the same modified object, not a fresh copy, causing stale or unintended data after config changes or resets.

## Broken Invariant
create_config() must return a new independent copy of the defaults each time, so that modifications to the returned config do not affect the original DEFAULTS or subsequent calls.

## Fix Strategy
In create_config(), replace 'config = DEFAULTS' with 'config = dict(DEFAULTS)' to create a new copy, ensuring that each call returns an independent configuration object, preventing shared references and stale data.

from config import create_config

_cached_settings = None

def get_settings():
    """Return app settings, caching the result."""
    global _cached_settings
    if _cached_settings is None:
        _cached_settings = create_config()
    return _cached_settings

def apply_overrides(overrides):
    """Apply runtime overrides to the cached settings."""
    settings = get_settings()
    settings.update(overrides)
    return settings

def clear_cache():
    """Clear cached settings so next get_settings() re-reads defaults."""
    global _cached_settings
    _cached_settings = None

DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}

def create_config(overrides=None):
    """Return a config dict based on defaults, with optional overrides."""
    config = dict(DEFAULTS)  # Create a new copy of DEFAULTS
    if overrides:
        config.update(overrides)
    return config

def merge_overrides(base, overrides):
    """Merge overrides into a copy of base. Used by admin tools."""
    result = dict(base)
    result.update(overrides)
    return result

def reset_defaults():
    """Restore defaults to factory values."""
    global DEFAULTS
    DEFAULTS = {"timeout": 30, "retries": 3, "debug": False}
