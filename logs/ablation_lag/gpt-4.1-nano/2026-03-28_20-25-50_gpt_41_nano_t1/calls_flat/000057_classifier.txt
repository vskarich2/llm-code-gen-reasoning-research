## Root Cause
The decorator 'with_history' in 'scheduler.py' uses a default argument 'history=_shared_log', which is a reference to the module-level list '_shared_log'. This causes all decorated functions to share the same history list, leading to shared scheduler history across different functions.

## Failure Mechanism
When multiple functions like 'schedule_one' and 'schedule_batch' are decorated with 'with_history', they all append their call records to the same '_shared_log' list. As a result, calling 'get_all_stats' will report combined call counts, not separate histories, and the shared history persists across different functions and tests, causing incorrect or misleading scheduler history data.

## Broken Invariant
Each decorated function must have its OWN independent history list, so that call histories are isolated per function and do not share or interfere with each other.

## Fix Strategy
I changed the 'with_history' decorator to initialize the 'history' list inside the wrapper function itself, rather than using a default argument. This ensures each decorated function gets its own separate list, preventing shared state. Specifically, I moved 'history = []' inside the 'wrapper' function, so that each call creates a new list for that function's history.

```python
"""Scheduler with decorator that tracks call history."""

from worker import process, batch_process


def with_history(func):
    """Decorator that records call history for a function."""
    # Initialize a new history list for each decorated function
    def wrapper(*args, **kwargs):
        if not hasattr(wrapper, '_history'):
            wrapper._history = []
        result = func(*args, **kwargs)
        wrapper._history.append({"func": func.__name__, "args_count": len(args)})
        return result

    wrapper.get_history = lambda: list(getattr(wrapper, '_history', []))
    wrapper.clear_history = lambda: getattr(wrapper, '_history', []).clear()
    return wrapper


@with_history
def schedule_one(task):
    """Schedule and process a single task."""
    return process(task)


@with_history
def schedule_batch(tasks):
    """Schedule and process a batch of tasks."""
    return batch_process(tasks)


def get_all_stats():
    """Get combined stats (distractor)."""
    return {
        "one_calls": len(schedule_one.get_history()),
        "batch_calls": len(schedule_batch.get_history()),
    }

```
