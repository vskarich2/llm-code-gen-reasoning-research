## Root Cause
In report.py, the insert_column method updates self.headers and each row in self.rows but neglects to update self.column_widths, which should be extended at the insertion point to match the new column. This causes the column_widths list to become shorter than the headers and data rows, leading to misaligned table formatting after inserting a column.

## Failure Mechanism
When insert_column is called, the headers and rows are updated to include the new column, but self.column_widths remains unchanged, retaining its previous length. During rendering, format_table uses self.column_widths to pad columns, but since self.column_widths is shorter than headers and data, it results in index errors or misaligned columns, breaking the report's visual structure.

## Broken Invariant
The length of self.column_widths must always match the length of self.headers and each row in self.rows, ensuring consistent column widths during formatting.

## Fix Strategy
I added a line in insert_column to insert the width of the new header into self.column_widths at the same position as the header and data columns, maintaining the invariant that all three lists are synchronized in length.

def make_row(values, num_cols):
    """Create a row with exactly num_cols elements, padding if needed."""
    row = list(values)[:num_cols]
    while len(row) < num_cols:
        row.append(None)
    return row


def validate_table(headers, rows, widths):
    """Check structural consistency of table components."""
    if len(headers) != len(widths):
        return False, "header/width count mismatch"
    for i, row in enumerate(rows):
        if len(row) != len(headers):
            return False, f"row {i} has {len(row)} cols, expected {len(headers)}"
    return True, "ok"


"""Table formatter that uses column widths for alignment."""


def format_table(headers, rows, widths):
    """Format a table into aligned string rows.

    Uses widths[i] to pad column i. All three arrays must
    have the same length for correct output.
    """
    lines = []
    header_parts = [h.ljust(widths[i]) for i, h in enumerate(headers)]
    lines.append(" | ".join(header_parts))
    lines.append("-+-".join("-" * w for w in widths))
    for row in rows:
        parts = [str(row[i]).ljust(widths[i]) for i in range(len(headers))]
        lines.append(" | ".join(parts))
    return lines


def recalculate_widths(headers, rows):
    """Recalculate column widths based on actual data.

    Returns a list of widths, one per column.
    """
    widths = [len(h) for h in headers]
    for row in rows:
        for i, val in enumerate(row):
            widths[i] = max(widths[i], len(str(val)))
    return widths
