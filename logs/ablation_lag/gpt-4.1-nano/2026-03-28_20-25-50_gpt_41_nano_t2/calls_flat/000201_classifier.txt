## Root Cause
The functions 'sync_user_to_cache' and 'refresh_user_snapshot' both perform cache updates for user data but are implemented separately, leading to duplicated logic and inconsistent cache synchronization. Specifically, 'refresh_user_snapshot' uses 'cache_put_if_absent' to set the user in cache if absent, while 'sync_user_to_cache' unconditionally updates the cache, causing potential inconsistency.

## Failure Mechanism

Conversely, 'sync_user_to_cache' always updates the cache. This inconsistency causes cache data to be stale or incomplete after user updates, especially if 'refresh_user_snapshot' is used in places expecting a full cache refresh.

## Broken Invariant

## Fix Strategy

Replace all calls to both functions with 'update_user_cache', ensuring consistent cache updates. This guarantees that cache always contains the latest user information after any operation.
