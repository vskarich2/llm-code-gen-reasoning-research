# Developer's Reasoning

## Root Cause
The process_batch function in pipeline.py was modified to remove calls to commit(st) and freeze_view(st), which are responsible for updating the 'stable' data and setting the 'frozen' flag in the state. Without these steps, the state remains uncommitted and unfrozen, causing the system to lack a consistent 'stable' snapshot and the 'frozen' status, which are essential for correct data verification and digest calculations.

## Failure Mechanism
When process_batch is called, it updates the 'pending' and 'view' data but does not promote these to 'stable' or mark the state as 'frozen'. As a result, functions like get_committed_total and get_committed_digest, which depend on 'meta.frozen' being True and 'stable' data being available, return None or inconsistent results. This leads to failures in verifying data consistency, such as in ingest_and_verify, which compares view and committed digests, now mismatched or invalid due to missing committed data.

## Broken Invariant
The invariant that 'meta.frozen' is True if and only if 'stable' contains the committed data, and that 'get_committed_total' and 'get_committed_digest' return meaningful values only when the state is frozen, is violated. Specifically, after processing, the state remains unfrozen and uncommitted, causing these functions to return None or inconsistent data, breaking the assumption that the view and committed data are synchronized and verifiable.

## Fix Strategy
Reintroduce the commit(st) and freeze_view(st) calls in process_batch after staging the data. This restores the 'stable' snapshot and sets 'meta.frozen' to True, ensuring that functions relying on these flags and data behave correctly. The updated process_batch function now performs all necessary steps to maintain the invariant that a committed, frozen state exists after processing a batch.

    return {
        "raw": list(entries),
        "pending": [],
        "stable": [],
        "view": [],
        "meta": {"version": 0, "frozen": False},
    }


def normalize(raw):
    return [dict(e) for e in raw]


def collapse(entries):
    merged = {}
    for e in entries:
        merged[e["id"]] = e
    return list(merged.values())


def stage(st, data):
    st["pending"] = list(data)
    st["view"] = list(data)
    st["meta"]["version"] += 1


def commit(st):
    """Promote pending to stable. Sorts by id for canonical ordering. Sets frozen gate."""
    st["stable"] = sorted(st["pending"], key=lambda e: e["id"])
    st["meta"]["frozen"] = True


def freeze_view(st):
    """Rebuild view from committed (stable) data."""
    st["view"] = list(st["stable"])


def materialize(st):
    return list(st["view"])


def get_committed_total(st):
    """Returns total only if state is committed (frozen). None otherwise."""
    if not st["meta"]["frozen"]:
        return None
    return sum(e.get("val", 0) for e in st["stable"])


def get_view_digest(st):
    """Order-sensitive digest of view items."""
    return "|".join(e["id"] for e in st["view"])


def get_committed_digest(st):
    """Order-sensitive digest of committed items."""
    if not st["meta"]["frozen"]:
        return None
    return "|".join(e["id"] for e in st["stable"])
