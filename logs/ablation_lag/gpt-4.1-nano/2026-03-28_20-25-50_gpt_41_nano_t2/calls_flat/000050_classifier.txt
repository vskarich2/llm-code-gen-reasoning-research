The enqueue function uses a mutable default argument 'queue=[]', which is shared across all calls, causing tasks to accumulate unintentionally.

## Failure Mechanism

## Broken Invariant

## Fix Strategy
Replaced the default mutable list argument with a default of None and initialized a new list inside the function if no queue is provided, preventing shared state across calls.
