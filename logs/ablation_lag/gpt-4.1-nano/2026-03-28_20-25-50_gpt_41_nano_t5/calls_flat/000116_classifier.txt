## Root Cause
In pipeline.py, the call to compute_raw_stats is passing 'normalized' data instead of the original 'data'. Since compute_raw_stats expects untransformed data, this results in incorrect raw metrics being computed.

## Failure Mechanism
When the pipeline normalizes the data before computing raw stats, the raw statistics no longer reflect the original data distribution, leading to inaccurate raw_max, raw_min, raw_sum, and raw_count values, which then affect derived metrics and reporting.

## Broken Invariant
compute_raw_stats must receive the original untransformed data to accurately compute raw metrics, and the pipeline must pass 'data' to compute_raw_stats, not 'normalized'.

## Fix Strategy
Changing the call in pipeline.py from compute_raw_stats(normalized) to compute_raw_stats(data) ensures raw metrics are computed on the original data, maintaining the correct invariant that raw stats reflect untransformed data.

"""Raw metrics computation.

compute_raw_stats MUST receive the original (untransformed) data.
"""

def compute_raw_stats(data):
    """Compute statistics on raw (untransformed) data.

    Keys: raw_max, raw_min, raw_sum, raw_count.
    """
    if not data:
        return {"raw_max": 0, "raw_min": 0, "raw_sum": 0, "raw_count": 0}
    return {
        "raw_max": max(data),
        "raw_min": min(data),
        "raw_sum": sum(data),
        "raw_count": len(data),
    }


def compute_derived(raw_stats):
    """Compute derived metrics from raw stats."""
    count = raw_stats.get("raw_count", 0)
    if count == 0:
        return {"raw_mean": 0}
    return {"raw_mean": raw_stats["raw_sum"] / count}


"""Multi-stage metrics pipeline.

Stage 1: compute raw stats on original data
Stage 2: normalize
Stage 3: clip to range
Stage 4: summarize for display
"""

from transforms import normalize, clip, summarize_for_display
from metrics import compute_raw_stats, compute_derived


def pipeline(data):
    """4-stage pipeline.

    raw_stats MUST reflect the original data before any transforms.
    """
    # Stage 2: normalize
    normalized = normalize(data)
    # Stage 3: clip
