# Developer's Reasoning

## Root Cause
The make_increment_steps() function captures the current value in a local variable 'captured' during the read step, but when two increments are interleaved, both read the same initial value (e.g., 0) because the read steps are executed before any write occurs. Consequently, both write steps set the counter to the same incremented value, causing the second increment to overwrite the first, resulting in only a single increment instead of two.

## Failure Mechanism
When two threads or steps execute concurrently, each calls the read step and captures the same initial value (e.g., 0). Both then proceed to the write step, each setting the counter to 'captured['current'] + 1', which is 1. The second write overwrites the first, so the counter ends up at 1 instead of 2, losing one update.

## Broken Invariant
After executing two concurrent increments, the counter value should increase by 2, i.e., get() should return 2, but due to the bug, it returns 1.

## Fix Strategy
Modify make_increment_steps() so that the read and write steps operate directly on the shared '_value' variable without capturing the value in a local variable. Specifically, replace the captured variable with a direct read in the write step, ensuring each increment reads the current value at the time of writing, thus preserving correct concurrent updates.



# Task Description

_value = 0


def reset():
    global _value
    _value = 0


def get():

def _set(v):
    global _value
    _value = v


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_increment_steps():
    """Split a read-then-increment into separate read and write steps.

    BUG: under interleaving, two increments both read the same value
    and both write value+1, losing one update.
    """
    # Removed 'captured' dictionary to avoid capturing the value prematurely.

    def step_read():
        return get()

    def step_write():
        _set(get() + 1)
        return get()

    return step_read, step_write


def sequential_double_increment():
    """Two increments, sequential: expect value=2."""
    reset()
    read_a, write_a = make_increment_steps()
    read_b, write_b = make_increment_steps()
