## Root Cause
The function is_enabled accepts flag_name as a parameter, which callers pass in camelCase (e.g., 'darkMode'), but the FLAGS dictionary uses snake_case keys (e.g., 'dark_mode'). This mismatch causes is_enabled to fail to find the correct key, resulting in returning False even when the feature is enabled.

## Failure Mechanism
When a caller passes a camelCase string like 'darkMode' to is_enabled, the function attempts to retrieve FLAGS['darkMode'], which does not exist, so get() returns the default False. This leads to the feature being reported as disabled despite being enabled in the FLAGS dictionary.

## Broken Invariant
The is_enabled function correctly determines whether a feature flag is enabled based on the provided flag name, assuming the flag name matches the key in FLAGS exactly, including case and format.

## Fix Strategy
Refactored is_enabled to convert the input flag_name from camelCase to snake_case before looking up in FLAGS, ensuring consistent key matching and correct feature flag status detection.

```python
FLAGS = {
    "dark_mode": True,
    "beta_features": False,
    "new_dashboard": True,
    "analytics_v2": False,
}


def is_enabled(flag_name):
    """Check if a feature flag is enabled.

    Args:
        flag_name: the flag key to look up (can be camelCase or snake_case)

    Returns:
        True if the flag is enabled, False otherwise.
    """
    # Convert camelCase to snake_case
    snake_case_name = _camel_to_snake(flag_name)
    return FLAGS.get(snake_case_name, False)


def list_flags():
    """Return all flag names."""
    return list(FLAGS.keys())


def _camel_to_snake(name):
    """Convert camelCase string to snake_case."""
    import re
    s1 = re.sub('(.)([A-Z][a-z]+)', r'\\1_\\2', name)
    return re.sub('([a-z0-9])([A-Z])', r'\\1_\\2', s1).lower()
```
