## Root Cause
The delete_column method in report.py removes the header at the specified index but does not remove the corresponding element from each row, causing misalignment between headers and data columns after deletion.

## Failure Mechanism
When delete_column is called, the header is removed but the data rows still contain the original number of elements, leading to a mismatch between headers and row data when rendering or accessing columns, which manifests as misaligned report columns.

## Broken Invariant
After calling delete_column(index), the headers and all data rows must have the same number of elements, ensuring that each header corresponds to exactly one element in each row.

## Fix Strategy
The fix involves deleting the element at the same index from each data row in addition to removing the header, maintaining the alignment between headers and row data. This is achieved by iterating over all rows and removing the element at the specified index before deleting the header.

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned.
        """
        # Remove the header at the specified index
        del self.headers[index]
        # Remove the element at the same index from each row
        for row in self.rows:
            del row[index]

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
