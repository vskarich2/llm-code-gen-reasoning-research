# Developer's Reasoning

## Root Cause
The function make_withdraw_steps creates separate check and act steps that rely on a shared 'result' dictionary. During interleaving, both check steps execute before either act step, causing both checks to pass when the balance is only sufficient for one withdrawal. Consequently, both withdrawals proceed, leading to an overdraft, even though the second withdrawal should be denied if the balance is insufficient.

## Failure Mechanism
In interleaved execution, check_a and check_b both execute before either act_a or act_b. Both checks see the initial balance of 100 as sufficient for 80, so both approve. Then, both act steps execute, each deducting 80, resulting in a total deduction of 160 from an initial 100, leaving the balance at -60. This occurs because the check and act steps are not atomic and do not account for concurrent modifications.

## Broken Invariant
The account balance must never become negative after any withdrawal, i.e., get_balance(name) >= 0 at all times, especially after withdrawal operations.

## Fix Strategy
Modify make_withdraw_steps to perform the check and withdrawal atomically within a single function, ensuring that the balance is verified and decremented in one step. This prevents the second withdrawal from proceeding if the balance is insufficient after the first withdrawal, thus maintaining the invariant that the balance never goes negative.

def reset():
    _accounts.clear()

def create_account(name, balance):

def get_balance(name):
    return _accounts.get(name, 0)

def check_balance(name, amount):
    """CHECK: is balance sufficient?"""
    return _accounts.get(name, 0) >= amount

def do_withdraw(name, amount):
    """ACT: decrement balance. Assumes caller verified."""
    _accounts[name] = _accounts.get(name, 0) - amount

def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results

def make_withdraw_steps(name, amount):
    """Split withdrawal into separate check and act steps.

    BUG: under interleaving, both checks pass before either debits.
    """
    def check_and_withdraw():
        if check_balance(name, amount):
            do_withdraw(name, amount)
            return True
        return False

    def step_withdraw():
        success = check_and_withdraw()
        return ("withdraw", success)

    return step_withdraw

def sequential_withdrawals():
    """Two withdrawals of 80 from balance=100. Sequential: second denied."""
    reset()
    create_account("alice", 100)
    check_a, act_a = make_withdraw_steps("alice", 80)
