## Root Cause
The bug is in the 'delete_column' function where the header is removed from 'self.headers' but the corresponding elements are not removed from 'self.rows'. This leads to misalignment between the headers and the data rows.

## Failure Mechanism
When a column is deleted using 'delete_column', the header is removed, but the rows still contain the data for that column. For example, if a report has headers ['A', 'B', 'C'] and rows [[1, 2, 3], [4, 5, 6]], deleting column index 1 results in headers ['A', 'C'] but rows remain [[1, 2, 3], [4, 5, 6]], causing misalignment.

## Broken Invariant
The number of elements in each row must match the number of headers at all times. This is violated when a column is deleted without removing the corresponding elements from the rows.

## Fix Strategy
The fix involves modifying the 'delete_column' function to also remove the corresponding elements from each row in 'self.rows'. This ensures that the number of elements in each row matches the number of headers after a column is deleted.

from data import make_row


class Report:
    """A simple table with column headers and data rows."""

    def __init__(self, headers):
        self.headers = list(headers)
        self.rows = []

    def add_row(self, *values):
        """Add a row of data."""
        self.rows.append(make_row(*values))

    def delete_column(self, index):
        """Remove a column by index from headers and all rows.

        Must remove the header AND the corresponding element
        from every row to keep them aligned."""
        del self.headers[index]  
        for row in self.rows:
            del row[index]  

    def render(self):
        """Render the table as a list of dicts keyed by header."""
        result = []
        for row in self.rows:
            result.append(dict(zip(self.headers, row)))
        return result

    def get_column(self, index):
        """Return all values in a given column."""
        return [row[index] for row in self.rows]

    def column_count(self):
        """Return the number of columns based on headers."""
        return len(self.headers)
