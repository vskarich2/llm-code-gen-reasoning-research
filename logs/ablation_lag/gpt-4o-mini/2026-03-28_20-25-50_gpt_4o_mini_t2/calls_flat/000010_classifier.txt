## Failure Mechanism

For example, if the first request sets `debug` to `True`, the next request will also see `debug` as `True`, even if it did not intend to enable debug mode.

## Fix Strategy
The code change creates a copy of the base configuration in the `apply_config` method before applying any overrides. This ensures that each request operates on its own independent configuration, preventing unintended side effects from previous requests.

```python
from config import create_config


class ConfigMiddleware:
    """Middleware that loads config once and applies per-request overrides."""

    def __init__(self):
        self._base = create_config()  # cached at init time

    def apply_config(self, request_overrides=None):
        """Return config for this request, applying any overrides."""
        cfg = dict(self._base)  # Create a copy to avoid mutating the cached reference
        if request_overrides:
            cfg.update(request_overrides)  # Now mutates the copy
        return cfg

    def get_timeout(self):
        return self._base.get("timeout", 30)
```
