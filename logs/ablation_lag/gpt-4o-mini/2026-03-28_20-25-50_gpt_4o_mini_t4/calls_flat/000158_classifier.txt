For example, if 'add_entry('Label1', 'Value1', 0)' is called, 'Label1' will be at index 0, but 'Value1' will be at the end of the '_values' list, leading to a mismatch.

## Broken Invariant

## Fix Strategy
The code change fixes the mechanism by modifying the 'add_entry' function to insert the value at the specified 'position' using '_values.insert(position, value)' instead of appending it. This ensures that both the label and value are aligned correctly in their respective lists.
