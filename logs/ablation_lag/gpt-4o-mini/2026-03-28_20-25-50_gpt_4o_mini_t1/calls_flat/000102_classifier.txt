## Root Cause
The bug occurs in the 'place_order' function where, upon a payment failure, the inventory reservation is not released. Specifically, the variable '_reserved' remains unchanged because the 'release' function is not called in the exception handling block.

## Failure Mechanism
When a user attempts to place an order and the payment fails (e.g., by setting '_gateway_fail' to True), the 'place_order' function raises a ValueError without releasing the reserved inventory. This results in the inventory being stuck as reserved, preventing future orders for that product until the reservation is manually reset.

## Broken Invariant
The system should ensure that all inventory reservations are released if a payment fails. This means that after a failed payment, the available stock should reflect the previously reserved quantities, allowing for new orders to be placed.

## Fix Strategy
By adding a call to the 'release' function in the exception handling block of 'place_order', the code ensures that any reserved inventory is properly released when a payment fails. This change restores the invariant that inventory reservations must be cleared on payment failure.

from inventory import reserve, release

_notifications = []

def reset():
    global _notifications, _gateway_fail, _stock, _reserved
    _notifications = []
    _gateway_fail = False
    _stock = {}
    _reserved = {}


def set_gateway_fail(fail):
    """Configure gateway to simulate payment failure."""
    global _gateway_fail
    _gateway_fail = fail


def _process_payment(amount):
    """Simulate payment gateway."""
    if _gateway_fail:
        raise ValueError("payment declined")
    return {"paid": amount}


def place_order(product_id, qty, price):
    """Place an order: reserve inventory, process payment, notify.

    If payment fails, inventory reservation should be rolled back.
    """
    reserve(product_id, qty)
    try:
        result = _process_payment(qty * price)
    except ValueError:
        release(product_id, qty)  # Fix: release inventory on payment failure
        raise
    _notifications.append({"product": product_id, "qty": qty})
    return {"status": "confirmed", "payment": result}


def get_notifications():
    return list(_notifications)
