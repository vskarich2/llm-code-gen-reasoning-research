# Developer's Reasoning

## Root Cause
The bug is in the 'process_payment' function where the early return on detecting a duplicate transaction ID (txn_id) prevents the 'record' function from being called. This means that duplicate transactions are not recorded in the ledger, leading to a mismatch between the transaction count and the ledger count.

## Failure Mechanism
If a payment is processed with a duplicate txn_id, the function checks '_cache' and finds the txn_id already exists. It then returns the cached result without recording the transaction in the ledger. For example, if 'process_payment' is called twice with the same txn_id, only the first call records the transaction, resulting in a ledger count of 1 while the transaction count is 2.

## Broken Invariant
The invariant that must hold is: 'The number of recorded transactions in the ledger must equal the number of times 'process_payment' is called, including duplicates.' This invariant is violated when duplicates are not recorded.

## Fix Strategy
The fix involves removing the early return statement that skips the 'record' function when a duplicate txn_id is detected. By ensuring that 'record' is called for every invocation of 'process_payment', the ledger will accurately reflect the total number of transactions processed.

from ledger import record, verify, reset_ledger

_cache = {}

def process_payment(txn_id, amount):
    """Process a payment. Detects duplicates via txn_id cache.

    Every call — including duplicates — must be recorded in the ledger
    so that verify() counts match total process_payment calls.
    """
    # Remove early return on duplicate to ensure all calls are recorded
    if txn_id in _cache:
        # Still return the cached result, but record the transaction
        record(txn_id, amount, "charged")
        return _cache[txn_id]

    result = {"txn_id": txn_id, "amount": amount, "status": "charged"}
    record(txn_id, amount, "charged")
    _cache[txn_id] = result
    return result

def get_cached(txn_id):
    """Retrieve a cached payment result."""
    return _cache.get(txn_id)
