# Developer's Reasoning

## Root Cause
The bug is in the `update_product` function, where the cache is not invalidated after updating a product. This means that the cached value remains stale and does not reflect the updated product information.

## Failure Mechanism
When a product's price is updated using `update_product`, the cache still holds the old price. If `get_product` is called after the update, it retrieves the stale cached value instead of the updated product from the database, leading to incorrect information being presented.

## Broken Invariant
The invariant that subsequent calls to `get_product()` must reflect the updates made to the product is violated, as the cache does not get invalidated and continues to return outdated information.

## Fix Strategy
By adding a call to `invalidate(product_id)` in the `update_product` function after updating the product, the cache will be cleared for that product ID, ensuring that the next call to `get_product()` retrieves the updated product information from the database.

from cache import get, put, invalidate

_db = {}

def add_product(product_id, name, price):
    """Add a product to the database."""
    _db[product_id] = {"name": name, "price": price}


def get_product(product_id):
    """Get product, checking cache first."""
    cached = get(product_id)
    if cached is not None:
        return cached
    product = _db.get(product_id)
    if product is not None:
        put(product_id, dict(product))
    return _db.get(product_id)


def update_product(product_id, **fields):
    """Update product in DB.

    Invariant: subsequent get_product() must reflect the update.
    """
    if product_id not in _db:
        return False
    _db[product_id].update(fields)
    invalidate(product_id)  # Fix: Invalidate cache after update
    return True


def reset():
    """Clear DB and cache."""
    _db.clear()
    from cache import clear
    clear()
