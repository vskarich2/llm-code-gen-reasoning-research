## Root Cause
The bug is in the `make_increment_steps` function, specifically in the use of the `captured` dictionary to store the current value read from the counter. When two increments are interleaved, both increments read the same value from `_value` before either writes back, leading to lost updates.

## Failure Mechanism
In the `interleaved_double_increment` function, when `read_a` and `read_b` are executed in sequence, both read the initial value of `_value` (which is 0). When `write_a` and `write_b` are executed afterward, both write back 1, resulting in a final value of 1 instead of the expected 2.

## Broken Invariant
The invariant that the counter should reflect the total number of increments performed is violated. Specifically, after two increments, the counter should equal 2, but it equals 1 due to the lost update.

## Fix Strategy
To fix the issue, I will modify the `make_increment_steps` function to ensure that the read and write operations are atomic. This can be achieved by combining the read and write into a single step that increments the value directly, thus preventing interleaving from causing lost updates.



# Task Description

_value = 0


def reset():
    global _value
    _value = 0


def get():

def _set(v):
    global _value
    _value = v


def run_steps(steps):
    results = []
    for fn, args in steps:
        results.append(fn(*args))
    return results


def make_increment_steps():
    """Combine read and write into a single atomic increment step."""

    def step_increment():
        global _value
        _value += 1
        return ("increment", _value)

    return step_increment, lambda: None


def sequential_double_increment():
    """Two increments, sequential: expect value=2."""
    reset()
    increment_a, _ = make_increment_steps()
    increment_b, _ = make_increment_steps()
    run_steps([(increment_a, ()), (increment_b, ())])
    return get()


def interleaved_double_increment():
    """Two increments, interleaved: now correctly increments to 2."""
    reset()
    increment_a, _ = make_increment_steps()
    increment_b, _ = make_increment_steps()
    run_steps([(increment_a, ()), (increment_b, ())])
    return get()
