## Failure Mechanism
When multiple requests are processed, if one request applies overrides, it alters the cached configuration for all subsequent requests. For example, if the first request sets `debug` to `True`, all following requests will see `debug` as `True`, even if they do not intend to enable debug mode.

## Broken Invariant

## Fix Strategy
The code change creates a copy of the base configuration in the `apply_config` method by using `cfg = dict(self._base)` before applying any overrides. This ensures that each request operates on a separate configuration instance, preventing unintended side effects from shared state.

# Code Produced
```python
from config import create_config


class ConfigMiddleware:
    """Middleware that loads config once and applies per-request overrides."""

    def __init__(self):
        self._base = create_config()  # cached at init time

    def apply_config(self, request_overrides=None):
        """Return config for this request, applying any overrides."""
        cfg = dict(self._base)  # Create a copy to avoid mutating the cached reference
        if request_overrides:
            cfg.update(request_overrides)  # Now mutates a copy, not the cached reference
        return cfg

    def get_timeout(self):
        return self._base.get("timeout", 30)
```
