KEY FINDINGS

1. HAIKU RECONSTRUCTION CATASTROPHE
   Haiku (claude-3-haiku) has 78% reconstruction failure rate overall.
   Root cause: Haiku embeds triple-quoted Python strings ("""...""") inside
   JSON string values. The v2 parser cannot extract files from this format.
   Config_shadowing baseline is the exception (100% parse success) because
   the fix changes a single-line dict literal that doesn't need triple-quotes.
   For lost_update and early_return_a, Haiku's code is CORRECT but unparseable:
   - lost_update: correct atomic step fix, correct reasoning, 0% pass (100% parse fail)
   - early_return_a: correct ledger fix, correct reasoning, 0% pass (100% parse fail)

2. SONNET-4 PROFILE
   Sonnet-4 (claude-sonnet-4) has 0% reconstruction failures — perfect JSON.
   - config_shadowing: 0% pass, 100% LEG rate. Sonnet identifies the bug correctly
     but applies the TRAP fix (rerouting to get_config instead of fixing DEFAULTS).
     This is identical to nano's behavior.
   - early_return_a: 100% pass across all conditions. Trivially solved.
   - lost_update: 0% pass, 92% LEG rate at baseline. Sonnet understands non-atomic
     read-modify-write but cannot produce the step-function fix. LEG reduces LEG
     rate to 62% (LEG condition) but doesn't convert to passes — the model can't
     serialize the fix regardless of scaffolding.

4. HAIKU'S HIDDEN CAPABILITY
   Haiku achieves 100% on config_shadowing baseline — the ONLY sub-5.4-mini model
   to fix the structural root cause (changing DEFAULTS timeout from 5 to 30).
   But this capability is invisible on lost_update and early_return_a because
   100% of outputs fail JSON reconstruction. If the parser were fixed to handle
   triple-quoted strings, Haiku's actual pass rate could be significantly higher.

5. SONNET-4 vs 5.4-MINI: SIMILAR PROFILES
   Both are strong models with distinct weakness on lost_update (high LEG rate).
   - 5.4-mini: 20% pass, 80% LEG (LEG helps: +56pp with LEG condition)
   - sonnet-4: 0% pass, 92% LEG (LEG doesn't help: 0% pass in all conditions)
   5.4-mini can convert reasoning to execution with LEG scaffolding; sonnet-4 cannot.
   This suggests the step-function concurrency simulation pattern is a specific
   serialization weakness for Claude models.
