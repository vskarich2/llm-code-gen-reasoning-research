# 🧨 Common Failure Modes to Watch

## 1. Hidden state reintroduction

* global config
* global logger
* mutable module state

## 2. Retry / state-machine leakage

* passing too much across attempts
* implicit access to prior attempt state

## 3. Schema drift

* graph output differs from legacy output
* breaks logs, metrics, or dashboard silently

## 4. Replay harness drift

* mocked replay path behaves differently from real execution path

## 5. Parallel nondeterminism

* merge-order bugs
* event-order instability
* hidden shared state

## 6. Prompt drift

* retry/state-machine prompt paths diverge from canonical templating system

## 7. Log schema entropy

* ad hoc event payloads
* metrics/dashboard become brittle
